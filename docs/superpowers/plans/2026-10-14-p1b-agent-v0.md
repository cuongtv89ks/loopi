# P1b — Loopi Agent v0 (Rust) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `loopi-agent`, the single Rust binary on the Pi Zero W that records low-fps H.264 video and Opus audio into a crash-safe on-disk queue, uploads it to the brain over mTLS, sends heartbeats, obeys pause/resume/audio commands, drives the privacy LED and button, and provisions WiFi on first boot.

**Architecture:** A library crate (`agent/src/lib.rs`) holds all logic behind small traits (`Clock`, `DiskUsage`, `Transport`, `AudioSource`, `LedDriver`, `SysProbe`) so it is unit-testable on macOS/Linux hosts; `main.rs` only wires real implementations. Video is captured by supervising `rpicam-vid --segment`; audio by a blocking ALSA thread encoding Ogg Opus. A tokio `current_thread` runtime runs uploader, heartbeat, video supervisor, LED loop and the control loop that computes recording gates.

**Tech Stack:** Rust stable ≥ 1.80 (edition 2021), tokio, reqwest 0.12 + rustls 0.23 (ring provider), rcgen 0.13, serde/toml/serde_json, chrono + chrono-tz, ulid, sha2, ogg 0.9 + opus 0.3 (libopus), alsa 0.9, gpiocdev 0.7, sd-notify 0.4; tests: tempfile, wiremock, jsonschema, serde_yaml.

**Spec:** `docs/superpowers/specs/2026-10-14-loopi-design.md` (§6.6, §7, §8, §11, §12, §14 P1). **Depends on:** P1a (`docs/protocol/v1.openapi.yaml` must exist).

## Global Constraints

- Target `arm-unknown-linux-gnueabihf` (ARMv6 hard-float, Pi Zero W). Everything must also build and test on the dev host; Linux-only crates (`alsa`, `gpiocdev`, `sd-notify`) are behind `cfg(target_os = "linux")`.
- Host prerequisites: macOS `brew install opus pkg-config`; Linux `sudo apt install libopus-dev libasound2-dev pkg-config`; `cargo install cargo-llvm-cov` for coverage.
- TLS: rustls 0.23 with the **ring** provider only (no `aws-lc-rs`), TLS 1.3, cipher order ChaCha20-Poly1305 first (ARMv6 has no AES hardware).
- Device key: ECDSA P-256. Pairing is trust-on-first-use; afterwards the server is verified against the stored CA.
- Protocol: `docs/protocol/v1.openapi.yaml`; header names exactly `X-Loopi-Kind`, `X-Loopi-Start`, `X-Loopi-End`, `X-Loopi-Sha256`, `X-Loopi-Video-Fps`, `X-Loopi-Agent-Version`; timestamps RFC 3339 UTC with `Z`.
- Data layout under `paths.data_dir` (default `/data`): `config/loopi.toml`, `config/state.json`, `config/wpa_supplicant-wlan0.conf`, `keys/{device_id,device.key,device.crt,ca.crt}`, `queue/items/<id>.<ext>` + `queue/items/<id>.meta`, `queue/quarantine/`, `queue/incoming/video/<run-ulid>/v_%06d.h264`, `queue/incoming/audio/<ulid>.opus.part`.
- Privacy invariant: the LED is **Solid whenever any recorder runs**; recorders die with the agent (`PR_SET_PDEATHSIG` + systemd `KillMode=control-group`); no config key disables the LED.
- Recording gates: video = paired ∧ clock synced ∧ ¬paused ∧ ¬quiet hours ∧ ¬disk stopped; audio = video gate ∧ `audio_enabled`. Pause and audio state persist in `config/state.json`.
- Disk guard: ≥ 85 % → delete oldest **video** items until < 80 %; ≥ 95 % → stop recording. Audio and markers are never deleted automatically.
- Defaults: 1920×1080 @ 2 fps, 800 kbps, `--intra` = 5 s, segment 60 s; Opus 16 kHz mono 24 kbps, 20 ms frames, pre-skip 312; heartbeat 15 s; upload backoff 1 s → 300 s; camera backoff ≤ 60 s; camera failure limit 5; GPIO LED 17, button 27 (active-low, pull-up).
- Runtime: tokio `current_thread`; target RSS < 20 MB (excluding `rpicam-vid`).
- Coverage ≥ 80 % for the library (`cargo llvm-cov --ignore-filename-regex 'main.rs'`).
- Commits: conventional commits.

## Review Focus

1. Power cut between moving a segment into the queue and writing its sidecar → on restart the orphan payload is removed and counted as dropped; it is never uploaded without metadata and never blocks the queue. Test: Task 2 (`recover_removes_orphans_and_counts_them`).
2. Wall clock jumps backwards (NTP correction) between two segments → the later segment gets `started_at = ended_at − segment`, never `ended_at < started_at` (the brain would reject it with 422 forever). Test: Task 9 (`segment_start_survives_clock_jump`).
3. Disk above 85 % while the brain is offline → only video items are deleted, audio and markers survive, and the drop count reaches the brain in a later heartbeat even if one heartbeat fails. Tests: Task 2 (`enforce_drops_only_video`), Task 8 (`dropped_count_survives_failed_heartbeat`).
4. Camera unplugged → `rpicam-vid` exits immediately in a loop: failures are counted, backoff grows to the cap, the LED goes to error blink after 5 failures, the recording flag is false. Test: Task 9 (`crashing_camera_backs_off_and_counts_failures`).
5. Pause arrives mid-segment → the recorder stops gracefully and the partial segment is still queued and uploaded; nothing stays in `incoming/`. Tests: Task 9 (`closing_gate_queues_partial_segment`), Task 11 e2e.

```rust
//! Small filesystem helpers shared by config, queue and pairing.
use std::fs::{self, File, OpenOptions};
use std::io::{self, Write};
use std::os::unix::fs::OpenOptionsExt;
use std::path::{Path, PathBuf};

/// Hidden temp path next to `path`: `dir/.name.tmp`. Anything ending in `.tmp` is garbage after a crash.
pub fn tmp_path(path: &Path) -> PathBuf {
    let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
    path.with_file_name(format!(".{name}.tmp"))
}

/// Write `bytes` to `path` atomically (temp file, fsync, rename, fsync dir) with permissions `mode`.
pub fn write_atomic(path: &Path, bytes: &[u8], mode: u32) -> io::Result<()> {
    let tmp = tmp_path(path);
    {
        let mut file = OpenOptions::new().write(true).create(true).truncate(true).mode(mode).open(&tmp)?;
        file.write_all(bytes)?;
        file.sync_all()?;
    }
    fs::rename(&tmp, path)?;
    if let Some(dir) = path.parent() {
        // Best effort: directory fsync is not supported on every filesystem (e.g. FAT).
        if let Ok(handle) = File::open(dir) {
            let _ = handle.sync_all();
        }
    }
    Ok(())
}
```

```rust
//! Quiet hours: local-time ranges during which nothing is recorded.
use chrono::{DateTime, NaiveTime, Utc};
use chrono_tz::Tz;

use crate::config::ScheduleConfig;

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct QuietHours {
    ranges: Vec<(NaiveTime, NaiveTime)>,
}

impl QuietHours {
    /// Parse `["HH:MM-HH:MM", ...]`. A range may wrap past midnight (`22:00-07:00`).
    pub fn parse(specs: &[String]) -> Result<Self, String> {
        let mut ranges = Vec::with_capacity(specs.len());
        for spec in specs {
            let (start, end) = spec
                .split_once('-')
                .ok_or_else(|| format!("quiet hours {spec:?} must look like HH:MM-HH:MM"))?;
            let parse = |s: &str| {
                NaiveTime::parse_from_str(s.trim(), "%H:%M").map_err(|_| format!("bad time {s:?} in {spec:?}"))
            };
            let (start, end) = (parse(start)?, parse(end)?);
            if start == end {
                return Err(format!("quiet hours {spec:?} is empty"));
            }
            ranges.push((start, end));
        }
        Ok(Self { ranges })
    }

    pub fn contains(&self, t: NaiveTime) -> bool {
        self.ranges.iter().any(|&(start, end)| {
            if start < end {
                t >= start && t < end
            } else {
                t >= start || t < end
            }
        })
    }
}

#[derive(Debug, Clone)]
pub struct Schedule {
    tz: Tz,
    quiet: QuietHours,
}

impl Schedule {
    pub fn from_config(config: &ScheduleConfig) -> Result<Self, String> {
        let tz: Tz = config
            .timezone
            .parse()
            .map_err(|_| format!("unknown timezone {:?}", config.timezone))?;
        Ok(Self { tz, quiet: QuietHours::parse(&config.quiet_hours)? })
    }

    pub fn is_quiet(&self, now: DateTime<Utc>) -> bool {
        self.quiet.contains(now.with_timezone(&self.tz).time())
    }
}
```

```rust
impl Config {
    pub fn parse(text: &str) -> Result<Self, ConfigError> {
        let config: Config = toml::from_str(text)?;
        config.validate()?;
        Ok(config)
    }

    pub fn load(path: &Path) -> Result<Self, ConfigError> {
        let text = fs::read_to_string(path).map_err(io_err(path))?;
        Self::parse(&text)
    }

    pub fn validate(&self) -> Result<(), ConfigError> {
        let invalid = |msg: String| Err(ConfigError::Invalid(msg));
        if !self.brain.url.starts_with("https://") {
            return invalid(format!("brain.url must start with https:// (got {:?})", self.brain.url));
        }
        if let Some(fp) = &self.brain.ca_fingerprint {
            if normalize_fingerprint(fp).is_none() {
                return invalid("brain.ca_fingerprint must be a SHA-256 hex fingerprint".into());
            }
        }
        let c = &self.capture;
        if !(1..=30).contains(&c.video_fps) {
            return invalid(format!("capture.video_fps must be 1..=30 (got {})", c.video_fps));
        }
        if !(64..=4608).contains(&c.video_width) || c.video_width % 2 != 0 {
            return invalid(format!("capture.video_width must be even and 64..=4608 (got {})", c.video_width));
        }
        if !(64..=2592).contains(&c.video_height) || c.video_height % 2 != 0 {
            return invalid(format!("capture.video_height must be even and 64..=2592 (got {})", c.video_height));
        }
        if !(100_000..=10_000_000).contains(&c.video_bitrate_bps) {
            return invalid(format!(
                "capture.video_bitrate_bps must be 100000..=10000000 (got {})",
                c.video_bitrate_bps
            ));
        }
        if !(10..=600).contains(&c.segment_seconds) {
            return invalid(format!("capture.segment_seconds must be 10..=600 (got {})", c.segment_seconds));
        }
        if c.audio_device.trim().is_empty() || c.camera_cmd.trim().is_empty() {
            return invalid("capture.audio_device and capture.camera_cmd must not be empty".into());
        }
        Schedule::from_config(&self.schedule).map_err(ConfigError::Invalid)?;
        if let Some(wifi) = &self.wifi {
            validate_wifi(wifi).map_err(ConfigError::Invalid)?;
        }
        Ok(())
    }
}

/// Lowercase hex without separators, or `None` if `raw` is not a SHA-256 fingerprint.
pub fn normalize_fingerprint(raw: &str) -> Option<String> {
    let cleaned: String = raw
        .chars()
        .filter(|c| *c != ':' && !c.is_whitespace())
        .collect::<String>()
        .to_ascii_lowercase();
    (cleaned.len() == 64 && cleaned.chars().all(|c| c.is_ascii_hexdigit())).then_some(cleaned)
}

fn is_hex64(s: &str) -> bool {
    s.len() == 64 && s.chars().all(|c| c.is_ascii_hexdigit())
}

fn validate_wifi(wifi: &WifiConfig) -> Result<(), String> {
    if wifi.ssid.is_empty() || wifi.ssid.len() > 32 {
        return Err("wifi.ssid must be 1..=32 bytes".into());
    }
    if let Some(cc) = &wifi.country {
        if cc.len() != 2 || !cc.chars().all(|c| c.is_ascii_uppercase()) {
            return Err("wifi.country must be a 2-letter uppercase code such as KR".into());
        }
    }
    // Empty psk means an open network (or a scrubbed boot copy).
    if wifi.psk.is_empty() || is_hex64(&wifi.psk) {
        return Ok(());
    }
    let printable = wifi.psk.chars().all(|c| c.is_ascii() && !c.is_ascii_control() && c != '"');
    if !(8..=63).contains(&wifi.psk.len()) || !printable {
        return Err("wifi.psk must be 8..=63 printable ASCII characters without '\"' (or 64 hex chars)".into());
    }
    Ok(())
}

/// wpa_supplicant config. The SSID is hex-encoded so any UTF-8 name works without escaping.
pub fn render_wpa_conf(wifi: &WifiConfig) -> String {
    let mut out = String::from("ctrl_interface=/run/wpa_supplicant\nupdate_config=0\n");
    if let Some(cc) = &wifi.country {
        out.push_str(&format!("country={cc}\n"));
    }
    out.push_str("network={\n");
    out.push_str(&format!("    ssid={}\n", hex::encode(wifi.ssid.as_bytes())));
    if wifi.psk.is_empty() {
        out.push_str("    key_mgmt=NONE\n");
    } else if is_hex64(&wifi.psk) {
        out.push_str(&format!("    psk={}\n", wifi.psk.to_ascii_lowercase()));
    } else {
        out.push_str(&format!("    psk=\"{}\"\n", wifi.psk));
    }
    out.push_str("}\n");
    out
}

/// Copy of `config` without the WiFi passphrase and the pairing token.
pub fn scrub_secrets(config: &Config) -> Config {
    let mut scrubbed = config.clone();
    if let Some(wifi) = scrubbed.wifi.as_mut() {
        wifi.psk.clear();
    }
    scrubbed.brain.pair_token = None;
    scrubbed
}

/// First-boot provisioning: copy a *fresh* boot-partition config (one that still carries a WiFi
/// passphrase or a pair token) to `<data_dir>/config/`, write the wpa_supplicant config, then
/// remove the secrets from the boot copy. Nothing is written if the boot config is invalid.
pub fn import_boot_config(boot_toml: &Path, data_dir: &Path) -> Result<ImportOutcome, ConfigError> {
    if !boot_toml.exists() {
        return Ok(ImportOutcome::NoBootConfig);
    }
    let config = Config::load(boot_toml)?;
    let fresh = config.wifi.as_ref().is_some_and(|w| !w.psk.is_empty()) || config.brain.pair_token.is_some();
    if !fresh {
        return Ok(ImportOutcome::AlreadyImported);
    }
    let config_dir = data_dir.join("config");
    fs::create_dir_all(&config_dir).map_err(io_err(&config_dir))?;
    let data_config = config_dir.join(CONFIG_FILE);
    write_atomic(&data_config, toml::to_string(&config)?.as_bytes(), PRIVATE).map_err(io_err(&data_config))?;
    if let Some(wifi) = &config.wifi {
        let wpa = config_dir.join(WPA_CONF_FILE);
        write_atomic(&wpa, render_wpa_conf(wifi).as_bytes(), PRIVATE).map_err(io_err(&wpa))?;
    }
    write_atomic(boot_toml, toml::to_string(&scrub_secrets(&config))?.as_bytes(), PUBLIC)
        .map_err(io_err(boot_toml))?;
    Ok(ImportOutcome::Imported)
}
```

```rust
use std::fs;
use std::io;
use std::path::PathBuf;
use std::sync::Mutex;

use crate::disk::DiskUsage;

/// Disk usage fixed at a settable percentage.
pub struct FixedDisk(pub Mutex<f32>);

impl FixedDisk {
    pub fn new(pct: f32) -> Self {
        Self(Mutex::new(pct))
    }
}

impl DiskUsage for FixedDisk {
    fn used_pct(&self) -> io::Result<f32> {
        Ok(*self.0.lock().unwrap())
    }
}

/// Usage = `base + per_item × (queued items in dir)`, so deleting items frees "space".
pub struct CountingDisk {
    pub dir: PathBuf,
    pub base: f32,
    pub per_item: f32,
}

impl DiskUsage for CountingDisk {
    fn used_pct(&self) -> io::Result<f32> {
        let items = fs::read_dir(&self.dir)?
            .filter_map(Result::ok)
            .filter(|e| e.path().extension().is_some_and(|x| x == "meta"))
            .count();
        Ok(self.base + items as f32 * self.per_item)
    }
}
```

```rust
//! Durable on-disk upload queue.
//!
//! `<root>/items/<id>.<ext>` holds the payload and `<root>/items/<id>.meta` its JSON `ItemMeta`.
//! The payload is renamed into place first, then the sidecar is written atomically, so only items
//! with a sidecar are visible. `open()` removes anything a power cut left half-written.
//! `<root>/quarantine/` keeps items the brain will never accept, with a `.reason` file.
use std::collections::HashSet;
use std::fs::{self, File};
use std::io::{self, Read, Write};
use std::path::{Path, PathBuf};

use chrono::{DateTime, Utc};
use sha2::{Digest, Sha256};

use crate::fsutil::write_atomic;
use crate::item::{ItemKind, ItemMeta};

const META_EXT: &str = "meta";
const TMP_EXT: &str = "tmp";
const FILE_MODE: u32 = 0o640;

#[derive(Debug, Clone, PartialEq)]
pub struct QueuedItem {
    pub meta: ItemMeta,
    pub data_path: PathBuf,
}

#[derive(Debug)]
pub struct Queue {
    items: PathBuf,
    quarantine: PathBuf,
}

pub fn sha256_file(path: &Path) -> io::Result<(String, u64)> {
    let mut file = File::open(path)?;
    let mut hasher = Sha256::new();
    let mut buf = vec![0u8; 64 * 1024];
    let mut size = 0u64;
    loop {
        let n = file.read(&mut buf)?;
        if n == 0 {
            break;
        }
        hasher.update(&buf[..n]);
        size += n as u64;
    }
    Ok((hex::encode(hasher.finalize()), size))
}

fn remove_if_exists(path: &Path) -> io::Result<()> {
    match fs::remove_file(path) {
        Err(e) if e.kind() != io::ErrorKind::NotFound => Err(e),
        _ => Ok(()),
    }
}

impl Queue {
    pub fn open(root: &Path) -> io::Result<(Self, u32)> {
        let queue = Self { items: root.join("items"), quarantine: root.join("quarantine") };
        fs::create_dir_all(&queue.items)?;
        fs::create_dir_all(&queue.quarantine)?;
        let dropped = queue.recover()?;
        Ok((queue, dropped))
    }

    pub fn items_dir(&self) -> &Path {
        &self.items
    }

    fn data_path(&self, id: &str, kind: ItemKind) -> PathBuf {
        self.items.join(format!("{id}.{}", kind.extension()))
    }

    fn meta_path(&self, id: &str) -> PathBuf {
        self.items.join(format!("{id}.{META_EXT}"))
    }

    /// Move `src` (same filesystem) into the queue and record its metadata.
    pub fn enqueue_file(
        &self,
        src: &Path,
        kind: ItemKind,
        started_at: DateTime<Utc>,
        ended_at: DateTime<Utc>,
        video_fps: Option<u32>,
    ) -> io::Result<ItemMeta> {
        let (sha256, size) = sha256_file(src)?;
        let id = ulid::Ulid::new().to_string();
        fs::rename(src, self.data_path(&id, kind))?;
        let meta = ItemMeta { id, kind, started_at, ended_at, sha256, size, video_fps };
        let json = serde_json::to_vec(&meta).map_err(io::Error::other)?;
        write_atomic(&self.meta_path(&meta.id), &json, FILE_MODE)?;
        Ok(meta)
    }

    pub fn enqueue_bytes(
        &self,
        bytes: &[u8],
        kind: ItemKind,
        started_at: DateTime<Utc>,
        ended_at: DateTime<Utc>,
    ) -> io::Result<ItemMeta> {
        let tmp = self.items.join(format!(".{}.{TMP_EXT}", ulid::Ulid::new()));
        {
            let mut file = File::create(&tmp)?;
            file.write_all(bytes)?;
            file.sync_all()?;
        }
        self.enqueue_file(&tmp, kind, started_at, ended_at, None)
    }

    fn metas(&self) -> io::Result<Vec<ItemMeta>> {
        let mut metas = Vec::new();
        for entry in fs::read_dir(&self.items)? {
            let path = entry?.path();
            if path.extension().is_some_and(|e| e == META_EXT) {
                if let Ok(meta) = serde_json::from_slice::<ItemMeta>(&fs::read(&path)?) {
                    metas.push(meta);
                }
            }
        }
        metas.sort_by(|a, b| a.id.cmp(&b.id));
        Ok(metas)
    }

    fn queued(&self, meta: ItemMeta) -> QueuedItem {
        let data_path = self.data_path(&meta.id, meta.kind);
        QueuedItem { meta, data_path }
    }

    pub fn oldest(&self) -> io::Result<Option<QueuedItem>> {
        Ok(self.metas()?.into_iter().next().map(|m| self.queued(m)))
    }

    pub fn oldest_of_kind(&self, kind: ItemKind) -> io::Result<Option<QueuedItem>> {
        Ok(self.metas()?.into_iter().find(|m| m.kind == kind).map(|m| self.queued(m)))
    }

    pub fn len(&self) -> io::Result<usize> {
        Ok(self.metas()?.len())
    }

    pub fn is_empty(&self) -> io::Result<bool> {
        Ok(self.len()? == 0)
    }

    pub fn remove(&self, meta: &ItemMeta) -> io::Result<()> {
        remove_if_exists(&self.meta_path(&meta.id))?;
        remove_if_exists(&self.data_path(&meta.id, meta.kind))
    }

    pub fn quarantine(&self, meta: &ItemMeta, reason: &str) -> io::Result<()> {
        let data = self.data_path(&meta.id, meta.kind);
        if data.exists() {
            fs::rename(&data, self.quarantine.join(format!("{}.{}", meta.id, meta.kind.extension())))?;
        }
        fs::write(self.quarantine.join(format!("{}.reason", meta.id)), reason)?;
        fs::rename(self.meta_path(&meta.id), self.quarantine.join(format!("{}.{META_EXT}", meta.id)))
    }

    /// Remove temp files, payloads without a valid sidecar and sidecars without a payload.
    fn recover(&self) -> io::Result<u32> {
        let mut dropped = 0u32;
        let mut valid = HashSet::new();
        let mut payloads = Vec::new();
        for entry in fs::read_dir(&self.items)? {
            let path = entry?.path();
            let name = path.file_name().and_then(|n| n.to_str()).unwrap_or_default().to_string();
            let ext = path.extension().and_then(|e| e.to_str()).unwrap_or_default().to_string();
            let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or_default().to_string();
            if ext == TMP_EXT || name.starts_with('.') {
                fs::remove_file(&path)?;
                dropped += 1;
            } else if ext == META_EXT {
                let meta = fs::read(&path).ok().and_then(|b| serde_json::from_slice::<ItemMeta>(&b).ok());
                match meta {
                    Some(m) if m.id == stem && self.data_path(&m.id, m.kind).exists() => {
                        valid.insert(stem);
                    }
                    _ => {
                        fs::remove_file(&path)?;
                        dropped += 1;
                    }
                }
            } else {
                payloads.push((stem, path));
            }
        }
        for (stem, path) in payloads {
            if !valid.contains(&stem) {
                fs::remove_file(&path)?;
                dropped += 1;
            }
        }
        Ok(dropped)
    }
}
```

```rust
//! Disk guard: keep the SD card from filling up while the brain is unreachable.
use std::ffi::CString;
use std::io;
use std::os::unix::ffi::OsStrExt;
use std::path::Path;

use crate::item::ItemKind;
use crate::queue::Queue;

pub const DROP_ABOVE_PCT: f32 = 85.0;
pub const DROP_UNTIL_PCT: f32 = 80.0;
pub const STOP_ABOVE_PCT: f32 = 95.0;

pub trait DiskUsage: Send + Sync {
    fn used_pct(&self) -> io::Result<f32>;
}

pub struct StatvfsUsage {
    path: CString,
}

impl StatvfsUsage {
    pub fn new(path: &Path) -> io::Result<Self> {
        let path = CString::new(path.as_os_str().as_bytes()).map_err(io::Error::other)?;
        Ok(Self { path })
    }
}

impl DiskUsage for StatvfsUsage {
    fn used_pct(&self) -> io::Result<f32> {
        // SAFETY: `stat` is plain old data and `path` is a valid NUL-terminated string.
        let mut stat: libc::statvfs = unsafe { std::mem::zeroed() };
        if unsafe { libc::statvfs(self.path.as_ptr(), &mut stat) } != 0 {
            return Err(io::Error::last_os_error());
        }
        let used = stat.f_blocks as f64 - stat.f_bfree as f64;
        let denominator = used + stat.f_bavail as f64;
        Ok(if denominator <= 0.0 { 0.0 } else { (used / denominator * 100.0) as f32 })
    }
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct DiskReport {
    pub used_pct: f32,
    pub dropped: u32,
    pub stop: bool,
}

/// At ≥ 85 % delete the oldest *video* items until usage is below 80 %. Audio and markers are
/// never deleted. `stop` is set when usage is still ≥ 95 % afterwards.
pub fn enforce(queue: &Queue, disk: &dyn DiskUsage) -> io::Result<DiskReport> {
    let mut used = disk.used_pct()?;
    let mut dropped = 0;
    if used >= DROP_ABOVE_PCT {
        while used >= DROP_UNTIL_PCT {
            let Some(item) = queue.oldest_of_kind(ItemKind::Video)? else { break };
            queue.remove(&item.meta)?;
            dropped += 1;
            used = disk.used_pct()?;
        }
    }
    Ok(DiskReport { used_pct: used, dropped, stop: used >= STOP_ABOVE_PCT })
}
```

```rust
/// A clock that only moves when told to.
pub struct ManualClock {
    now: Mutex<DateTime<Utc>>,
    synced: AtomicBool,
}

impl ManualClock {
    pub fn new(now: DateTime<Utc>) -> Self {
        Self { now: Mutex::new(now), synced: AtomicBool::new(true) }
    }

    pub fn advance(&self, by: chrono::Duration) {
        let mut now = self.now.lock().unwrap();
        *now += by;
    }

    pub fn set_synced(&self, synced: bool) {
        self.synced.store(synced, Ordering::SeqCst);
    }
}

impl Clock for ManualClock {
    fn now(&self) -> DateTime<Utc> {
        *self.now.lock().unwrap()
    }

    fn is_synced(&self) -> bool {
        self.synced.load(Ordering::SeqCst)
    }
}
```

```rust
//! User-controllable state (pause, audio on/off), remote command parsing and recording gates.
use std::io;
use std::path::Path;

use serde::{Deserialize, Serialize};
use serde_json::Value;

use crate::fsutil::write_atomic;
use crate::status::AgentStatus;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub struct ControlState {
    pub paused: bool,
    pub audio_enabled: bool,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Command {
    Pause,
    Resume,
    TogglePause,
    SetAudio(bool),
}

impl ControlState {
    pub fn initial(audio_enabled: bool) -> Self {
        Self { paused: false, audio_enabled }
    }

    #[must_use]
    pub fn apply(self, command: &Command) -> Self {
        match command {
            Command::Pause => Self { paused: true, ..self },
            Command::Resume => Self { paused: false, ..self },
            Command::TogglePause => Self { paused: !self.paused, ..self },
            Command::SetAudio(on) => Self { audio_enabled: *on, ..self },
        }
    }
}

fn is_empty_payload(payload: &Value) -> bool {
    payload.is_null() || payload.as_object().is_some_and(|o| o.is_empty())
}

/// Translate a brain command (protocol v1 `Command`). Only `set_config {audio_enabled}` is allowed.
pub fn parse_remote_command(kind: &str, payload: &Value) -> Result<Command, String> {
    match kind {
        "pause" if is_empty_payload(payload) => Ok(Command::Pause),
        "resume" if is_empty_payload(payload) => Ok(Command::Resume),
        "set_config" => {
            let object = payload.as_object().ok_or_else(|| "set_config payload must be an object".to_string())?;
            match (object.len(), object.get("audio_enabled")) {
                (1, Some(Value::Bool(on))) => Ok(Command::SetAudio(*on)),
                _ => Err(format!("set_config supports only {{\"audio_enabled\": bool}}, got {payload}")),
            }
        }
        other => Err(format!("unsupported command {other:?} with payload {payload}")),
    }
}

/// Persisted state; a missing or corrupt file falls back to defaults (and is logged).
pub fn load_state(path: &Path, default_audio: bool) -> ControlState {
    match std::fs::read(path) {
        Ok(bytes) => serde_json::from_slice(&bytes).unwrap_or_else(|e| {
            tracing::warn!(error = %e, path = %path.display(), "corrupt control state, using defaults");
            ControlState::initial(default_audio)
        }),
        Err(_) => ControlState::initial(default_audio),
    }
}

pub fn save_state(path: &Path, state: &ControlState) -> io::Result<()> {
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let json = serde_json::to_vec(state).map_err(io::Error::other)?;
    write_atomic(path, &json, 0o600)
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Gates {
    pub video: bool,
    pub audio: bool,
}

pub fn recording_gates(state: &ControlState, status: &AgentStatus) -> Gates {
    let video = status.paired && status.clock_synced && !state.paused && !status.quiet && !status.disk_stopped;
    Gates { video, audio: video && state.audio_enabled }
}
```

```rust
//! Privacy LED. Solid whenever anything is being recorded — errors never hide recording.
use std::future::Future;
use std::io;
use std::time::Duration;

use tokio::time::Instant;

use crate::control::ControlState;
use crate::status::AgentStatus;

pub const CAMERA_FAILURE_LIMIT: u32 = 5;
const SLOW_PERIOD_MS: u64 = 1000;
const FAST_PERIOD_MS: u64 = 200;
const BLINK_FRAME: Duration = Duration::from_millis(50);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LedPattern {
    Off,
    Solid,
    SlowBlink,
    FastBlink,
}

pub fn led_pattern(status: &AgentStatus, state: &ControlState) -> LedPattern {
    if status.recording_video || status.recording_audio {
        return LedPattern::Solid;
    }
    let error = !status.paired
        || !status.clock_synced
        || status.disk_stopped
        || status.camera_failures >= CAMERA_FAILURE_LIMIT;
    if error {
        LedPattern::FastBlink
    } else if state.paused || status.quiet {
        LedPattern::SlowBlink
    } else {
        LedPattern::Off
    }
}

pub fn level_at(pattern: LedPattern, elapsed_ms: u64) -> bool {
    match pattern {
        LedPattern::Off => false,
        LedPattern::Solid => true,
        LedPattern::SlowBlink => elapsed_ms % SLOW_PERIOD_MS < SLOW_PERIOD_MS / 2,
        LedPattern::FastBlink => elapsed_ms % FAST_PERIOD_MS < FAST_PERIOD_MS / 2,
    }
}

pub trait LedDriver: Send {
    fn set(&mut self, on: bool) -> io::Result<()>;
}

pub struct NoopLed;

impl LedDriver for NoopLed {
    fn set(&mut self, _on: bool) -> io::Result<()> {
        Ok(())
    }
}

/// Fast-blink `led` until `fut` completes (used while pairing), then switch it off.
pub async fn blink_while<F: Future>(led: &mut dyn LedDriver, fut: F) -> F::Output {
    tokio::pin!(fut);
    let start = Instant::now();
    let mut ticker = tokio::time::interval(BLINK_FRAME);
    loop {
        tokio::select! {
            out = &mut fut => {
                let _ = led.set(false);
                return out;
            }
            _ = ticker.tick() => {
                let on = level_at(LedPattern::FastBlink, start.elapsed().as_millis() as u64);
                let _ = led.set(on);
            }
        }
    }
}
```

```rust
//! Physical button: short press = mark a moment, hold ≥ 2 s = toggle privacy pause.
use std::time::Duration;

pub const SHORT_MAX: Duration = Duration::from_millis(1000);
pub const LONG_MIN: Duration = Duration::from_millis(2000);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Press {
    Short,
    Long,
}

/// Presses between 1 s and 2 s are ignored so an accidental hold does nothing.
pub fn classify(held: Duration) -> Option<Press> {
    if held < SHORT_MAX {
        Some(Press::Short)
    } else if held >= LONG_MIN {
        Some(Press::Long)
    } else {
        None
    }
}

/// Watch an active-low button (GPIO to GND, internal pull-up) on a dedicated thread.
#[cfg(target_os = "linux")]
pub fn spawn_button_thread(chip: String, line: u32, tx: tokio::sync::mpsc::Sender<Press>) -> anyhow::Result<()> {
    use gpiocdev::line::{Bias, EdgeDetection, EdgeKind};

    let request = gpiocdev::Request::builder()
        .on_chip(&chip)
        .with_consumer("loopi-button")
        .with_line(line)
        .as_input()
        .with_bias(Bias::PullUp)
        .with_edge_detection(EdgeDetection::BothEdges)
        .with_debounce_period(Duration::from_millis(20))
        .request()?;
    std::thread::Builder::new().name("button".into()).spawn(move || {
        let mut pressed_at: Option<std::time::Instant> = None;
        loop {
            let event = match request.read_edge_event() {
                Ok(event) => event,
                Err(e) => {
                    tracing::warn!(error = %e, "button read failed");
                    std::thread::sleep(Duration::from_secs(1));
                    continue;
                }
            };
            match event.kind {
                EdgeKind::Falling => pressed_at = Some(std::time::Instant::now()),
                EdgeKind::Rising => {
                    let press = pressed_at.take().and_then(|start| classify(start.elapsed()));
                    if let Some(press) = press {
                        if tx.blocking_send(press).is_err() {
                            return;
                        }
                    }
                }
            }
        }
    })?;
    Ok(())
}
```

```rust
//! rustls client configurations: ring provider, TLS 1.3, ChaCha20 first (no AES hardware on ARMv6).
use std::sync::Arc;

use rustls::client::danger::{HandshakeSignatureValid, ServerCertVerified, ServerCertVerifier};
use rustls::crypto::{ring as ring_provider, verify_tls12_signature, verify_tls13_signature, CryptoProvider};
use rustls::pki_types::pem::PemObject;
use rustls::pki_types::{CertificateDer, PrivateKeyDer, ServerName, UnixTime};
use rustls::{ClientConfig, DigitallySignedStruct, RootCertStore, SignatureScheme};

#[derive(Debug, thiserror::Error)]
pub enum TlsError {
    #[error("invalid PEM: {0}")]
    Pem(String),
    #[error(transparent)]
    Rustls(#[from] rustls::Error),
}

pub fn provider() -> CryptoProvider {
    let mut provider = ring_provider::default_provider();
    provider.cipher_suites = vec![
        ring_provider::cipher_suite::TLS13_CHACHA20_POLY1305_SHA256,
        ring_provider::cipher_suite::TLS13_AES_128_GCM_SHA256,
        ring_provider::cipher_suite::TLS13_AES_256_GCM_SHA384,
    ];
    provider
}

fn pem_err(e: impl std::fmt::Display) -> TlsError {
    TlsError::Pem(e.to_string())
}

/// Client config for every request after pairing: trust only the brain CA, present the device cert.
pub fn mtls_config(ca_pem: &str, cert_pem: &str, key_pem: &str) -> Result<ClientConfig, TlsError> {
    let mut roots = RootCertStore::empty();
    for cert in CertificateDer::pem_slice_iter(ca_pem.as_bytes()) {
        roots.add(cert.map_err(pem_err)?)?;
    }
    if roots.is_empty() {
        return Err(TlsError::Pem("no CA certificate".into()));
    }
    let chain: Vec<CertificateDer<'static>> =
        CertificateDer::pem_slice_iter(cert_pem.as_bytes()).collect::<Result<_, _>>().map_err(pem_err)?;
    if chain.is_empty() {
        return Err(TlsError::Pem("no device certificate".into()));
    }
    let key = PrivateKeyDer::from_pem_slice(key_pem.as_bytes()).map_err(pem_err)?;
    Ok(ClientConfig::builder_with_provider(Arc::new(provider()))
        .with_protocol_versions(&[&rustls::version::TLS13])?
        .with_root_certificates(roots)
        .with_client_auth_cert(chain, key)?)
}

/// Pairing only: the device has no CA yet, so it accepts the server certificate and instead
/// checks the CA it receives against `brain.ca_fingerprint` (trust on first use).
pub fn pairing_config() -> Result<ClientConfig, TlsError> {
    let provider = Arc::new(provider());
    Ok(ClientConfig::builder_with_provider(provider.clone())
        .with_protocol_versions(&[&rustls::version::TLS13])?
        .dangerous()
        .with_custom_certificate_verifier(Arc::new(AcceptAnyServerCert { provider }))
        .with_no_client_auth())
}

#[derive(Debug)]
struct AcceptAnyServerCert {
    provider: Arc<CryptoProvider>,
}

impl ServerCertVerifier for AcceptAnyServerCert {
    fn verify_server_cert(
        &self,
        _end_entity: &CertificateDer<'_>,
        _intermediates: &[CertificateDer<'_>],
        _server_name: &ServerName<'_>,
        _ocsp_response: &[u8],
        _now: UnixTime,
    ) -> Result<ServerCertVerified, rustls::Error> {
        Ok(ServerCertVerified::assertion())
    }

    fn verify_tls12_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> Result<HandshakeSignatureValid, rustls::Error> {
        verify_tls12_signature(message, cert, dss, &self.provider.signature_verification_algorithms)
    }

    fn verify_tls13_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> Result<HandshakeSignatureValid, rustls::Error> {
        verify_tls13_signature(message, cert, dss, &self.provider.signature_verification_algorithms)
    }

    fn supported_verify_schemes(&self) -> Vec<SignatureScheme> {
        self.provider.signature_verification_algorithms.supported_schemes()
    }
}
```

```rust
//! HTTP transport to the brain (protocol v1).
use std::path::Path;
use std::time::Duration;

use async_trait::async_trait;
use chrono::{DateTime, SecondsFormat, Utc};
use reqwest::{header, Client, StatusCode};
use tokio_util::io::ReaderStream;

use crate::item::{ItemKind, ItemMeta};
use crate::wire::{HeartbeatRequest, HeartbeatResponse, PairRequest, PairResponse, RemoteCommand, AGENT_VERSION};

pub const CONNECT_TIMEOUT: Duration = Duration::from_secs(10);
pub const REQUEST_TIMEOUT: Duration = Duration::from_secs(120);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PutOutcome {
    Created,
    Duplicate,
    Conflict,
    Rejected(u16),
    BrainFull,
    UpgradeRequired,
    Unauthorized,
}

#[derive(Debug, thiserror::Error)]
pub enum TransportError {
    #[error("network error: {0}")]
    Network(String),
    #[error("brain returned HTTP {0}")]
    Status(u16),
    #[error("unexpected response: {0}")]
    Decode(String),
    #[error("local I/O error: {0}")]
    Io(#[from] std::io::Error),
}

#[async_trait]
pub trait Transport: Send + Sync {
    async fn put_item(&self, meta: &ItemMeta, data: &Path) -> Result<PutOutcome, TransportError>;
    async fn heartbeat(&self, request: &HeartbeatRequest) -> Result<Vec<RemoteCommand>, TransportError>;
}

pub fn rfc3339(t: DateTime<Utc>) -> String {
    t.to_rfc3339_opts(SecondsFormat::Millis, true)
}

fn network(e: reqwest::Error) -> TransportError {
    TransportError::Network(e.to_string())
}

pub fn build_client(tls: rustls::ClientConfig) -> Result<Client, TransportError> {
    Client::builder()
        .use_preconfigured_tls(tls)
        .connect_timeout(CONNECT_TIMEOUT)
        .timeout(REQUEST_TIMEOUT)
        .build()
        .map_err(network)
}

pub fn map_put_status(status: u16) -> Result<PutOutcome, TransportError> {
    match status {
        201 => Ok(PutOutcome::Created),
        200 => Ok(PutOutcome::Duplicate),
        409 => Ok(PutOutcome::Conflict),
        401 | 403 => Ok(PutOutcome::Unauthorized),
        426 => Ok(PutOutcome::UpgradeRequired),
        507 => Ok(PutOutcome::BrainFull),
        400..=499 => Ok(PutOutcome::Rejected(status)),
        _ => Err(TransportError::Status(status)),
    }
}

pub struct HttpTransport {
    client: Client,
    base_url: String,
}

impl HttpTransport {
    pub fn new(client: Client, base_url: &str) -> Self {
        Self { client, base_url: base_url.trim_end_matches('/').to_string() }
    }
}

#[async_trait]
impl Transport for HttpTransport {
    async fn put_item(&self, meta: &ItemMeta, data: &Path) -> Result<PutOutcome, TransportError> {
        let file = tokio::fs::File::open(data).await?;
        let size = file.metadata().await?.len();
        let mut request = self
            .client
            .put(format!("{}/v1/items/{}", self.base_url, meta.id))
            .header("X-Loopi-Kind", meta.kind.as_str())
            .header("X-Loopi-Start", rfc3339(meta.started_at))
            .header("X-Loopi-End", rfc3339(meta.ended_at))
            .header("X-Loopi-Sha256", meta.sha256.as_str())
            .header("X-Loopi-Agent-Version", AGENT_VERSION)
            .header(header::CONTENT_TYPE, meta.kind.content_type())
            .header(header::CONTENT_LENGTH, size)
            .body(reqwest::Body::wrap_stream(ReaderStream::new(file)));
        if let (ItemKind::Video, Some(fps)) = (meta.kind, meta.video_fps) {
            request = request.header("X-Loopi-Video-Fps", fps);
        }
        let response = request.send().await.map_err(network)?;
        map_put_status(response.status().as_u16())
    }

    async fn heartbeat(&self, request: &HeartbeatRequest) -> Result<Vec<RemoteCommand>, TransportError> {
        let response = self
            .client
            .post(format!("{}/v1/heartbeat", self.base_url))
            .header("X-Loopi-Agent-Version", AGENT_VERSION)
            .json(request)
            .send()
            .await
            .map_err(network)?;
        if response.status() != StatusCode::OK {
            return Err(TransportError::Status(response.status().as_u16()));
        }
        let body: HeartbeatResponse = response.json().await.map_err(|e| TransportError::Decode(e.to_string()))?;
        Ok(body.commands)
    }
}

pub async fn pair(client: &Client, base_url: &str, request: &PairRequest) -> Result<PairResponse, TransportError> {
    let response = client
        .post(format!("{}/v1/pair", base_url.trim_end_matches('/')))
        .header("X-Loopi-Agent-Version", AGENT_VERSION)
        .json(request)
        .send()
        .await
        .map_err(network)?;
    if response.status() != StatusCode::CREATED {
        return Err(TransportError::Status(response.status().as_u16()));
    }
    response.json().await.map_err(|e| TransportError::Decode(e.to_string()))
}
```

```rust
//! Device identity: P-256 key + CSR, pairing with the brain (trust on first use), persistence.
use std::fs;
use std::io;
use std::path::Path;

use rcgen::{CertificateParams, DistinguishedName, DnType, KeyPair, PKCS_ECDSA_P256_SHA256};
use rustls::pki_types::pem::PemObject;
use rustls::pki_types::CertificateDer;
use sha2::{Digest, Sha256};

use crate::config::{normalize_fingerprint, Config};
use crate::fsutil::write_atomic;
use crate::transport::{pair, TransportError};
use crate::wire::{HwInfo, PairRequest};

pub const DEVICE_ID_FILE: &str = "device_id";
pub const KEY_FILE: &str = "device.key";
pub const CERT_FILE: &str = "device.crt";
pub const CA_FILE: &str = "ca.crt";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Identity {
    pub device_id: String,
    pub key_pem: String,
    pub cert_pem: String,
    pub ca_cert_pem: String,
}

#[derive(Debug, thiserror::Error)]
pub enum PairError {
    #[error("device is not paired and brain.pair_token is not configured")]
    NoToken,
    #[error("CA fingerprint mismatch: expected {expected}, got {actual}")]
    CaMismatch { expected: String, actual: String },
    #[error("brain sent an unreadable CA certificate")]
    BadCa,
    #[error("pairing request failed: {0}")]
    Transport(#[from] TransportError),
    #[error("key generation failed: {0}")]
    Key(#[from] rcgen::Error),
    #[error("I/O error: {0}")]
    Io(#[from] io::Error),
}

/// `device_id` is written last, so its presence means the identity is complete.
pub fn load_identity(dir: &Path) -> io::Result<Option<Identity>> {
    if !dir.join(DEVICE_ID_FILE).exists() {
        return Ok(None);
    }
    let read = |name: &str| fs::read_to_string(dir.join(name));
    Ok(Some(Identity {
        device_id: read(DEVICE_ID_FILE)?.trim().to_string(),
        key_pem: read(KEY_FILE)?,
        cert_pem: read(CERT_FILE)?,
        ca_cert_pem: read(CA_FILE)?,
    }))
}

fn save_identity(dir: &Path, identity: &Identity) -> io::Result<()> {
    fs::create_dir_all(dir)?;
    let files = [
        (KEY_FILE, &identity.key_pem),
        (CERT_FILE, &identity.cert_pem),
        (CA_FILE, &identity.ca_cert_pem),
        (DEVICE_ID_FILE, &identity.device_id),
    ];
    for (name, contents) in files {
        write_atomic(&dir.join(name), contents.as_bytes(), 0o600)?;
    }
    Ok(())
}

pub fn generate_key_and_csr() -> Result<(String, String), rcgen::Error> {
    let key = KeyPair::generate_for(&PKCS_ECDSA_P256_SHA256)?;
    let mut params = CertificateParams::new(Vec::<String>::new())?;
    let mut name = DistinguishedName::new();
    name.push(DnType::CommonName, "loopi-device");
    params.distinguished_name = name;
    let csr = params.serialize_request(&key)?;
    Ok((key.serialize_pem(), csr.pem()?))
}

/// Lowercase hex SHA-256 of the first certificate's DER in `pem`.
pub fn sha256_of_first_cert(pem: &str) -> Option<String> {
    let der = CertificateDer::pem_slice_iter(pem.as_bytes()).next()?.ok()?;
    Some(hex::encode(Sha256::digest(der.as_ref())))
}

/// The CA must match the fingerprint the brain claims and, if configured, the one in `loopi.toml`.
pub fn verify_ca(ca_pem: &str, response_fp: &str, configured: Option<&str>) -> Result<(), PairError> {
    let actual = sha256_of_first_cert(ca_pem).ok_or(PairError::BadCa)?;
    if normalize_fingerprint(response_fp).as_deref() != Some(actual.as_str()) {
        return Err(PairError::CaMismatch { expected: response_fp.into(), actual });
    }
    if let Some(expected) = configured {
        let expected = normalize_fingerprint(expected).ok_or(PairError::BadCa)?;
        if expected != actual {
            return Err(PairError::CaMismatch { expected, actual });
        }
    }
    Ok(())
}

pub async fn ensure_paired(
    config: &Config,
    keys_dir: &Path,
    hw: HwInfo,
    client: &reqwest::Client,
) -> Result<Identity, PairError> {
    if let Some(identity) = load_identity(keys_dir)? {
        return Ok(identity);
    }
    let token = config.brain.pair_token.clone().ok_or(PairError::NoToken)?;
    let (key_pem, csr_pem) = generate_key_and_csr()?;
    let response = pair(client, &config.brain.url, &PairRequest { token, csr_pem, hw_info: hw }).await?;
    verify_ca(&response.ca_cert_pem, &response.ca_fingerprint, config.brain.ca_fingerprint.as_deref())?;
    let identity = Identity {
        device_id: response.device_id,
        key_pem,
        cert_pem: response.cert_pem,
        ca_cert_pem: response.ca_cert_pem,
    };
    save_identity(keys_dir, &identity)?;
    Ok(identity)
}
```

```rust
//! Upload loop: oldest item first; quarantine what the brain will never accept; back off on errors.
use std::io;
use std::sync::Arc;
use std::time::Duration;

use tokio::sync::watch;

use crate::queue::Queue;
use crate::status::StatusTx;
use crate::transport::{PutOutcome, Transport, TransportError};

pub const MAX_BACKOFF: Duration = Duration::from_secs(300);

pub fn backoff_delay(failures: u32) -> Duration {
    let secs = 1u64.checked_shl(failures.min(20)).unwrap_or(u64::MAX);
    Duration::from_secs(secs).min(MAX_BACKOFF)
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum UploadStep {
    Uploaded(String),
    Idle,
    Quarantined(String),
    Blocked(String),
}

pub async fn upload_once(queue: &Queue, transport: &dyn Transport) -> io::Result<UploadStep> {
    let Some(item) = queue.oldest()? else { return Ok(UploadStep::Idle) };
    let id = item.meta.id.clone();
    let quarantine = |reason: &str| -> io::Result<UploadStep> {
        tracing::warn!(id = %id, reason, "quarantining item");
        queue.quarantine(&item.meta, reason)?;
        Ok(UploadStep::Quarantined(id.clone()))
    };
    match transport.put_item(&item.meta, &item.data_path).await {
        Ok(PutOutcome::Created | PutOutcome::Duplicate) => {
            queue.remove(&item.meta)?;
            Ok(UploadStep::Uploaded(id))
        }
        Ok(PutOutcome::Conflict) => quarantine("brain reported a conflicting item with the same id (409)"),
        Ok(PutOutcome::Rejected(code)) => quarantine(&format!("brain rejected the item (HTTP {code})")),
        Err(TransportError::Io(e)) if e.kind() == io::ErrorKind::NotFound => quarantine("payload file missing"),
        Ok(PutOutcome::BrainFull) => Ok(UploadStep::Blocked("brain storage is full".into())),
        Ok(PutOutcome::Unauthorized) => Ok(UploadStep::Blocked("brain rejected the device certificate".into())),
        Ok(PutOutcome::UpgradeRequired) => Ok(UploadStep::Blocked("agent is too old for the brain".into())),
        Err(e) => Ok(UploadStep::Blocked(e.to_string())),
    }
}

pub async fn run_uploader(
    queue: Arc<Queue>,
    transport: Arc<dyn Transport>,
    status: StatusTx,
    mut shutdown: watch::Receiver<bool>,
    idle_poll: Duration,
) {
    let mut failures = 0u32;
    loop {
        if *shutdown.borrow() {
            return;
        }
        let delay = match upload_once(&queue, transport.as_ref()).await {
            Ok(UploadStep::Uploaded(_) | UploadStep::Quarantined(_)) => {
                failures = 0;
                Duration::ZERO
            }
            Ok(UploadStep::Idle) => {
                failures = 0;
                idle_poll
            }
            Ok(UploadStep::Blocked(reason)) => {
                let delay = backoff_delay(failures);
                failures = failures.saturating_add(1);
                tracing::warn!(%reason, retry_in = ?delay, "upload blocked");
                status.send_modify(|s| s.last_error = Some(reason));
                delay
            }
            Err(e) => {
                let delay = backoff_delay(failures);
                failures = failures.saturating_add(1);
                tracing::error!(error = %e, "queue error");
                status.send_modify(|s| s.last_error = Some(format!("queue error: {e}")));
                delay
            }
        };
        if delay.is_zero() {
            tokio::task::yield_now().await;
            continue;
        }
        tokio::select! {
            _ = tokio::time::sleep(delay) => {}
```

```rust
use std::fs;
use std::path::Path;

use crate::wire::{HwInfo, AGENT_VERSION};

const SOC_TEMP_PATH: &str = "/sys/class/thermal/thermal_zone0/temp";
const WIRELESS_PATH: &str = "/proc/net/wireless";
const WIFI_IFACE: &str = "wlan0";
const MAX_FIELD: usize = 100;

pub trait SysProbe: Send + Sync {
    fn soc_temp_c(&self) -> Option<f32>;
    fn wifi_rssi_dbm(&self) -> Option<i32>;
}

    }

pub fn read_soc_temp(path: &Path) -> Option<f32> {
    let millis: f32 = fs::read_to_string(path).ok()?.trim().parse().ok()?;
    Some(millis / 1000.0)
}

/// Signal level (dBm) of `iface` from `/proc/net/wireless` ("wlan0: 0000 54. -56. -256 ...").
pub fn parse_wireless(contents: &str, iface: &str) -> Option<i32> {
    contents.lines().find_map(|line| {
        let rest = line.trim_start().strip_prefix(iface)?.strip_prefix(':')?;
        let level = rest.split_whitespace().nth(2)?;
        level.trim_end_matches('.').parse::<f32>().ok().map(|v| v as i32)
    })
}

pub fn parse_cpu_serial(cpuinfo: &str) -> Option<String> {
    cpuinfo.lines().find_map(|line| {
        let (key, value) = line.split_once(':')?;
        (key.trim() == "Serial").then(|| value.trim().to_string())
    })
}

fn clip(s: &str) -> String {
    s.chars().take(MAX_FIELD).collect()
}

pub fn hw_info() -> HwInfo {
    let model = fs::read_to_string("/proc/device-tree/model")
        .map(|m| m.trim_end_matches('\0').trim().to_string())
        .unwrap_or_else(|_| "unknown".into());
    let serial = fs::read_to_string("/proc/cpuinfo")
        .ok()
        .and_then(|c| parse_cpu_serial(&c))
        .unwrap_or_else(|| "unknown".into());
    HwInfo { model: clip(&model), serial: clip(&serial), agent_version: AGENT_VERSION.into() }
}
```

```rust
//! Heartbeat: report status every 15 s, receive commands, ack them on the next heartbeat.
use std::sync::Arc;
use std::time::{Duration, Instant};

use tokio::sync::{mpsc, watch};

use crate::control::{parse_remote_command, Command, ControlState};
use crate::queue::Queue;
use crate::status::{AgentStatus, StatusTx};
use crate::sysinfo::SysProbe;
use crate::transport::{Transport, TransportError};
use crate::wire::{HeartbeatRequest, RemoteCommand, AGENT_VERSION};

pub const HEARTBEAT_INTERVAL: Duration = Duration::from_secs(15);
const MAX_ERROR_LEN: usize = 500;

pub fn build_request(
    status: &AgentStatus,
    control: &ControlState,
    queue_depth: u64,
    uptime_s: u64,
    probe: &dyn SysProbe,
    acked: Vec<String>,
) -> HeartbeatRequest {
    HeartbeatRequest {
        agent_version: AGENT_VERSION.into(),
        uptime_s,
        soc_temp_c: probe.soc_temp_c(),
        disk_used_pct: status.disk_used_pct.clamp(0.0, 100.0),
        queue_depth,
        wifi_rssi_dbm: probe.wifi_rssi_dbm(),
        clock_synced: status.clock_synced,
        paused: control.paused,
        audio_enabled: control.audio_enabled,
        recording_video: status.recording_video,
        recording_audio: status.recording_audio,
        mic_missing: status.mic_missing,
        camera_failures: status.camera_failures,
        last_error: status.last_error.as_ref().map(|e| e.chars().take(MAX_ERROR_LEN).collect()),
        dropped_items: status.dropped_since_heartbeat,
        acked_command_ids: acked,
    }
}

#[derive(Debug, Default, PartialEq)]
pub struct Translated {
    pub commands: Vec<Command>,
    pub acked: Vec<String>,
    pub errors: Vec<String>,
}

/// Every received command is acked — invalid ones too, so the brain stops re-sending them;
/// the reason is reported through `last_error`.
pub fn translate(remote: Vec<RemoteCommand>) -> Translated {
    let mut out = Translated::default();
    for command in remote {
        match parse_remote_command(&command.kind, &command.payload) {
            Ok(parsed) => out.commands.push(parsed),
            Err(e) => out.errors.push(format!("command {}: {e}", command.id)),
        }
        out.acked.push(command.id);
    }
    out
}

pub struct HeartbeatDeps {
    pub transport: Arc<dyn Transport>,
    pub queue: Arc<Queue>,
    pub status: StatusTx,
    pub control: watch::Receiver<ControlState>,
    pub commands: mpsc::Sender<Command>,
    pub probe: Arc<dyn SysProbe>,
    pub started: Instant,
    pub interval: Duration,
}

/// One heartbeat. On failure the acks and the dropped-item count are kept for the next attempt.
pub async fn heartbeat_once(deps: &HeartbeatDeps, acked: &mut Vec<String>) -> Result<(), TransportError> {
    let request = {
        let status = deps.status.borrow();
        let control = deps.control.borrow();
        let depth = deps.queue.len().unwrap_or(0) as u64;
        build_request(&status, &control, depth, deps.started.elapsed().as_secs(), deps.probe.as_ref(), acked.clone())
    };
    let remote = deps.transport.heartbeat(&request).await?;
    acked.clear();
    let reported = request.dropped_items;
    deps.status.send_modify(|s| s.dropped_since_heartbeat = s.dropped_since_heartbeat.saturating_sub(reported));
    let translated = translate(remote);
    acked.extend(translated.acked);
    if let Some(error) = translated.errors.last() {
        tracing::warn!(%error, "invalid command from brain");
        deps.status.send_modify(|s| s.last_error = Some(error.clone()));
    }
    for command in translated.commands {
        if deps.commands.send(command).await.is_err() {
            break;
        }
    }
    Ok(())
}

pub async fn run_heartbeat(deps: HeartbeatDeps, mut shutdown: watch::Receiver<bool>) {
    let mut acked = Vec::new();
    let mut ticker = tokio::time::interval(deps.interval);
    loop {
        tokio::select! {
            _ = ticker.tick() => {}
            _ = shutdown.changed() => return,
        }
        if let Err(e) = heartbeat_once(&deps, &mut acked).await {
            tracing::warn!(error = %e, "heartbeat failed");
        }
    }
}
```

```rust
const INTRA_SECONDS: u32 = 5;

#[derive(Debug, Clone)]
pub struct VideoOptions {
    pub camera_cmd: String,
    pub width: u32,
    pub height: u32,
    pub fps: u32,
    pub bitrate_bps: u32,

impl VideoOptions {

            width: capture.video_width,
            height: capture.video_height,

/// `--inline` repeats SPS/PPS so every segment decodes on its own; `--intra` keeps I-frames
/// frequent enough that `--segment` can cut close to the requested length.
pub fn rpicam_args(opts: &VideoOptions, run_dir: &Path) -> Vec<String> {
    let mut args: Vec<String> = ["-t", "0", "-n", "--codec", "h264", "--inline"].iter().map(|s| s.to_string()).collect();
    args.extend([
        "--intra".to_string(),
        (opts.fps * INTRA_SECONDS).to_string(),
        "--framerate".to_string(),
        opts.fps.to_string(),
        "--width".to_string(),
        opts.width.to_string(),
        "--height".to_string(),
        opts.height.to_string(),
        "--bitrate".to_string(),
        opts.bitrate_bps.to_string(),
        "--segment".to_string(),
        opts.segment.as_millis().to_string(),
        "-o".to_string(),
        run_dir.join(SEGMENT_PATTERN).to_string_lossy().into_owned(),
    ]);
    args
}

/// A segment starts where the previous one ended. If the wall clock jumped backwards, fall back
/// to `ended - segment` so `ended_at` is never before `started_at`.
pub fn segment_start(previous_end: DateTime<Utc>, ended: DateTime<Utc>, segment: chrono::Duration) -> DateTime<Utc> {
    if ended > previous_end {
        previous_end
    } else {
        ended - segment
    }
}

fn list_segments(dir: &Path) -> io::Result<Vec<PathBuf>> {
    let mut files: Vec<PathBuf> = fs::read_dir(dir)?
        .filter_map(Result::ok)
        .map(|e| e.path())
        .filter(|p| {
            let name = p.file_name().and_then(|n| n.to_str()).unwrap_or_default();
            name.starts_with("v_") && name.ends_with(".h264")
        })
        .collect();
    files.sort();
    Ok(files)
}

fn mtime(path: &Path) -> io::Result<DateTime<Utc>> {
    Ok(fs::metadata(path)?.modified()?.into())
}

fn to_chrono(d: Duration) -> chrono::Duration {
    chrono::Duration::from_std(d).unwrap_or(chrono::Duration::seconds(60))
}

pub struct SegmentCollector {
    run_dir: PathBuf,
    last_end: DateTime<Utc>,
    segment: chrono::Duration,
    fps: u32,
}

impl SegmentCollector {
    pub fn new(run_dir: PathBuf, run_started: DateTime<Utc>, segment: Duration, fps: u32) -> Self {
        Self { run_dir, last_end: run_started, segment: to_chrono(segment), fps }
    }

    /// Queue every closed segment. While rpicam-vid runs the newest file is still being written,
    /// so it is only included once the process has exited (`include_last`).
    pub fn collect(&mut self, queue: &Queue, include_last: bool) -> io::Result<Vec<ItemMeta>> {
        let mut files = list_segments(&self.run_dir)?;
        if !include_last {
            files.pop();
        }
        let mut queued = Vec::with_capacity(files.len());
        for path in files {
            if fs::metadata(&path)?.len() == 0 {
                fs::remove_file(&path)?;
                continue;
            }
            let ended = mtime(&path)?;
            let started = segment_start(self.last_end, ended, self.segment);
            queued.push(queue.enqueue_file(&path, ItemKind::Video, started, ended, Some(self.fps))?);
            self.last_end = ended;
        }
        Ok(queued)
    }
}

/// After a crash or power cut, queue segments left in old run directories.
pub fn recover_incoming(incoming: &Path, queue: &Queue, segment: Duration, fps: u32) -> io::Result<u32> {
    if !incoming.exists() {
        return Ok(0);
    }
    let mut recovered = 0;
    for entry in fs::read_dir(incoming)? {
        let run_dir = entry?.path();
        if !run_dir.is_dir() {
            continue;
        }
        for path in list_segments(&run_dir)? {
            if fs::metadata(&path)?.len() == 0 {
                fs::remove_file(&path)?;
                continue;
            }
            let ended = mtime(&path)?;
            queue.enqueue_file(&path, ItemKind::Video, ended - to_chrono(segment), ended, Some(fps))?;
            recovered += 1;
        }
        let _ = fs::remove_dir(&run_dir);
    }
    Ok(recovered)
}

pub fn camera_backoff(failures: u32, max: Duration) -> Duration {
    Duration::from_secs(1u64 << failures.min(6)).min(max)
}

#[cfg(target_os = "linux")]
fn die_with_parent(command: &mut Command) {
    // SAFETY: prctl(2) is async-signal-safe; this runs in the child between fork and exec.
    unsafe {
        command.pre_exec(|| {
            if libc::prctl(libc::PR_SET_PDEATHSIG, libc::SIGTERM) != 0 {
                return Err(io::Error::last_os_error());
            }
            Ok(())
        });
    }
}

#[cfg(not(target_os = "linux"))]
fn die_with_parent(_command: &mut Command) {}

fn spawn_camera(cmd: &str, args: &[String]) -> io::Result<Child> {
    let mut command = Command::new(cmd);
    command
        .args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::inherit())
        .kill_on_drop(true);
    die_with_parent(&mut command);
    command.spawn()
}

/// SIGINT lets rpicam-vid close its file cleanly; SIGKILL after `grace`.
async fn stop_child(child: &mut Child, grace: Duration) {
    if let Some(pid) = child.id() {
        // SAFETY: kill(2) on our own child process.
        unsafe {
            libc::kill(pid as libc::pid_t, libc::SIGINT);
        }
    }
    if tokio::time::timeout(grace, child.wait()).await.is_err() {
        let _ = child.kill().await;
    }
}

enum RunEnd {
    Stopped,
    Exited { ran_for: Duration, code: Option<i32> },
}

async fn record_once(
    opts: &VideoOptions,
    queue: &Queue,
    clock: &dyn Clock,
    gate: &mut watch::Receiver<bool>,
    status: &StatusTx,
    shutdown: &mut watch::Receiver<bool>,
) -> io::Result<RunEnd> {
    let run_dir = opts.incoming_dir.join(ulid::Ulid::new().to_string());
    fs::create_dir_all(&run_dir)?;
    let mut child = spawn_camera(&opts.camera_cmd, &rpicam_args(opts, &run_dir))?;
    let started = Instant::now();
    status.send_modify(|s| s.recording_video = true);
    let mut collector = SegmentCollector::new(run_dir.clone(), clock.now(), opts.segment, opts.fps);
    let mut ticker = tokio::time::interval(opts.poll);
    let end = loop {
        tokio::select! {
            _ = ticker.tick() => {
                if let Err(e) = collector.collect(queue, false) {
                    tracing::warn!(error = %e, "collecting video segments failed");
                }
            }
            exit = child.wait() => {
                break RunEnd::Exited { ran_for: started.elapsed(), code: exit.ok().and_then(|s| s.code()) };
            }
            changed = gate.changed() => {
                if changed.is_err() || !*gate.borrow() {
                    stop_child(&mut child, opts.stop_grace).await;
                    break RunEnd::Stopped;
                }
            }
            _ = shutdown.changed() => {
                stop_child(&mut child, opts.stop_grace).await;
                break RunEnd::Stopped;
            }
        }
    };
    let collected = collector.collect(queue, true);
    let _ = fs::remove_dir(&run_dir);
    status.send_modify(|s| s.recording_video = false);
    collected?;
    Ok(end)
}

async fn wait_for_gate(gate: &mut watch::Receiver<bool>, shutdown: &mut watch::Receiver<bool>) -> bool {
    loop {
        if *shutdown.borrow() {
            return false;
        }
        if *gate.borrow_and_update() {
            return true;
        }
        tokio::select! {
            changed = gate.changed() => if changed.is_err() { return false; },
            changed = shutdown.changed() => if changed.is_err() { return false; },
        }
    }
}

async fn sleep_or_shutdown(delay: Duration, shutdown: &mut watch::Receiver<bool>) -> bool {
    tokio::select! {
        _ = tokio::time::sleep(delay) => true,
        _ = shutdown.changed() => false,
    }
}

pub async fn run_video(
    opts: VideoOptions,
    queue: Arc<Queue>,
    clock: Arc<dyn Clock>,
    mut gate: watch::Receiver<bool>,
    status: StatusTx,
    mut shutdown: watch::Receiver<bool>,
) {
    let mut failures = 0u32;
    loop {
        if !wait_for_gate(&mut gate, &mut shutdown).await {
            return;
        }
        let message = match record_once(&opts, &queue, clock.as_ref(), &mut gate, &status, &mut shutdown).await {
            Ok(RunEnd::Stopped) => {
                failures = 0;
                status.send_modify(|s| s.camera_failures = 0);
                continue;
            }
            Ok(RunEnd::Exited { ran_for, code }) => {
                failures = if ran_for >= opts.healthy_run { 1 } else { failures.saturating_add(1) };
                format!("rpicam-vid exited with {code:?} after {} s", ran_for.as_secs())
            }
            Err(e) => {
                failures = failures.saturating_add(1);
                format!("video recorder: {e}")
            }
        };
        tracing::warn!(%message, failures, "camera problem");
        status.send_modify(|s| {
            s.camera_failures = failures;
            s.last_error = Some(message);
        });
        if !sleep_or_shutdown(camera_backoff(failures, opts.max_backoff), &mut shutdown).await {
            return;
        }
    }
}
```

```rust
/// 440 Hz tone. `stepping` advances a ManualClock by 20 ms per frame and fails after `frames`
/// (simulating an unplugged mic); `realtime` sleeps 20 ms per frame and never fails.
pub struct ToneSource {
    frames_left: Option<u64>,

    realtime: bool,
    sample: u64,
}

    pub fn stepping(clock: Arc<ManualClock>, frames: u64) -> Self {
        Self { frames_left: Some(frames), step_clock: Some(clock), realtime: false, sample: 0 }
    }

    pub fn realtime() -> Self {
        Self { frames_left: None, step_clock: None, realtime: true, sample: 0 }
    }
}

impl AudioSource for ToneSource {
    fn read_frame(&mut self, frame: &mut [i16; FRAME_SAMPLES]) -> io::Result<()> {
        if let Some(left) = self.frames_left.as_mut() {
            if *left == 0 {
                return Err(io::Error::new(io::ErrorKind::BrokenPipe, "microphone unplugged"));
            }
            *left -= 1;
        }
        for value in frame.iter_mut() {
            let t = self.sample as f32 / SAMPLE_RATE as f32;
            *value = ((t * 440.0 * std::f32::consts::TAU).sin() * 8000.0) as i16;
            self.sample += 1;
        }
        if let Some(clock) = &self.step_clock {
            clock.advance(chrono::Duration::milliseconds(20));
        }
        if self.realtime {
            std::thread::sleep(std::time::Duration::from_millis(20));
        }
        Ok(())
    }
}
```

```rust
//! Minimal Ogg Opus writer (RFC 7845) for 16 kHz mono speech.
use std::io::Write;

use ogg::writing::{PacketWriteEndInfo, PacketWriter};
use opus::{Application, Bitrate, Channels, Encoder};

pub const SAMPLE_RATE: u32 = 16_000;
/// 20 ms at 16 kHz.
pub const FRAME_SAMPLES: usize = 320;
/// Ogg Opus granule positions always count 48 kHz samples.
pub const GRANULE_PER_FRAME: u64 = 960;
/// libopus look-ahead (2.5 ms + 4 ms delay compensation) expressed at 48 kHz.
pub const PRE_SKIP: u16 = 312;
pub const BITRATE_BPS: i32 = 24_000;
const MAX_PACKET: usize = 1500;

#[derive(Debug, thiserror::Error)]
pub enum OggOpusError {
    #[error("opus: {0}")]
    Opus(#[from] opus::Error),
    #[error("io: {0}")]
    Io(#[from] std::io::Error),
    #[error("a frame must have {FRAME_SAMPLES} samples, got {0}")]
    FrameSize(usize),
}

pub struct OggOpusWriter<W: Write> {
    writer: PacketWriter<'static, W>,
    encoder: Encoder,
    serial: u32,
    granule: u64,
    pending: Option<Vec<u8>>,
    frames: u64,
}

fn opus_head() -> Vec<u8> {
    let mut head = Vec::with_capacity(19);
    head.extend_from_slice(b"OpusHead");
    head.push(1); // version
    head.push(1); // channels
    head.extend_from_slice(&PRE_SKIP.to_le_bytes());
    head.extend_from_slice(&SAMPLE_RATE.to_le_bytes());
    head.extend_from_slice(&0i16.to_le_bytes()); // output gain
    head.push(0); // channel mapping family
    head
}

fn opus_tags() -> Vec<u8> {
    let vendor = b"loopi-agent";
    let mut tags = Vec::with_capacity(8 + 4 + vendor.len() + 4);
    tags.extend_from_slice(b"OpusTags");
    tags.extend_from_slice(&(vendor.len() as u32).to_le_bytes());
    tags.extend_from_slice(vendor);
    tags.extend_from_slice(&0u32.to_le_bytes()); // no user comments
    tags
}

impl<W: Write> OggOpusWriter<W> {
    pub fn new(out: W, serial: u32) -> Result<Self, OggOpusError> {
        let mut encoder = Encoder::new(SAMPLE_RATE, Channels::Mono, Application::Voip)?;
        encoder.set_bitrate(Bitrate::Bits(BITRATE_BPS))?;
        let mut writer = PacketWriter::new(out);
        writer.write_packet(opus_head(), serial, PacketWriteEndInfo::EndPage, 0)?;
        writer.write_packet(opus_tags(), serial, PacketWriteEndInfo::EndPage, 0)?;
        Ok(Self { writer, encoder, serial, granule: 0, pending: None, frames: 0 })
    }

    /// Encode one 20 ms frame. Packets are written one frame late so the final one can carry
    /// the end-of-stream flag.
    pub fn write_frame(&mut self, pcm: &[i16]) -> Result<(), OggOpusError> {
        if pcm.len() != FRAME_SAMPLES {
            return Err(OggOpusError::FrameSize(pcm.len()));
        }
        let mut buf = [0u8; MAX_PACKET];
        let len = self.encoder.encode(pcm, &mut buf)?;
        if let Some(previous) = self.pending.replace(buf[..len].to_vec()) {
            self.granule += GRANULE_PER_FRAME;
            self.writer.write_packet(previous, self.serial, PacketWriteEndInfo::NormalPacket, self.granule)?;
        }
        self.frames += 1;
        Ok(())
    }

    pub fn frames(&self) -> u64 {
        self.frames
    }

    pub fn finish(mut self) -> Result<W, OggOpusError> {
        let last = self.pending.take().unwrap_or_default();
        if !last.is_empty() {
            self.granule += GRANULE_PER_FRAME;
        }
        self.writer.write_packet(last, self.serial, PacketWriteEndInfo::EndStream, self.granule)?;
        Ok(self.writer.into_inner())
    }
}
```

```rust
const PART_SUFFIX: &str = ".opus.part";

pub trait AudioSource: Send {

}

/// First USB audio card in `/proc/asound/cards` (" 1 [Device ]: USB-Audio - ...").
pub fn parse_usb_card(cards: &str) -> Option<u32> {
    cards
        .lines()
        .filter(|line| line.contains("USB-Audio"))
        .find_map(|line| line.split_whitespace().next()?.parse().ok())
}

/// `plughw` lets ALSA convert rate/channels when the mic does not support 16 kHz mono natively.
pub fn resolve_device(configured: &str, proc_cards: &str) -> Option<String> {
    if configured != "auto" {
        return Some(configured.to_string());
    }
    parse_usb_card(proc_cards).map(|card| format!("plughw:{card},0"))
}

/// Next multiple of `segment` (since the Unix epoch) strictly after `t`.
pub fn next_boundary(t: DateTime<Utc>, segment: Duration) -> DateTime<Utc> {
    let seconds = segment.as_secs().max(1) as i64;
    let next = (t.timestamp().div_euclid(seconds) + 1) * seconds;
    DateTime::from_timestamp(next, 0).expect("timestamp in range")
}

/// Queue `.opus.part` files left by a crash; they lack the end-of-stream page but still decode.
pub fn recover_incoming(dir: &Path, queue: &Queue, segment: Duration) -> io::Result<u32> {
    if !dir.exists() {
        return Ok(0);
    }
    let mut recovered = 0;
    for entry in fs::read_dir(dir)? {
        let path = entry?.path();
        let is_part = path.file_name().and_then(|n| n.to_str()).is_some_and(|n| n.ends_with(PART_SUFFIX));
        if !is_part {
            continue;
        }
        if fs::metadata(&path)?.len() == 0 {
            fs::remove_file(&path)?;
            continue;
        }
        let ended: DateTime<Utc> = fs::metadata(&path)?.modified()?.into();
        let started = ended - chrono::Duration::from_std(segment).unwrap_or(chrono::Duration::seconds(60));
        queue.enqueue_file(&path, ItemKind::Audio, started, ended, None)?;
        recovered += 1;
    }
    Ok(recovered)
}

/// Record consecutive segments until the gate closes, shutdown, or a read error (returned
/// after the current partial segment has been queued).
fn record_segments(
    source: &mut dyn AudioSource,
    opts: &AudioOptions,
    queue: &Queue,
    clock: &dyn Clock,
    gate: &watch::Receiver<bool>,
    shutdown: &watch::Receiver<bool>,
) -> io::Result<()> {
    fs::create_dir_all(&opts.incoming_dir)?;
    let mut frame = [0i16; FRAME_SAMPLES];
    loop {
        let started = clock.now();
        let boundary = next_boundary(started, opts.segment);
        let part = opts.incoming_dir.join(format!("{}{PART_SUFFIX}", ulid::Ulid::new()));
        let serial = (ulid::Ulid::new().random() & 0xffff_ffff) as u32;
        let mut writer = OggOpusWriter::new(BufWriter::new(File::create(&part)?), serial).map_err(io::Error::other)?;
        let (stop, read_result) = loop {
            if *shutdown.borrow() || !*gate.borrow() {
                break (true, Ok(()));
            }
            if let Err(e) = source.read_frame(&mut frame) {
                break (true, Err(e));
            }
            writer.write_frame(&frame).map_err(io::Error::other)?;
            if clock.now() >= boundary {
                break (false, Ok(()));
            }
        };
        let frames = writer.frames();
        let mut out = writer.finish().map_err(io::Error::other)?;
        out.flush()?;
        out.get_ref().sync_all()?;
        drop(out);
        if frames > 0 {
            let ended = clock.now().max(started);
            queue.enqueue_file(&part, ItemKind::Audio, started, ended, None)?;
        } else {
            fs::remove_file(&part)?;
        }
        read_result?;
        if stop {
            return Ok(());
        }
    }
}

fn report_mic_error(status: &StatusTx, error: &io::Error) {
    tracing::warn!(%error, "microphone unavailable");
    status.send_modify(|s| {
        s.mic_missing = true;
        s.last_error = Some(format!("microphone: {error}"));
    });
}

fn sleep_unless_shutdown(total: Duration, shutdown: &watch::Receiver<bool>) {
    let mut waited = Duration::ZERO;
    while waited < total && !*shutdown.borrow() {
        std::thread::sleep(SHUTDOWN_POLL.min(total - waited));
        waited += SHUTDOWN_POLL;
    }
}

/// Blocking loop for a dedicated thread. `recording_audio` is raised *before* the device is
/// opened so the LED is never off while the microphone could be capturing.
pub fn run_audio_blocking(
    factory: AudioSourceFactory,
    opts: AudioOptions,
    queue: Arc<Queue>,
    clock: Arc<dyn Clock>,
    gate: watch::Receiver<bool>,
    status: StatusTx,
    shutdown: watch::Receiver<bool>,
) {
    loop {
        if *shutdown.borrow() {
            return;
        }
        if !*gate.borrow() {
            std::thread::sleep(GATE_POLL);
            continue;
        }
        status.send_modify(|s| s.recording_audio = true);
        let result = match factory() {
            Ok(mut source) => {
                status.send_modify(|s| s.mic_missing = false);
                record_segments(source.as_mut(), &opts, &queue, clock.as_ref(), &gate, &shutdown)
            }
            Err(e) => Err(e),
        };
        status.send_modify(|s| s.recording_audio = false);
        if let Err(e) = result {
            report_mic_error(&status, &e);
            sleep_unless_shutdown(opts.retry, &shutdown);
        }
    }
}

pub mod alsa_source {
    //! ALSA capture from the USB microphone.
    use std::io;

    use alsa::pcm::{Access, Format, HwParams, PCM};
    use alsa::{Direction, ValueOr};

    use super::{resolve_device, AudioSource, AudioSourceFactory};
    use crate::recorder::ogg_opus::{FRAME_SAMPLES, SAMPLE_RATE};

    fn to_io(e: alsa::Error) -> io::Error {
        io::Error::other(e)
    }

    pub struct AlsaSource {
        pcm: PCM,
    }

    impl AlsaSource {
        pub fn open(device: &str) -> io::Result<Self> {
            let pcm = PCM::new(device, Direction::Capture, false).map_err(to_io)?;
            {
                let hw = HwParams::any(&pcm).map_err(to_io)?;
                hw.set_channels(1).map_err(to_io)?;
                hw.set_rate(SAMPLE_RATE, ValueOr::Nearest).map_err(to_io)?;
                hw.set_format(Format::s16()).map_err(to_io)?;
                hw.set_access(Access::RWInterleaved).map_err(to_io)?;
                pcm.hw_params(&hw).map_err(to_io)?;
            }
            pcm.prepare().map_err(to_io)?;
            Ok(Self { pcm })
        }
    }

    impl AudioSource for AlsaSource {
        fn read_frame(&mut self, frame: &mut [i16; FRAME_SAMPLES]) -> io::Result<()> {
            let io = self.pcm.io_i16().map_err(to_io)?;
            let mut filled = 0;
            while filled < FRAME_SAMPLES {
                match io.readi(&mut frame[filled..]) {
                    Ok(n) => filled += n,
                    // Overrun (EPIPE): recover and keep going; anything else means the mic is gone.
                    Err(e) if e.errno() == libc::EPIPE => self.pcm.try_recover(e, true).map_err(to_io)?,
                    Err(e) => return Err(to_io(e)),
                }
            }
            Ok(())
        }
    }

    pub fn factory(device_config: String) -> AudioSourceFactory {
        Box::new(move || {
            let cards = std::fs::read_to_string("/proc/asound/cards").unwrap_or_default();
            let device = resolve_device(&device_config, &cards)
                .ok_or_else(|| io::Error::new(io::ErrorKind::NotFound, "no USB microphone found"))?;
            Ok(Box::new(AlsaSource::open(&device)?) as Box<dyn AudioSource>)
        })
    }
}
```

```rust
    pub probe: Arc<dyn SysProbe>,
    pub timings: Timings,
}

fn set_if_changed(slot: &mut bool, value: bool) -> bool {
    let changed = *slot != value;
    *slot = value;
    changed
}

fn apply_command(control: &watch::Sender<ControlState>, state_path: &Path, command: &Command) {
    let next = control.borrow().apply(command);
    if let Err(e) = control::save_state(state_path, &next) {
        tracing::error!(error = %e, "could not persist control state");
    }
    control.send_replace(next);
    tracing::info!(?command, ?next, "control state changed");
}

fn handle_press(press: Press, queue: &Queue, clock: &dyn Clock, control: &watch::Sender<ControlState>, state_path: &Path) {
    match press {
        Press::Short => {
            let now = clock.now();
            if let Err(e) = queue.enqueue_bytes(b"{}", ItemKind::Marker, now, now) {
                tracing::error!(error = %e, "could not queue marker");
            }
        }
        Press::Long => apply_command(control, state_path, &Command::TogglePause),
    }
}

fn check_disk(queue: &Queue, disk: &dyn DiskUsage, status: &StatusTx) {
    match disk::enforce(queue, disk) {
        Ok(report) => status.send_modify(|s| {
            s.disk_used_pct = report.used_pct;
            s.disk_stopped = report.stop;
            s.dropped_since_heartbeat += report.dropped;
        }),
        Err(e) => status.send_modify(|s| s.last_error = Some(format!("disk check: {e}"))),
    }
}

async fn led_loop(
    mut led: Box<dyn LedDriver>,
    status: watch::Receiver<AgentStatus>,
    control: watch::Receiver<ControlState>,
    frame: Duration,
    mut shutdown: watch::Receiver<bool>,
) {
    let start = Instant::now();
    let mut ticker = tokio::time::interval(frame);
    let mut last = None;
    loop {
        tokio::select! {
            _ = ticker.tick() => {}
            _ = shutdown.changed() => break,
        }
        let pattern = led_pattern(&status.borrow(), &control.borrow());
        let on = level_at(pattern, start.elapsed().as_millis() as u64);
        if last != Some(on) {
            if let Err(e) = led.set(on) {
                tracing::warn!(error = %e, "LED write failed");
            }
            last = Some(on);
        }
    }
    // Privacy invariant: keep the LED on until both recorders have really stopped.
    let deadline = Instant::now() + LED_SHUTDOWN_WAIT;
    while Instant::now() < deadline {
        let recording = {
            let s = status.borrow();
            s.recording_video || s.recording_audio
        };
        if !recording {
            break;
        }
        let _ = led.set(true);
        tokio::time::sleep(frame).await;
    }
    let _ = led.set(false);
}

pub async fn run(deps: Deps, mut shutdown: watch::Receiver<bool>) -> anyhow::Result<()> {
    let Deps { config, clock, disk, transport, audio_factory, led, mut presses, probe, timings } = deps;
    let paths = Paths::new(&config.paths.data_dir);
    let segment = Duration::from_secs(config.capture.segment_seconds.into());

    let (queue, dropped) = Queue::open(&paths.queue).context("opening the upload queue")?;
    let recovered = video::recover_incoming(&paths.video_incoming, &queue, segment, config.capture.video_fps)?
        + audio::recover_incoming(&paths.audio_incoming, &queue, segment)?;
    tracing::info!(recovered, dropped, "queue ready");
    let queue = Arc::new(queue);
    let schedule = Schedule::from_config(&config.schedule).map_err(anyhow::Error::msg)?;

    let (control_tx, control_rx) = watch::channel(control::load_state(&paths.state, config.capture.audio_enabled));
    let status = status_channel(AgentStatus {
        paired: true,
        clock_synced: clock.is_synced(),
        quiet: schedule.is_quiet(clock.now()),
        dropped_since_heartbeat: dropped,
        ..AgentStatus::default()
    });
    let (video_gate_tx, video_gate_rx) = watch::channel(false);
    let (audio_gate_tx, audio_gate_rx) = watch::channel(false);
    let (command_tx, mut command_rx) = mpsc::channel::<Command>(32);

    let mut tasks = JoinSet::new();
    tasks.spawn(run_uploader(queue.clone(), transport.clone(), status.clone(), shutdown.clone(), timings.upload_idle));
    tasks.spawn(run_heartbeat(
        HeartbeatDeps {
            transport,
            queue: queue.clone(),
            status: status.clone(),
            control: control_rx.clone(),
            commands: command_tx,
            probe,
            started: std::time::Instant::now(),
            interval: timings.heartbeat,
        },
        shutdown.clone(),
    ));
    let video_opts = VideoOptions { poll: timings.video_poll, ..VideoOptions::from_config(&config.capture, paths.video_incoming.clone()) };
    tasks.spawn(video::run_video(video_opts, queue.clone(), clock.clone(), video_gate_rx, status.clone(), shutdown.clone()));
    tasks.spawn(led_loop(led, status.subscribe(), control_rx.clone(), timings.led_frame, shutdown.clone()));

    let audio_opts = AudioOptions {
        segment: timings.audio_segment.unwrap_or(segment),
        incoming_dir: paths.audio_incoming.clone(),
        retry: timings.audio_retry,
    };
    let audio_thread = {
        let (queue, clock, status, shutdown) = (queue.clone(), clock.clone(), status.clone(), shutdown.clone());
        std::thread::Builder::new()
            .name("audio".into())
            .spawn(move || audio::run_audio_blocking(audio_factory, audio_opts, queue, clock, audio_gate_rx, status, shutdown))?
    };

    let mut tick = tokio::time::interval(timings.tick);
    let mut disk_tick = tokio::time::interval(timings.disk_check);
    loop {
        let gates = recording_gates(&control_tx.borrow(), &status.borrow());
        video_gate_tx.send_if_modified(|g| set_if_changed(g, gates.video));
        audio_gate_tx.send_if_modified(|g| set_if_changed(g, gates.audio));
        tokio::select! {
            Some(command) = command_rx.recv() => apply_command(&control_tx, &paths.state, &command),
            Some(press) = presses.recv() => handle_press(press, &queue, clock.as_ref(), &control_tx, &paths.state),
            _ = tick.tick() => {
                let (synced, quiet) = (clock.is_synced(), schedule.is_quiet(clock.now()));
                status.send_if_modified(|s| set_if_changed(&mut s.clock_synced, synced) | set_if_changed(&mut s.quiet, quiet));
            }
            _ = disk_tick.tick() => check_disk(&queue, disk.as_ref(), &status),
            _ = shutdown.changed() => break,
        }
    }

    video_gate_tx.send_replace(false);
    audio_gate_tx.send_replace(false);
    while tasks.join_next().await.is_some() {}
    tokio::task::spawn_blocking(move || audio_thread.join())
        .await?
        .map_err(|_| anyhow::anyhow!("audio thread panicked"))?;
    Ok(())
}
```

```rust
//! `loopi-agent selftest`: quick on-device checks printed as a report.
use std::path::Path;
use std::time::Duration;

use crate::config::Config;
use crate::disk::{DiskUsage, StatvfsUsage};
use crate::pairing::load_identity;

const CAMERA_TIMEOUT: Duration = Duration::from_secs(20);
const SILENCE_DBFS: f32 = -120.0;

#[derive(Debug, Clone, PartialEq)]
pub struct Check {
    pub name: &'static str,
    pub ok: bool,
    pub detail: String,
}

impl Check {
    pub fn pass(name: &'static str, detail: impl Into<String>) -> Self {
        Self { name, ok: true, detail: detail.into() }
    }

    pub fn fail(name: &'static str, detail: impl Into<String>) -> Self {
        Self { name, ok: false, detail: detail.into() }
    }
}

pub fn format_report(checks: &[Check]) -> String {
    let mut out = String::new();
    for check in checks {
        let tag = if check.ok { "[ OK ]" } else { "[FAIL]" };
        out.push_str(&format!("{tag} {}: {}\n", check.name, check.detail));
    }
    let passed = checks.iter().filter(|c| c.ok).count();
    out.push_str(&format!("{passed}/{} checks passed\n", checks.len()));
    out
}

/// First sensor line of `rpicam-vid --list-cameras`, e.g. "0 : ov5647 [2592x1944 ...] (...)".
pub fn parse_camera_list(output: &str) -> Option<String> {
    if !output.contains("Available cameras") {
        return None;
    }
    output
        .lines()
        .map(str::trim)
        .find(|line| line.starts_with(|c: char| c.is_ascii_digit()) && line.contains(" : "))
        .map(str::to_string)
}

pub fn rms_dbfs(samples: &[i16]) -> f32 {
    if samples.is_empty() {
        return SILENCE_DBFS;
    }
    let mean_square = samples.iter().map(|&s| (s as f64).powi(2)).sum::<f64>() / samples.len() as f64;
    if mean_square == 0.0 {
        return SILENCE_DBFS;
    }
    (20.0 * (mean_square.sqrt() / 32768.0).log10()) as f32
}

async fn camera_check(camera_cmd: &str) -> Check {
    let run = tokio::process::Command::new(camera_cmd).arg("--list-cameras").output();
    match tokio::time::timeout(CAMERA_TIMEOUT, run).await {
        Ok(Ok(output)) => {
            let text = format!("{}{}", String::from_utf8_lossy(&output.stdout), String::from_utf8_lossy(&output.stderr));
            match parse_camera_list(&text) {
                Some(sensor) => Check::pass("camera", sensor),
                None => Check::fail("camera", text.lines().last().unwrap_or("no output").to_string()),
            }
        }
        Ok(Err(e)) => Check::fail("camera", format!("cannot run {camera_cmd}: {e}")),
        Err(_) => Check::fail("camera", "timed out listing cameras"),
    }
}

#[cfg(target_os = "linux")]
fn mic_check(device: &str) -> Check {
    use crate::recorder::audio::alsa_source::factory;
    use crate::recorder::ogg_opus::FRAME_SAMPLES;

    let mut source = match factory(device.to_string())() {
        Ok(source) => source,
        Err(e) => return Check::fail("microphone", e.to_string()),
    };
    let mut frame = [0i16; FRAME_SAMPLES];
    let mut samples = Vec::with_capacity(FRAME_SAMPLES * 50);
    for _ in 0..50 {
        if let Err(e) = source.read_frame(&mut frame) {
            return Check::fail("microphone", e.to_string());
        }
        samples.extend_from_slice(&frame);
    }
    Check::pass("microphone", format!("1 s captured, level {:.1} dBFS", rms_dbfs(&samples)))
}

#[cfg(not(target_os = "linux"))]
fn mic_check(_device: &str) -> Check {
    Check::fail("microphone", "audio capture needs Linux/ALSA")
}

pub async fn run_selftest(config_path: &Path) -> Vec<Check> {
    let config = match Config::load(config_path) {
        Ok(config) => config,
        Err(e) => return vec![Check::fail("config", e.to_string())],
    };
    let data = &config.paths.data_dir;
    let mut checks = vec![Check::pass("config", config_path.display().to_string())];
    checks.push(match load_identity(&data.join("keys")) {
        Ok(Some(identity)) => Check::pass("pairing", format!("device {}", identity.device_id)),
        Ok(None) => Check::fail("pairing", "not paired yet"),
        Err(e) => Check::fail("pairing", e.to_string()),
    });
    checks.push(if config.paths.sync_flag.exists() {
        Check::pass("clock", "NTP synchronised")
    } else {
        Check::fail("clock", "waiting for NTP")
    });
    checks.push(camera_check(&config.capture.camera_cmd).await);
    checks.push(mic_check(&config.capture.audio_device));
    checks.push(match StatvfsUsage::new(data).and_then(|d| d.used_pct()) {
        Ok(pct) => Check { name: "disk", ok: pct < 85.0, detail: format!("{pct:.1}% used") },
        Err(e) => Check::fail("disk", e.to_string()),
    });
    checks
}
```

```rust
//! `loopi-agent run | provision | selftest` — wires real hardware into the library.
use std::path::{Path, PathBuf};
use std::process::ExitCode;
use std::sync::Arc;
use std::time::Duration;

use anyhow::{bail, Context, Result};
use loopi_agent::clock::SystemClock;
use loopi_agent::config::{import_boot_config, Config};
use loopi_agent::disk::StatvfsUsage;
use loopi_agent::led::{blink_while, LedDriver, NoopLed};
use loopi_agent::pairing::{ensure_paired, Identity, PairError};
use loopi_agent::recorder::audio::AudioSourceFactory;
use loopi_agent::run::{run, Deps, Timings};
use loopi_agent::selftest::{format_report, run_selftest};
use loopi_agent::sysinfo::{hw_info, LinuxProbe};
use loopi_agent::transport::{build_client, HttpTransport, Transport};
use loopi_agent::{button::Press, tls};
use tokio::sync::{mpsc, watch};

const DATA_CONFIG: &str = "/data/config/loopi.toml";
const PAIR_RETRY: Duration = Duration::from_secs(30);
const PAIR_RETRY_CONFIG_ERROR: Duration = Duration::from_secs(120);
const WATCHDOG_PING: Duration = Duration::from_secs(10);

fn main() -> ExitCode {
    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::try_from_default_env().unwrap_or_else(|_| "info".into()))
        .without_time() // journald adds timestamps
        .init();
    let args: Vec<String> = std::env::args().skip(1).collect();
    let result = match args.first().map(String::as_str) {
        None | Some("run") => runtime().and_then(|rt| rt.block_on(agent_main())),
        Some("provision") => provision(&args[1..]),
        Some("selftest") => runtime().map(|rt| {
            let checks = rt.block_on(run_selftest(Path::new(DATA_CONFIG)));
            print!("{}", format_report(&checks));
        }),
        Some(other) => Err(anyhow::anyhow!("unknown command {other:?}; use run | provision | selftest")),
    };
    match result {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            tracing::error!("{e:#}");
            ExitCode::FAILURE
        }
    }
}

fn runtime() -> Result<tokio::runtime::Runtime> {
    Ok(tokio::runtime::Builder::new_current_thread().enable_all().build()?)
}

fn provision(args: &[String]) -> Result<()> {
    let (mut boot, mut data) = (PathBuf::from("/boot/loopi.toml"), PathBuf::from("/data"));
    let mut it = args.iter();
    while let Some(flag) = it.next() {
        let value = it.next().with_context(|| format!("{flag} needs a value"))?;
        match flag.as_str() {
            "--boot" => boot = value.into(),
            "--data" => data = value.into(),
            _ => bail!("unknown flag {flag}"),
        }
    }
    let outcome = import_boot_config(&boot, &data)?;
    println!("{outcome:?}");
    Ok(())
}

async fn pair_until_done(config: &Config, keys: &Path, mut shutdown: watch::Receiver<bool>) -> Result<Identity> {
    let client = build_client(tls::pairing_config()?)?;
    loop {
        let delay = match ensure_paired(config, keys, hw_info(), &client).await {
            Ok(identity) => return Ok(identity),
            Err(e @ (PairError::NoToken | PairError::CaMismatch { .. } | PairError::BadCa)) => {
                tracing::error!(error = %e, "pairing needs a fix in loopi.toml");
                PAIR_RETRY_CONFIG_ERROR
            }
            Err(e) => {
                tracing::warn!(error = %e, "pairing failed, will retry");
                PAIR_RETRY
            }
        };
        tokio::select! {
            _ = tokio::time::sleep(delay) => {}
            _ = shutdown.changed() => bail!("shutdown before pairing completed"),
        }
    }
}

async fn agent_main() -> Result<()> {
    let config = Config::load(Path::new(DATA_CONFIG)).context("loading /data/config/loopi.toml")?;
    let (shutdown_tx, shutdown_rx) = watch::channel(false);
    tokio::spawn(async move {
        let mut term = tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate()).expect("SIGTERM handler");
        tokio::select! {
            _ = term.recv() => {}
            _ = tokio::signal::ctrl_c() => {}
        }
        let _ = shutdown_tx.send(true);
    });
    spawn_watchdog();

    let mut led = open_led(&config);
    let keys = config.paths.data_dir.join("keys");
    let identity = blink_while(led.as_mut(), pair_until_done(&config, &keys, shutdown_rx.clone())).await?;
    tracing::info!(device_id = %identity.device_id, "paired");

    let tls = tls::mtls_config(&identity.ca_cert_pem, &identity.cert_pem, &identity.key_pem)?;
    let transport: Arc<dyn Transport> = Arc::new(HttpTransport::new(build_client(tls)?, &config.brain.url));
    let deps = Deps {
        clock: Arc::new(SystemClock::new(config.paths.sync_flag.clone())),
        disk: Arc::new(StatvfsUsage::new(&config.paths.data_dir)?),
        transport,
        audio_factory: audio_factory(&config),
        led,
        presses: open_button(&config),
        probe: Arc::new(LinuxProbe),
        timings: Timings::default(),
        config,
    };
    run(deps, shutdown_rx).await
}
```
