# P4a — Prod image and OTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signed A/B over-the-air updates for the Pi Zero W (RAUC + firmware tryboot, automatic rollback), a prod image without SSH, and the brain side that offers bundles, starts updates per device and shows versions with release notes.

**Architecture:** The boot FAT holds one directory per slot (`a/`, `b/`); `config.txt` boots the good slot through `os_prefix=`, `tryboot.txt` boots the slot under trial on a `"0 tryboot"` reboot, so every other reboot falls back. RAUC (CLI, no D-Bus service) writes the other rootfs slot through a custom bootloader backend (`loopi-boot`, POSIX sh). The agent gets an `update` command through the heartbeat, downloads the bundle over mTLS with `Range` resume, installs, reboots into the trial and confirms it after its first heartbeat; a systemd timer reboots an unconfirmed trial after 10 minutes. The brain serves bundles from `LOOPI_OTA_DIR`, records each update in `ota_update`, and adds update controls to Thiết bị and a new Phiên bản page.

**Tech Stack:** Rust agent (tokio current_thread, reqwest + rustls/ring, serde), Python 3.13 brain (FastAPI/Starlette 1.8, psycopg 3, Jinja + HTMX, pytest + testcontainers), Buildroot 2026.02 (RAUC 1.15.1, host-rauc), POSIX sh on the device, bash + jq on the build host.

**Spec:** `docs/superpowers/specs/2026-10-18-p4a-prod-ota-design.md` (D26–D29), binding spec `docs/superpowers/specs/2026-10-14-loopi-design.md` §6.3, §6.5, §6.7, §7, §8, §10.6, §12, §14 (P4 row).

## Review Focus

- An update command the brain gave up on (device offline for more than 30 minutes) must never reach the device later and start an install: expiry deletes the unacked command (Task 3, `test_expired_update_is_never_delivered`).
- Two clicks on "Cập nhật" (two tabs) must produce exactly one unfinished update per device, never two commands (Task 3, `test_concurrent_requests_make_one_update`).
- A malformed `/etc/loopi-release` or kernel command line must never make the brain reject every heartbeat (422): the agent drops values the contract would refuse (Task 5, `os_info_drops_values_the_contract_refuses`).
- Confirming a trial must never write `config.txt` from nothing: `set-state <slot> good` without a `tryboot.txt` for that slot fails and leaves `config.txt` untouched, and only the booted slot is ever promoted (Task 8, cases "confirm without tryboot" and "good for a slot that is not booted").
- Release notes are git commit subjects shown on the web: a subject with markup is escaped (Task 4, `test_release_notes_are_escaped`).

```python
# Update bundles (P4a design §7; contract BundleName, OsVersion, UpdateCommand).

SHA256_RE = re.compile(r"^[0-9a-f]{64}$")
MAX_BUNDLE_BYTES = 256 * 1024**2
UPDATE_KEYS = ("bundle", "version", "variant", "sha256", "size")
```

```python
def _validate_update(payload: dict) -> None:
    if sorted(payload) != sorted(UPDATE_KEYS):
        raise ValueError(f"update needs exactly {', '.join(UPDATE_KEYS)}")
    bundle, version, variant, sha256, size = (payload[key] for key in UPDATE_KEYS)
    if not (isinstance(bundle, str) and BUNDLE_RE.fullmatch(bundle)):
        raise ValueError("update bundle is not a Loopi bundle name")
    if not (isinstance(version, str) and VERSION_RE.fullmatch(version)):
        raise ValueError("update version is malformed")
    if variant not in ("dev", "prod") or bundle != f"loopi-{variant}-{version}.raucb":
        raise ValueError("update variant and version must match the bundle name")
    if not (isinstance(sha256, str) and SHA256_RE.fullmatch(sha256)):
        raise ValueError("update sha256 must be 64 lowercase hex digits")
    if type(size) is not int or not 1 <= size <= MAX_BUNDLE_BYTES:
        raise ValueError(f"update size must be an integer from 1 to {MAX_BUNDLE_BYTES}")


def validate_command(type_: str, payload: dict) -> None:
    if type_ not in COMMAND_TYPES:
        raise ValueError(f"unknown command type {type_!r}")
    if type_ == "update":
        _validate_update(payload)
        return
    if type_ != "set_config":
        if payload:
            raise ValueError(f"{type_} takes no payload")
        return
    if not payload:
        raise ValueError("set_config needs at least one key")
    for key, value in payload.items():
        expected = SET_CONFIG_KEYS.get(key)
        if expected is None:
            raise ValueError(f"set_config key {key!r} is not allowed")
        if not isinstance(value, expected):
            raise ValueError(f"set_config key {key!r} must be {expected.__name__}")
```

Note: the variant check `bundle != f"loopi-{variant}-{version}.raucb"` also refuses `{"variant": "dev"}` with a prod bundle name; the error message mentions "variant" (the server-only test matches on it).

```python
"""The OTA bundle catalog (P4a design §8, §8.1, spec D29): signed RAUC bundles in LOOPI_OTA_DIR, each beside the JSON
description the build and os/scripts/publish-bundle.sh wrote. The brain never opens a bundle (the device's RAUC checks
its signature); it offers one only while the file on disk agrees with its description (name, size)."""
from __future__ import annotations

import datetime as dt
import json
import logging
import re
from dataclasses import dataclass
from pathlib import Path

from .devices import BUNDLE_RE, MAX_BUNDLE_BYTES, SHA256_RE, VERSION_RE

log = logging.getLogger(__name__)
STEM_RE = re.compile(r"^loopi-(dev|prod)-[0-9A-Za-z.+-]{1,64}$")
COMMIT_RE = re.compile(r"^[0-9a-f]{40}$")
MAX_NOTES = 50
MAX_SUBJECT = 200  # characters of a commit subject kept for the page


@dataclass(frozen=True)
class Note:
    commit: str
    subject: str


@dataclass(frozen=True)
class Bundle:
    name: str
    version: str
    variant: str
    sha256: str
    size: int
    built_at: dt.datetime
    commit: str
    notes_base: str | None
    notes: tuple[Note, ...]
    notes_truncated: bool

    @property
    def stem(self) -> str:
        return self.name.removesuffix(".raucb")


@dataclass(frozen=True)
class Unusable:
    stem: str
    file: str
    reason: str  # Vietnamese: shown on the Phiên bản page


class BadBundle(ValueError):
    """A bundle whose description or file cannot be trusted; the message is for the owner (Vietnamese)."""


def description_path(ota_dir: Path, name: str) -> Path:
    return ota_dir / (name.removesuffix(".raucb") + ".json")


def _notes(raw) -> tuple[Note, ...]:
    if not isinstance(raw, list) or len(raw) > MAX_NOTES:
        raise BadBundle("ghi chú phát hành không hợp lệ")
    notes = []
    for entry in raw:
        if not (isinstance(entry, dict) and isinstance(entry.get("commit"), str) and isinstance(entry.get("subject"), str)):
            raise BadBundle("ghi chú phát hành không hợp lệ")
        notes.append(Note(entry["commit"][:40], entry["subject"][:MAX_SUBJECT]))
    return tuple(notes)


def _built_at(value) -> dt.datetime:
    parsed = None
    if isinstance(value, str):
        try:
            parsed = dt.datetime.fromisoformat(value.replace("Z", "+00:00"))
        except ValueError:
            parsed = None
    if parsed is None or parsed.tzinfo is None:
        raise BadBundle("ngày build không hợp lệ")
    return parsed


def load(ota_dir: Path, description: Path) -> Bundle:
    """Parse one description and check the bundle file beside it. Raises BadBundle or OSError."""
    try:
        data = json.loads(description.read_text(encoding="utf-8"))
    except (json.JSONDecodeError, UnicodeDecodeError) as exc:
        raise BadBundle("file mô tả không phải JSON hợp lệ") from exc
    if not isinstance(data, dict):
        raise BadBundle("file mô tả không phải JSON hợp lệ")
    name, version, variant = data.get("bundle"), data.get("version"), data.get("variant")
    if not (isinstance(name, str) and BUNDLE_RE.fullmatch(name)) or description_path(ota_dir, name) != description:
        raise BadBundle("tên bundle không khớp tên file mô tả")
    if not (isinstance(version, str) and VERSION_RE.fullmatch(version)) or variant not in ("dev", "prod") \
            or name != f"loopi-{variant}-{version}.raucb":
        raise BadBundle("phiên bản hoặc biến thể không khớp tên bundle")
    sha256, size, commit = data.get("sha256"), data.get("size"), data.get("commit")
    if not (isinstance(sha256, str) and SHA256_RE.fullmatch(sha256)):
        raise BadBundle("sha256 không hợp lệ")
    if type(size) is not int or not 1 <= size <= MAX_BUNDLE_BYTES:
        raise BadBundle("kích thước trong file mô tả không hợp lệ")
    if not (isinstance(commit, str) and COMMIT_RE.fullmatch(commit)):
        raise BadBundle("mã commit không hợp lệ")
    base = data.get("notes_base")
    if base is not None and not (isinstance(base, str) and VERSION_RE.fullmatch(base)):
        raise BadBundle("ghi chú phát hành không hợp lệ")
    truncated = data.get("notes_truncated", False)
    if not isinstance(truncated, bool):
        raise BadBundle("ghi chú phát hành không hợp lệ")
    notes = _notes(data.get("notes", []))
    built_at = _built_at(data.get("built_at"))
    path = ota_dir / name
    if not path.is_file():
        raise BadBundle("thiếu file .raucb")
    if path.stat().st_size != size:
        raise BadBundle("file .raucb khác kích thước ghi trong file mô tả")
    return Bundle(name, version, variant, sha256, size, built_at, commit, base, notes, truncated)


def scan(ota_dir: Path) -> tuple[list[Bundle], list[Unusable]]:
    """Every bundle the brain can offer (newest build first) and every file it cannot, with the reason."""
    if not ota_dir.is_dir():
        return [], []
    found: list[Bundle] = []
    unusable: list[Unusable] = []
    described: set[str] = set()
    for description in sorted(ota_dir.glob("loopi-*.json")):
        stem = description.name.removesuffix(".json")
        described.add(stem)
        try:
            found.append(load(ota_dir, description))
        except BadBundle as exc:
            log.warning("unusable OTA bundle %s: %s", description.name, exc)
            unusable.append(Unusable(stem, description.name, str(exc)))
        except OSError as exc:
            log.warning("unreadable OTA bundle %s: %s", description.name, exc)
            unusable.append(Unusable(stem, description.name, "không đọc được file"))
    for path in sorted(ota_dir.glob("loopi-*.raucb")):
        stem = path.name.removesuffix(".raucb")
        if stem not in described:
            unusable.append(Unusable(stem, path.name, "thiếu file mô tả .json"))
    found.sort(key=lambda bundle: bundle.built_at, reverse=True)
    return found, unusable


def find(ota_dir: Path, name: str) -> Bundle | None:
    """The bundle called ``name`` if the catalog offers it (exact file name; nothing else is ever resolved)."""
    if not BUNDLE_RE.fullmatch(name):
        return None
    try:
        return load(ota_dir, description_path(ota_dir, name))
    except (BadBundle, OSError):
        return None
```

```sql
-- P4a: OTA updates (design 2026-10-18-p4a-prod-ota-design.md §6-§8, spec D27, D29). The brain records what the owner
-- asked a device to install and what the device last said about it; the device is the source of truth.
ALTER TABLE device_command DROP CONSTRAINT device_command_type_check;
ALTER TABLE device_command ADD CONSTRAINT device_command_type_check
    CHECK (type IN ('pause', 'resume', 'set_config', 'update'));

CREATE TABLE ota_update (
    id            TEXT PRIMARY KEY,                    -- the update command's id
    device_id     TEXT NOT NULL REFERENCES device(id),
    bundle        TEXT NOT NULL,                       -- kept after the bundle file is deleted
    version       TEXT NOT NULL,
    variant       TEXT NOT NULL CHECK (variant IN ('dev', 'prod')),
    state         TEXT NOT NULL DEFAULT 'requested' CHECK (state IN (
                      'requested', 'downloading', 'installing', 'rebooting', 'trying',
                      'succeeded', 'rolled_back', 'failed')),
    error         TEXT,
    requested_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),  -- the last report (or the request): expiry counts from here
    finished_at   TIMESTAMPTZ                          -- set with a final state; NULL while the update runs
);
-- At most one unfinished update per device: a second click (another tab) loses the race here.
CREATE UNIQUE INDEX ota_update_one_unfinished ON ota_update (device_id) WHERE finished_at IS NULL;
CREATE INDEX ota_update_device_recent ON ota_update (device_id, requested_at DESC);
```

```python
"""OTA update records (P4a design §6-§8, spec D27): what the owner asked a device to install, and what the device last
said about it. The device is the source of truth: its report wins, even over a timeout the brain declared."""
from __future__ import annotations

import datetime as dt
import logging
from pathlib import Path

import psycopg
from psycopg.types.json import Jsonb
from psycopg_pool import AsyncConnectionPool

from . import bundles, devices

log = logging.getLogger(__name__)
TERMINAL = ("succeeded", "rolled_back", "failed")
STALE_AFTER = dt.timedelta(minutes=30)
HISTORY = 5
# Owner-facing (Vietnamese)
TIMEOUT_ERROR = "Thiết bị không phản hồi trong 30 phút."
BUSY = "Thiết bị đang có một lần cập nhật chưa xong."
NOT_FOUND = "Không tìm thấy bản cập nhật này."
REVOKED = "Thiết bị đã bị thu hồi."
IN_USE = "Đang có một lần cập nhật dùng bản này."


class UpdateRefused(Exception):
    """The update cannot start; the message (Vietnamese) says why."""


class DeleteRefused(Exception):
    """The bundle must stay; the message (Vietnamese) says why."""


async def expire_stale(pool: AsyncConnectionPool) -> list[str]:
    """Give up on updates no report has touched for STALE_AFTER, and withdraw their commands if still unsent."""
    async with pool.connection() as conn:
        async with conn.transaction():
            cur = await conn.execute(
                "UPDATE ota_update SET state = 'failed', error = %s, finished_at = now()"
                " WHERE finished_at IS NULL AND updated_at < now() - %s RETURNING id",
                (TIMEOUT_ERROR, STALE_AFTER),
            )
            ids = [row["id"] for row in await cur.fetchall()]
            if ids:
                # A device that comes back later must never start an update the brain gave up on.
                await conn.execute("DELETE FROM device_command WHERE id = ANY(%s) AND acked_at IS NULL", (ids,))
    for update_id in ids:
        log.warning("OTA update %s expired: no report for %s", update_id, STALE_AFTER)
    return ids


async def request_update(pool: AsyncConnectionPool, ota_dir: Path, device_id: str, bundle_name: str) -> str:
    """Queue an update command for one device (spec D27). Raises UpdateRefused, or LookupError for an unknown device."""
    bundle = bundles.find(ota_dir, bundle_name)
    if bundle is None:
        raise UpdateRefused(NOT_FOUND)
    await expire_stale(pool)
    payload = {"bundle": bundle.name, "version": bundle.version, "variant": bundle.variant,
               "sha256": bundle.sha256, "size": bundle.size}
    devices.validate_command("update", payload)
    command_id = devices.new_id()
    try:
        async with pool.connection() as conn:
            async with conn.transaction():
                cur = await conn.execute("SELECT revoked FROM device WHERE id = %s FOR UPDATE", (device_id,))
                device = await cur.fetchone()
                if device is None:
                    raise LookupError(device_id)
                if device["revoked"]:
                    raise UpdateRefused(REVOKED)
                cur = await conn.execute(
                    "SELECT 1 FROM ota_update WHERE device_id = %s AND finished_at IS NULL", (device_id,))
                if await cur.fetchone() is not None:
                    raise UpdateRefused(BUSY)
                await conn.execute(
                    "INSERT INTO device_command (id, device_id, type, payload) VALUES (%s, %s, 'update', %s)",
                    (command_id, device_id, Jsonb(payload)),
                )
                await conn.execute(
                    "INSERT INTO ota_update (id, device_id, bundle, version, variant) VALUES (%s, %s, %s, %s, %s)",
                    (command_id, device_id, bundle.name, bundle.version, bundle.variant),
                )
    except psycopg.errors.UniqueViolation as exc:  # a concurrent request for this device won the race
        raise UpdateRefused(BUSY) from exc
    log.info("OTA update %s: device %s -> %s", command_id, device_id, bundle.name)
    return command_id


async def record_report(pool: AsyncConnectionPool, device_id: str, report: dict) -> None:
    """Record the device's word about one of its own updates. Reviving an update the brain timed out never makes a
    second unfinished update for the device; a final state always lands."""
    command_id = report.get("command_id")
    if not command_id:
        return
    params = {"state": report["state"], "error": report.get("error"), "terminal": report["state"] in TERMINAL,
              "id": command_id, "device": device_id}
    async with pool.connection() as conn:
        await conn.execute(
            "UPDATE ota_update u SET state = %(state)s, error = %(error)s, updated_at = now(),"
            " finished_at = CASE WHEN %(terminal)s THEN COALESCE(u.finished_at, now()) ELSE NULL END"
            " WHERE u.id = %(id)s AND u.device_id = %(device)s"
            " AND (%(terminal)s OR u.finished_at IS NULL OR NOT EXISTS ("
            "   SELECT 1 FROM ota_update o WHERE o.device_id = u.device_id AND o.finished_at IS NULL AND o.id <> u.id))",
            params,
        )


async def recent_updates(pool: AsyncConnectionPool, device_ids: list[str]) -> dict[str, list[dict]]:
    """The last HISTORY updates of each device, newest first."""
    if not device_ids:
        return {}
    async with pool.connection() as conn:
        cur = await conn.execute(
            "SELECT * FROM (SELECT u.*, row_number() OVER ("
            "   PARTITION BY device_id ORDER BY requested_at DESC, id DESC) AS n"
            " FROM ota_update u WHERE device_id = ANY(%s)) r"
            " WHERE n <= %s ORDER BY device_id, requested_at DESC, id DESC",
            (device_ids, HISTORY),
        )
        rows = await cur.fetchall()
    history: dict[str, list[dict]] = {device_id: [] for device_id in device_ids}
    for row in rows:
        history[row["device_id"]].append(row)
    return history


async def delete_bundle(pool: AsyncConnectionPool, ota_dir: Path, stem: str) -> None:
    """Delete a bundle and its description (spec D29). Raises LookupError for an unknown name, DeleteRefused while an
    unfinished update uses it or a device runs that version."""
    if not bundles.STEM_RE.fullmatch(stem):
        raise LookupError(stem)
    name = f"{stem}.raucb"
    paths = (ota_dir / name, bundles.description_path(ota_dir, name))
    if not any(path.exists() for path in paths):
        raise LookupError(stem)
    await expire_stale(pool)
    bundle = bundles.find(ota_dir, name)
    async with pool.connection() as conn:
        cur = await conn.execute("SELECT 1 FROM ota_update WHERE bundle = %s AND finished_at IS NULL", (name,))
        if await cur.fetchone() is not None:
            raise DeleteRefused(IN_USE)
        if bundle is not None:
            cur = await conn.execute(
                "SELECT name FROM device WHERE NOT revoked AND last_heartbeat->>'os_version' = %s"
                " AND last_heartbeat->>'os_variant' = %s ORDER BY name",
                (bundle.version, bundle.variant),
            )
            running = [row["name"] for row in await cur.fetchall()]
            if running:
                raise DeleteRefused(f"Thiết bị {', '.join(running)} đang chạy bản này.")
    for path in paths:
        path.unlink(missing_ok=True)
    log.info("deleted OTA bundle %s", stem)
```

```python
"""OTA on the web (P4a design §8, §8.1; spec D27, D29): the update controls of Thiết bị and the Phiên bản page."""
from __future__ import annotations

from fastapi import APIRouter, Depends, Form, HTTPException, Request
from fastapi.responses import HTMLResponse

from .. import bundles, devices, ota
from .routes import TEMPLATES, require_htmx

router = APIRouter()


def _running(device_rows: list[dict]) -> dict[tuple[str, str], list[str]]:
    """(version, variant) -> names of the unrevoked devices whose latest heartbeat reports it."""
    running: dict[tuple[str, str], list[str]] = {}
    for row in device_rows:
        heartbeat = row["last_heartbeat"] or {}
        if row["revoked"] or not heartbeat.get("os_version"):
            continue
        key = (heartbeat["os_version"], heartbeat.get("os_variant") or "")
        running.setdefault(key, []).append(row["name"])
    return running

            "bundles": offered,
            "unusable": unusable,
            "running": _running(await devices.list_devices(state.pool)),

@router.post("/versions/{stem}/delete", response_class=HTMLResponse, dependencies=[Depends(require_htmx)])

    try:
        await ota.delete_bundle(state.pool, state.settings.ota_dir, stem)
    except LookupError as exc:
        raise HTTPException(status_code=404, detail="unknown bundle") from exc
    except ota.DeleteRefused as exc:
        found = bundles.find(state.settings.ota_dir, f"{stem}.raucb")
        return TEMPLATES.TemplateResponse(

            {
                "b": found,
                "stem": stem,
                "error": str(exc),
                "running": _running(await devices.list_devices(state.pool)),
                "zone": state.settings.zone,
            },
        )
    return TEMPLATES.TemplateResponse(request, "_bundle_deleted.html", {"stem": stem})
```

```rust
/// Contract `OsVersion`: `^[0-9A-Za-z.+-]{1,64}$`.
pub fn is_valid_version(version: &str) -> bool {
    !version.is_empty()
        && version.len() <= 64
        && version.chars().all(|c| c.is_ascii_alphanumeric() || matches!(c, '.' | '+' | '-'))
}

/// Contract `BundleName`: `loopi-(dev|prod)-<version>.raucb`.
pub fn is_valid_bundle_name(name: &str) -> bool {
    let Some(rest) = name.strip_suffix(".raucb") else { return false };
    let version = rest.strip_prefix("loopi-dev-").or_else(|| rest.strip_prefix("loopi-prod-"));
    version.is_some_and(is_valid_version)
}

fn is_sha256(text: &str) -> bool {
    text.len() == 64 && text.chars().all(|c| c.is_ascii_digit() || ('a'..='f').contains(&c))
}

/// Translate the brain's `update` command (contract `UpdateCommand`); refuses exactly what the brain refuses.
pub fn parse_update(id: &str, payload: &Value) -> Result<UpdateRequest, String> {
    let object = payload.as_object().ok_or_else(|| format!("update payload must be an object, got {payload}"))?;
    if object.len() != UPDATE_KEYS.len() || !UPDATE_KEYS.iter().all(|key| object.contains_key(*key)) {
        return Err(format!("update needs exactly {}, got {payload}", UPDATE_KEYS.join(", ")));
    }
    let text = |key: &str| object[key].as_str().ok_or_else(|| format!("update {key} must be a string"));
    let (bundle, version, sha256) = (text("bundle")?, text("version")?, text("sha256")?);
    let variant = Variant::parse(text("variant")?).ok_or("update variant must be dev or prod")?;
    let size = object["size"].as_u64().filter(|s| (1..=MAX_BUNDLE_BYTES).contains(s))
        .ok_or_else(|| format!("update size must be an integer from 1 to {MAX_BUNDLE_BYTES}"))?;
    if !is_valid_version(version) || !is_valid_bundle_name(bundle) || !is_sha256(sha256) {
        return Err(format!("update payload is malformed: {payload}"));
    }
    if bundle != format!("loopi-{}-{version}.raucb", variant.as_str()) {
        return Err(format!("update bundle {bundle} does not match variant {} and version {version}", variant.as_str()));
    }
    Ok(UpdateRequest {
        command_id: Some(id.to_string()),
        bundle: bundle.to_string(),
        version: version.to_string(),
        variant,
        sha256: sha256.to_string(),
        size,
    })
}
```

```rust
use std::path::Path;

use crate::ota::{is_valid_version, Slot, Variant};

pub const CMDLINE_PATH: &str = "/proc/cmdline";

pub struct OsInfo {
    pub version: Option<String>,
    pub variant: Option<Variant>,
    pub slot: Option<Slot>,
}

impl OsInfo {
    /// Unreadable or malformed files give unknown fields, never an error: a heartbeat with a value the contract
    /// refuses would be refused as a whole.
    pub fn read(release: &Path, cmdline: &Path) -> Self {
        let (version, variant) = fs::read_to_string(release).map(|text| parse_release(&text)).unwrap_or((None, None));
        let slot = fs::read_to_string(cmdline).ok().and_then(|text| parse_cmdline_slot(&text));
        Self { version, variant, slot }
    }
}

/// `LOOPI_OS_VERSION=<version>` and `LOOPI_OS_VARIANT=dev|prod` lines; anything else is ignored.
pub fn parse_release(text: &str) -> (Option<String>, Option<Variant>) {
    let value = |key: &str| text.lines().find_map(|line| line.trim().strip_prefix(key)).map(str::trim);
    let version = value("LOOPI_OS_VERSION=").filter(|v| is_valid_version(v)).map(String::from);
    let variant = value("LOOPI_OS_VARIANT=").and_then(Variant::parse);
    (version, variant)
}

pub fn parse_cmdline_slot(cmdline: &str) -> Option<Slot> {
    cmdline.split_whitespace().find_map(|word| word.strip_prefix("rauc.slot=")).and_then(Slot::parse)
```

```rust
//! The update in progress, kept in /data/ota/pending.json across reboots (P4a design §6). `/data` is shared by both
//! slots, so this format must stay readable by the agent versions before and after this one.
use std::fs;
use std::io;
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};

use super::{OtaReport, OtaState, Slot};
use crate::fsutil::write_atomic;

pub const PENDING_FILE: &str = "pending.json";

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Phase {
    Downloading,
    Installing,
    Rebooting,
    Succeeded,
    RolledBack,
    Failed,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Pending {
    pub command_id: Option<String>,
    /// `None` for the hand-made first move to A/B slots (os/scripts/migrate-to-ab.sh).
    pub bundle: Option<String>,
    pub version: String,
    pub target_slot: Slot,
    pub phase: Phase,
    #[serde(default)]
    pub error: Option<String>,
}

impl Pending {
    pub fn report(&self, state: OtaState) -> OtaReport {
        OtaReport::new(self.command_id.clone(), &self.version, state, self.error.clone())
    }

    /// The state to report for a finished update, or `None` while it runs.
    pub fn outcome(&self) -> Option<OtaState> {
        match self.phase {
            Phase::Succeeded => Some(OtaState::Succeeded),
            Phase::RolledBack => Some(OtaState::RolledBack),
            Phase::Failed => Some(OtaState::Failed),
            Phase::Downloading | Phase::Installing | Phase::Rebooting => None,
        }
    }
}

/// What the last boot left behind, and what to do about it.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum BootAction {
    Idle,
    /// A trial boot of the slot an update installed: confirm it once a heartbeat gets through.
    Confirm(Pending),
    /// The trial did not confirm itself and the firmware went back to the good slot.
    RolledBack(Pending),
    /// Power or the agent went away before the reboot (while downloading or installing).
    Interrupted(Pending),
    /// An outcome the brain may not have heard yet.
    Deliver(Pending),
}

pub fn reconcile(pending: Option<Pending>, booted: Slot) -> BootAction {
    let Some(pending) = pending else { return BootAction::Idle };
    match pending.phase {
        Phase::Downloading | Phase::Installing => BootAction::Interrupted(pending),
        Phase::Rebooting if pending.target_slot == booted => BootAction::Confirm(pending),
        Phase::Rebooting => BootAction::RolledBack(pending),
        Phase::Succeeded | Phase::RolledBack | Phase::Failed => BootAction::Deliver(pending),
    }
}

pub struct PendingStore {
    dir: PathBuf,
}

impl PendingStore {
    pub fn new(data_dir: &Path) -> Self {
        Self { dir: data_dir.join("ota") }
    }

    pub fn dir(&self) -> &Path {
        &self.dir
    }

    /// `Ok(None)` when no update is pending; a corrupt file is `InvalidData`.
    pub fn load(&self) -> io::Result<Option<Pending>> {
        match fs::read(self.dir.join(PENDING_FILE)) {
            Ok(bytes) => serde_json::from_slice(&bytes).map(Some).map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e)),
            Err(e) if e.kind() == io::ErrorKind::NotFound => Ok(None),
            Err(e) => Err(e),
        }
    }

    pub fn save(&self, pending: &Pending) -> io::Result<()> {
        fs::create_dir_all(&self.dir)?;
        let bytes = serde_json::to_vec(pending).map_err(io::Error::other)?;
        write_atomic(&self.dir.join(PENDING_FILE), &bytes, 0o600)
    }

    pub fn remove(&self) -> io::Result<()> {
        match fs::remove_file(self.dir.join(PENDING_FILE)) {
            Err(e) if e.kind() != io::ErrorKind::NotFound => Err(e),
            _ => Ok(()),
        }
    }

    pub fn bundle_path(&self, bundle: &str) -> PathBuf {
        self.dir.join(bundle)
    }

    pub fn part_path(&self, bundle: &str) -> PathBuf {
        self.dir.join(format!("{bundle}.part"))
    }

    /// Delete every downloaded or half-downloaded bundle.
    pub fn clear_downloads(&self) -> io::Result<()> {
        let entries = match fs::read_dir(&self.dir) {
            Err(e) if e.kind() == io::ErrorKind::NotFound => return Ok(()),
            other => other?,
        };
        for entry in entries {
            let path = entry?.path();
            let name = path.file_name().and_then(|n| n.to_str()).unwrap_or_default();
            if name.ends_with(".raucb") || name.ends_with(".raucb.part") {
                fs::remove_file(&path)?;
            }
        }
        Ok(())
    }
}
```

```rust
/// Run a command; on failure the error names it and keeps the last lines it printed.
pub fn run(program: &str, args: &[&str]) -> Result<(), String> {
    let output = Command::new(program).args(args).output().map_err(|e| format!("{program}: {e}"))?;
    if output.status.success() {
        return Ok(());
    }
    let text = String::from_utf8_lossy(if output.stderr.is_empty() { &output.stdout } else { &output.stderr }).into_owned();
    let tail: Vec<&str> = text.lines().filter(|l| !l.trim().is_empty()).collect();
    let tail = tail[tail.len().saturating_sub(3)..].join(" / ");
    Err(format!("{program} {} failed ({}): {tail}", args.join(" "), output.status))
}
```

```rust
        self.record("mark-bad other".into())
    }

    pub result: Mutex<Option<String>>,
}

    }
}

/// Writes `body` to the destination; pops scripted failures first.
pub struct FakeFetcher {
    pub body: Vec<u8>,
    pub failures: Mutex<VecDeque<TransportError>>,
    pub calls: Mutex<u32>,
}

    pub fn new(body: &[u8]) -> Self {
```

```rust
//! The OTA task (P4a design §6): finish what the last boot left (confirm a trial, report a rollback or an
//! interruption), then install the updates the brain sends, one at a time.
use std::path::Path;
use std::sync::Arc;
use std::time::Duration;

use tokio::sync::{mpsc, watch};

use super::pending::{reconcile, BootAction, Pending, PendingStore, Phase};
use super::system::{BundleFetcher, Rauc, Rebooter};
use super::{OtaReport, OtaState, Slot, UpdateRequest};
use crate::disk::DiskUsage;
use crate::status::StatusTx;
use crate::transport::TransportError;

/// Updates need room: a ~75 MB bundle on a card above this would push the queue toward the 85 % video drop.
pub const MAX_DISK_PCT: f32 = 80.0;
pub const IN_PROGRESS: &str = "another update is in progress";
pub const INTERRUPTED: &str = "interrupted before the update was installed (power loss or restart)";
const SHUTDOWN: &str = "shutting down";

#[derive(Debug, Clone, Copy)]
pub struct OtaTimings {
    pub retry_first: Duration,
    pub retry_max: Duration,
    pub attempts: u32,
    /// How long to let the brain hear "rebooting" before the device goes quiet.
    pub reboot_report_wait: Duration,
}

impl Default for OtaTimings {
    fn default() -> Self {
        Self { retry_first: Duration::from_secs(1), retry_max: Duration::from_secs(300), attempts: 10,
               reboot_report_wait: Duration::from_secs(45) }
    }
}

pub struct OtaDeps {
    pub store: PendingStore,
    pub rauc: Arc<dyn Rauc>,
    pub rebooter: Arc<dyn Rebooter>,
    pub fetcher: Arc<dyn BundleFetcher>,
    pub disk: Arc<dyn DiskUsage>,
    pub status: StatusTx,
    /// Heartbeats the brain answered with 200 since the agent started.
    pub delivered: watch::Receiver<u64>,
    pub booted: Slot,
    pub timings: OtaTimings,
}

pub async fn run_ota(mut deps: OtaDeps, mut updates: mpsc::Receiver<UpdateRequest>, mut shutdown: watch::Receiver<bool>) {
    on_boot(&mut deps, &mut shutdown).await;
    loop {
        tokio::select! {
            update = updates.recv() => match update {
                Some(request) => install(&mut deps, request, &mut shutdown).await,
                None => return,
            },
            changed = shutdown.changed() => if changed.is_err() || *shutdown.borrow() { return },
        }
        if *shutdown.borrow() {
            return;
        }
    }
}

fn publish(status: &StatusTx, report: Option<OtaReport>) {
    status.send_modify(|s| s.ota = report);
}

fn stopping(shutdown: &watch::Receiver<bool>) -> bool {
    *shutdown.borrow()
}

/// Wait until at least `count` heartbeats got through; false on shutdown.
async fn heartbeats(delivered: &mut watch::Receiver<u64>, count: u64, shutdown: &mut watch::Receiver<bool>) -> bool {
    loop {
        if *delivered.borrow_and_update() >= count {
            return true;
        }
        tokio::select! {
            changed = delivered.changed() => if changed.is_err() { return false },
            changed = shutdown.changed() => if changed.is_err() || *shutdown.borrow() { return false },
        }
    }
}

/// Keep `report` in the heartbeat until two more heartbeats got through (the first may have been built before it was
/// set), then forget the update.
async fn deliver(deps: &mut OtaDeps, report: OtaReport, shutdown: &mut watch::Receiver<bool>) {
    publish(&deps.status, Some(report.clone()));
    let target = *deps.delivered.borrow() + 2;
    if heartbeats(&mut deps.delivered, target, shutdown).await {
        if let Err(e) = deps.store.remove() {
            tracing::warn!(error = %e, "could not delete the finished update's state");
        }
        deps.status.send_modify(|s| {
            if s.ota.as_ref() == Some(&report) {
                s.ota = None;
            }
        });
    }
}

fn save(deps: &OtaDeps, pending: &Pending) {
    if let Err(e) = deps.store.save(pending) {
        tracing::error!(error = %e, "could not save the update state");
    }
}

async fn blocking<T: Send + 'static>(f: impl FnOnce() -> Result<T, String> + Send + 'static) -> Result<T, String> {
    tokio::task::spawn_blocking(f).await.unwrap_or_else(|e| Err(format!("worker thread failed: {e}")))
}

async fn finish(deps: &mut OtaDeps, mut pending: Pending, phase: Phase, error: Option<String>,
                shutdown: &mut watch::Receiver<bool>) {
    pending.phase = phase;
    pending.error = error;
    save(deps, &pending);
    let state = pending.outcome().expect("finish() takes a final phase");
    tracing::info!(?state, version = %pending.version, error = ?pending.error, "update finished");
    deliver(deps, pending.report(state), shutdown).await;
}

async fn on_boot(deps: &mut OtaDeps, shutdown: &mut watch::Receiver<bool>) {
    let pending = deps.store.load().unwrap_or_else(|e| {
        tracing::warn!(error = %e, "unreadable update state; forgetting it");
        let _ = deps.store.remove();
        None
    });
    match reconcile(pending, deps.booted) {
        BootAction::Idle => {}
        BootAction::Deliver(pending) => {
            let state = pending.outcome().expect("Deliver carries a final phase");
            deliver(deps, pending.report(state), shutdown).await;
        }
        BootAction::Interrupted(pending) => {
            if let Err(e) = deps.store.clear_downloads() {
                tracing::warn!(error = %e, "could not delete partial bundles");
            }
            finish(deps, pending, Phase::Failed, Some(INTERRUPTED.into()), shutdown).await;
        }
        BootAction::RolledBack(pending) => {
            let rauc = deps.rauc.clone();
            if let Err(e) = blocking(move || rauc.mark_bad_other()).await {
                tracing::warn!(error = %e, "could not mark the failed slot bad");
            }
            finish(deps, pending, Phase::RolledBack, None, shutdown).await;
        }
        BootAction::Confirm(pending) => {
            publish(&deps.status, Some(pending.report(OtaState::Trying)));
            tracing::info!(version = %pending.version, "trial boot: confirming after the first heartbeat");
            if !heartbeats(&mut deps.delivered, 1, shutdown).await {
                return;
            }
            let rauc = deps.rauc.clone();
            match blocking(move || rauc.mark_good()).await {
                Ok(()) => finish(deps, pending, Phase::Succeeded, None, shutdown).await,
                Err(e) => finish(deps, pending, Phase::Failed, Some(format!("could not confirm the new version: {e}")), shutdown).await,
            }
        }
    }
}

enum Download {
    Done,
    Failed(String),
    Shutdown,
}

async fn download(deps: &OtaDeps, request: &UpdateRequest, part: &Path, shutdown: &mut watch::Receiver<bool>) -> Download {
    let mut delay = deps.timings.retry_first;
    let mut last = String::new();
    for attempt in 1..=deps.timings.attempts {
        let result = tokio::select! {
            result = deps.fetcher.fetch(&request.bundle, part, request.size) => result,
            _ = shutdown.changed() => return Download::Shutdown,
        };
        match result {
            Ok(()) => return Download::Done,
            Err(TransportError::Status(404)) => return Download::Failed("the brain no longer offers this bundle".into()),
            Err(e) => {
                tracing::warn!(attempt, error = %e, "bundle download failed");
                last = e.to_string();
            }
        }
        if attempt == deps.timings.attempts {
            break;
        }
        tokio::select! {
            _ = tokio::time::sleep(delay) => {}
            _ = shutdown.changed() => return Download::Shutdown,
        }
        delay = (delay * 2).min(deps.timings.retry_max);
    }
    Download::Failed(format!("download failed: {last}"))
}

async fn install(deps: &mut OtaDeps, request: UpdateRequest, shutdown: &mut watch::Receiver<bool>) {
    match deps.store.load() {
        Ok(Some(pending)) if pending.outcome().is_none() => {
            let id = request.command_id.as_deref().unwrap_or("-");
            tracing::warn!(id, "update ignored: {IN_PROGRESS}");
            deps.status.send_modify(|s| s.last_error = Some(format!("update {id} ignored: {IN_PROGRESS}")));
            return;
        }
        Err(e) => tracing::warn!(error = %e, "unreadable update state; starting over"),
        _ => {}
    }
    let mut pending = Pending {
        command_id: request.command_id.clone(),
        bundle: Some(request.bundle.clone()),
        version: request.version.clone(),
        target_slot: deps.booted.other(),
        phase: Phase::Downloading,
        error: None,
    };
    match deps.disk.used_pct() {
        Ok(pct) if pct <= MAX_DISK_PCT => {}
        Ok(pct) => {
            let reason = format!("the card is {pct:.0}% full; updates need it at most {MAX_DISK_PCT:.0}% full");
            return finish(deps, pending, Phase::Failed, Some(reason), shutdown).await;
        }
        Err(e) => return finish(deps, pending, Phase::Failed, Some(format!("disk usage unreadable: {e}")), shutdown).await,
    }
    save(deps, &pending);
    publish(&deps.status, Some(pending.report(OtaState::Downloading)));
    let (part, bundle) = (deps.store.part_path(&request.bundle), deps.store.bundle_path(&request.bundle));
    match download(deps, &request, &part, shutdown).await {
        Download::Done => {}
        Download::Shutdown => return,
        Download::Failed(reason) => {
            let _ = std::fs::remove_file(&part);
            return finish(deps, pending, Phase::Failed, Some(reason), shutdown).await;
        }
    }
    let check = part.clone();
    let digest = blocking(move || crate::queue::sha256_file(&check).map_err(|e| e.to_string())).await;
    if !matches!(&digest, Ok((sha, size)) if *sha == request.sha256 && *size == request.size) {
        let _ = std::fs::remove_file(&part);
        return finish(deps, pending, Phase::Failed, Some("bundle checksum mismatch".into()), shutdown).await;
    }
    if let Err(e) = std::fs::rename(&part, &bundle) {
        return finish(deps, pending, Phase::Failed, Some(format!("could not keep the bundle: {e}")), shutdown).await;
    }
    pending.phase = Phase::Installing;
    save(deps, &pending);
    publish(&deps.status, Some(pending.report(OtaState::Installing)));
    let (rauc, path) = (deps.rauc.clone(), bundle.clone());
    let installed = blocking(move || rauc.install(&path)).await;
    let _ = std::fs::remove_file(&bundle);
    if let Err(e) = installed {
        return finish(deps, pending, Phase::Failed, Some(format!("install failed: {e}")), shutdown).await;
    }
    pending.phase = Phase::Rebooting;
    save(deps, &pending);
    publish(&deps.status, Some(pending.report(OtaState::Rebooting)));
    let target = *deps.delivered.borrow() + 2;
    let wait = deps.timings.reboot_report_wait;
    let _ = tokio::time::timeout(wait, heartbeats(&mut deps.delivered, target, shutdown)).await;
    if stopping(shutdown) {
        return;
    }
    let rebooter = deps.rebooter.clone();
    if let Err(e) = blocking(move || rebooter.reboot_into_trial()).await {
        finish(deps, pending, Phase::Failed, Some(format!("reboot failed: {e}")), shutdown).await;
    }
    // On success systemd is stopping us now; the next boot continues in on_boot().
}
```

```rust
use tokio::io::AsyncWriteExt;

use crate::ota::system::BundleFetcher;

#[async_trait]
impl BundleFetcher for HttpTransport {
    /// GET /v1/ota/{bundle} into `dest`, resuming with `Range: bytes=<have>-` (P4a design §6). A 200 answer to a range
    /// request restarts the file; the body may never grow past `size`.
    async fn fetch(&self, bundle: &str, dest: &Path, size: u64) -> Result<(), TransportError> {
        let mut have = match tokio::fs::metadata(dest).await {
            Ok(meta) => meta.len(),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => 0,
            Err(e) => return Err(e.into()),
        };
        if have > size {
            tokio::fs::remove_file(dest).await?;
            have = 0;
        }
        if have == size {
            return Ok(());
        }
        let mut request = self
            .client
            .get(format!("{}/v1/ota/{bundle}", self.base_url))
            .header("X-Loopi-Agent-Version", AGENT_VERSION)
            .timeout(self.timeouts.upload(size - have));
        if have > 0 {
            request = request.header(header::RANGE, format!("bytes={have}-"));
        }
        let mut response = request.send().await.map_err(network)?;
        let mut written = match response.status().as_u16() {
            206 if have > 0 => have,
            200 => 0,
            status => return Err(TransportError::Status(status)),
        };
        let mut file = if written == 0 {
            tokio::fs::File::create(dest).await?
        } else {
            tokio::fs::OpenOptions::new().append(true).open(dest).await?
        };
        while let Some(chunk) = response.chunk().await.map_err(network)? {
            written += chunk.len() as u64;
            if written > size {
                drop(file);
                tokio::fs::remove_file(dest).await?;
                return Err(TransportError::Decode(format!("bundle larger than the {size} bytes announced")));
            }
            file.write_all(&chunk).await?;
        }
        file.sync_all().await?;
        if written != size {
            return Err(TransportError::Decode(format!("bundle ended at {written} of {size} bytes")));
        }
        Ok(())
    }
}
```

```sh
#!/bin/sh
# Loopi A/B boot control (P4a design §4-§6, spec D26): the RAUC custom bootloader backend, the step that puts a slot's
# kernel files on the boot partition, and the trial-boot guard.
#
# Slots: A = /dev/mmcblk0p2 + /boot/a/, B = /dev/mmcblk0p3 + /boot/b/. config.txt boots the good slot (os_prefix=a/ or
# b/; none at all is the pre-P4a layout, which is slot A). tryboot.txt is read by the firmware only on a "0 tryboot"
# reboot and boots the slot under trial; any other reboot (watchdog, panic=10, power loss, the guard) goes back to
# config.txt. A trial is confirmed by renaming tryboot.txt over config.txt: config.txt is never written from nothing.
#
# RAUC:  get-primary | get-current | get-state <A|B> | set-primary <A|B> | set-state <A|B> good|bad
# Loopi: install-files <A|B> <mounted slot root> | trial-pending | guard
set -eu

BOOT="${LOOPI_BOOT_DIR:-/boot}"
STATE_DIR="${LOOPI_STATE_DIR:-/data/rauc}"
CMDLINE="${LOOPI_CMDLINE:-/proc/cmdline}"
TRYBOOT_FLAG="${LOOPI_TRYBOOT_FLAG:-/proc/device-tree/chosen/bootloader/tryboot}"
REMOUNT="${LOOPI_REMOUNT:-1}"
REBOOT_CMD="${LOOPI_REBOOT_CMD:-systemctl reboot}"
SHARE=usr/share/loopi/boot

die() { echo "loopi-boot: $*" >&2; exit 1; }

slot_dir() { case "$1" in A) echo a ;; B) echo b ;; *) die "unknown slot '$1'" ;; esac; }
slot_root() { case "$1" in A) echo /dev/mmcblk0p2 ;; B) echo /dev/mmcblk0p3 ;; *) die "unknown slot '$1'" ;; esac; }

# The os_prefix of a config file: a, b or nothing.
prefix_of() { sed -n 's|^os_prefix=\([ab]\)/$|\1|p' "$1" 2>/dev/null | tail -n 1; }

primary() {
	[ -f "$BOOT/config.txt" ] || die "$BOOT/config.txt is missing"
	case "$(prefix_of "$BOOT/config.txt")" in b) echo B ;; *) echo A ;; esac
}

current() { tr ' ' '\n' < "$CMDLINE" | sed -n 's/^rauc\.slot=\([AB]\)$/\1/p' | head -n 1; }

# True when the firmware booted this time from tryboot.txt (a 4-byte big-endian 1 in the device tree).
in_trial() {
	[ -f "$TRYBOOT_FLAG" ] || return 1
	one="$(mktemp)"
	printf '\000\000\000\001' > "$one"
	if cmp -s "$TRYBOOT_FLAG" "$one"; then rm -f "$one"; return 0; fi
	rm -f "$one"
	return 1
}

boot_ro() { sync; if [ "$REMOUNT" = 1 ]; then mount -o remount,ro "$BOOT" || true; fi; }
boot_rw() {
	[ "$REMOUNT" = 1 ] || return 0
	mount -o remount,rw "$BOOT"
	trap boot_ro EXIT
}

# put <file>: stdin to <file> through a temporary sibling, renamed into place.
put() { cat > "$1.new"; sync; mv -f "$1.new" "$1"; sync; }

# The firmware config that boots <slot>: the slot's own template when its files are on the boot partition (it may come
# from another variant), else the current config.txt. The USB gadget overlay keeps the state the running config.txt
# has (dev images switch it with loopi-usbmode); a template without it (prod) never gets it.
render_config() {
	template="$BOOT/$(slot_dir "$1")/loopi-config.txt"
	[ -f "$template" ] || template="$BOOT/config.txt"
	if grep -q '^dtoverlay=dwc2' "$BOOT/config.txt" 2>/dev/null; then
		usb='s/^# *dtoverlay=dwc2/dtoverlay=dwc2/'
	else
		usb='s/^dtoverlay=dwc2/# dtoverlay=dwc2/'
	fi
	sed -e '/^# Loopi slot$/,$d' -e '/^os_prefix=/d' -e "$usb" "$template"
	printf '# Loopi slot\n[all]\nos_prefix=%s/\n' "$(slot_dir "$1")"
}

write_tryboot() { boot_rw; render_config "$1" | put "$BOOT/tryboot.txt"; }

state_get() {
	[ -f "$STATE_DIR/boot-state" ] || return 0
	awk -v s="$1" '$1 == s && ($2 == "good" || $2 == "bad") { v = $2 } END { if (v != "") print v }' "$STATE_DIR/boot-state"
}

state_set() {
	mkdir -p "$STATE_DIR"
	{ if [ -f "$STATE_DIR/boot-state" ]; then awk -v s="$1" '$1 != s' "$STATE_DIR/boot-state"; fi; echo "$1 $2"; } \
		| put "$STATE_DIR/boot-state"
}

# Once both slots have their own files and config.txt names one, the pre-P4a kernel files at the root are unused.
cleanup_legacy() {
	[ -f "$BOOT/a/zImage" ] && [ -f "$BOOT/b/zImage" ] || return 0
	[ -n "$(prefix_of "$BOOT/config.txt")" ] || return 0
	rm -rf "$BOOT/zImage" "$BOOT/bcm2708-rpi-zero-w.dtb" "$BOOT/cmdline.txt" "$BOOT/overlays"
}

trial_unconfirmed() { c="$(current)"; in_trial && [ -n "$c" ] && [ "$c" != "$(primary)" ]; }

cmd="${1:-}"
[ $# -gt 0 ] && shift
case "$cmd" in
get-primary)
	primary
	;;
get-current)
	c="$(current)"
	[ -n "$c" ] || die "no rauc.slot= on the kernel command line"
	echo "$c"
	;;
get-state)
	[ $# = 1 ] || die "usage: get-state <A|B>"
	slot_dir "$1" > /dev/null
	s="$(state_get "$1")"
	if [ -z "$s" ]; then
		if [ "$1" = "$(primary)" ]; then s=good; else s=bad; fi
	fi
	echo "$s"
	;;
set-primary)
	[ $# = 1 ] || die "usage: set-primary <A|B>"
	slot_dir "$1" > /dev/null
	if [ "$1" = "$(primary)" ]; then
		boot_rw
		rm -f "$BOOT/tryboot.txt"
	else
		write_tryboot "$1"
	fi
	;;
set-state)
	[ $# = 2 ] || die "usage: set-state <A|B> good|bad"
	dir="$(slot_dir "$1")"
	case "$2" in good | bad) ;; *) die "state must be good or bad, not '$2'" ;; esac
	if [ "$2" = good ] && [ "$1" = "$(current)" ] && [ "$1" != "$(primary)" ]; then
		[ "$(prefix_of "$BOOT/tryboot.txt")" = "$dir" ] || die "no tryboot.txt for slot $1: nothing to confirm"
		state_set "$1" good
		boot_rw
		sync
		mv -f "$BOOT/tryboot.txt" "$BOOT/config.txt"
		sync
		cleanup_legacy
	else
		state_set "$1" "$2"
		if [ "$2" = bad ] && [ "$(prefix_of "$BOOT/tryboot.txt")" = "$dir" ]; then
			boot_rw
			rm -f "$BOOT/tryboot.txt"
		fi
	fi
	;;
install-files)
	[ $# = 2 ] || die "usage: install-files <A|B> <mounted slot root>"
	dir="$(slot_dir "$1")"
	[ "$1" != "$(current)" ] || die "slot $1 is running; its boot files stay as they are"
	for f in zImage bcm2708-rpi-zero-w.dtb cmdline.txt loopi-config.txt; do
		[ -f "$2/$SHARE/$f" ] || die "$2/$SHARE/$f is missing"
	done
	boot_rw
	rm -rf "$BOOT/$dir.new"
	cp -r "$2/$SHARE" "$BOOT/$dir.new"
	sed -e "s|@ROOT@|$(slot_root "$1")|g" -e "s|@SLOT@|$1|g" "$2/$SHARE/cmdline.txt" > "$BOOT/$dir.new/cmdline.txt"
	sync
	rm -rf "$BOOT/$dir"
	mv "$BOOT/$dir.new" "$BOOT/$dir"
	sync
	write_tryboot "$1"
	;;
trial-pending)
	trial_unconfirmed
	;;
guard)
	if trial_unconfirmed; then
		echo "loopi-boot: slot $(current) was not confirmed in time; rebooting into slot $(primary)" >&2
		$REBOOT_CMD
	fi
	;;
*)
	die "usage: loopi-boot get-primary|get-current|get-state|set-primary|set-state|install-files|trial-pending|guard"
	;;
esac
```

```sh
# Assemble the SD card (P4a design §4): boot (FAT: firmware, config.txt booting slot A, slot dirs a/ and b/), rootfs-A
# (squashfs), rootfs-B (empty until the first update), data (ext4). Then the signed RAUC bundle of this rootfs and the
# description the brain lists it by (P4a design §8).
set -eu
BOARD_DIR="$(cd "$(dirname "$0")" && pwd)"
: "${LOOPI_OS_VERSION:?}" "${LOOPI_VARIANT:?}" "${LOOPI_COMMIT:?}" "${LOOPI_RAUC_KEYS:?}"

WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT

# --- boot partition, laid out by the shipped loopi-boot, so the first config.txt is the one an update would write
STAGE="$WORK/boot"
mkdir -p "$STAGE"
cp "${BINARIES_DIR}/rpi-firmware/bootcode.bin" "${BINARIES_DIR}/rpi-firmware/start.elf" \
	"${BINARIES_DIR}/rpi-firmware/fixup.dat" "${BOARD_DIR}/loopi.toml.example" "$STAGE/"

	sh "${TARGET_DIR}/usr/libexec/loopi/loopi-boot" install-files A "${TARGET_DIR}"
mv "$STAGE/tryboot.txt" "$STAGE/config.txt"
BOOT_IMG="${BINARIES_DIR}/boot.vfat"
rm -f "$BOOT_IMG"
# FAT32 with 512-byte clusters: 64 MiB is just big enough for a FAT32 without mkdosfs warning about too few clusters
# (the default would silently pick FAT16).
"${HOST_DIR}/sbin/mkfs.vfat" -F 32 -s 1 -n BOOT -C "$BOOT_IMG" 65536
MTOOLS_SKIP_CHECK=1 "${HOST_DIR}/bin/mcopy" -s -i "$BOOT_IMG" "$STAGE"/* ::
MTOOLS_SKIP_CHECK=1 "${HOST_DIR}/bin/mmd" -i "$BOOT_IMG" ::b

# --- data partition (empty; grows on first boot)
DATA_IMG="${BINARIES_DIR}/data.ext4"
EMPTY_DIR="$WORK/empty"
mkdir -p "$EMPTY_DIR"
rm -f "${DATA_IMG}"
truncate -s 64M "${DATA_IMG}"
"${HOST_DIR}/sbin/mkfs.ext4" -q -F -L data -b 4096 -i 65536 -d "${EMPTY_DIR}" "${DATA_IMG}"

support/scripts/genimage.sh -c "${BOARD_DIR}/genimage.cfg"

# --- signed update bundle (spec D26-D28) and its description for the brain
BUNDLE_DIR="$WORK/bundle"
mkdir -p "$BUNDLE_DIR"
cp "${BINARIES_DIR}/rootfs.squashfs" "$BUNDLE_DIR/rootfs.squashfs"
cat > "$BUNDLE_DIR/manifest.raucm" <<EOF
[update]
compatible=loopi-rpi0w
version=${LOOPI_OS_VERSION}

[bundle]
format=verity

[image.rootfs]
filename=rootfs.squashfs
EOF
BUNDLE="${BINARIES_DIR}/${NAME}.raucb"
rm -f "${BINARIES_DIR}"/loopi-*.raucb "${BINARIES_DIR}"/loopi-*.json
"${HOST_DIR}/bin/rauc" bundle --cert="${LOOPI_RAUC_KEYS}/signing.cert.pem" --key="${LOOPI_RAUC_KEYS}/signing.key.pem" \
	"$BUNDLE_DIR" "$BUNDLE"

SHA="$(sha256sum "$BUNDLE" | cut -d' ' -f1)"
SIZE="$(stat -c %s "$BUNDLE")"
printf '{"bundle": "%s.raucb", "version": "%s", "variant": "%s", "sha256": "%s", "size": %s, "built_at": "%s", "commit": "%s"}\n' \
	"$NAME" "$LOOPI_OS_VERSION" "$LOOPI_VARIANT" "$SHA" "$SIZE" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$LOOPI_COMMIT" \
	> "${BINARIES_DIR}/${NAME}.json"
```

- [ ] **Step 7: Signing keys script** — create `os/scripts/rauc-keys.sh` (mode 755):

```bash
#!/usr/bin/env bash
# Create the OTA signing keys once (P4a design §9): a CA, whose certificate every image carries as the RAUC keyring,
# and a signing certificate issued by it for os/build.sh to sign bundles with. Kept outside git and never printed.
# Back the directory up: without it no update can ever be installed again, only a re-flash.
# Usage: os/scripts/rauc-keys.sh            (LOOPI_RAUC_KEYS overrides ~/.config/loopi/rauc)
set -euo pipefail
DIR="${LOOPI_RAUC_KEYS:-$HOME/.config/loopi/rauc}"
umask 077
if [ -e "$DIR/ca.key.pem" ] || [ -e "$DIR/signing.key.pem" ]; then
  echo "OTA signing keys already exist in $DIR; nothing changed" >&2
  exit 1
fi
mkdir -p "$DIR"
chmod 700 "$DIR"
openssl ecparam -name prime256v1 -genkey -noout -out "$DIR/ca.key.pem"
openssl req -x509 -new -key "$DIR/ca.key.pem" -sha256 -days 7300 -subj "/CN=Loopi OTA CA" \
  -addext "basicConstraints=critical,CA:TRUE" -addext "keyUsage=critical,keyCertSign,cRLSign" \
  -out "$DIR/ca.cert.pem"
openssl ecparam -name prime256v1 -genkey -noout -out "$DIR/signing.key.pem"
openssl req -new -key "$DIR/signing.key.pem" -subj "/CN=Loopi OTA signing" -out "$DIR/signing.csr.pem"
printf 'basicConstraints=critical,CA:FALSE\nkeyUsage=critical,digitalSignature\nsubjectKeyIdentifier=hash\nauthorityKeyIdentifier=keyid\n' \
  > "$DIR/signing.ext"
openssl x509 -req -in "$DIR/signing.csr.pem" -CA "$DIR/ca.cert.pem" -CAkey "$DIR/ca.key.pem" -CAcreateserial \
  -days 7300 -sha256 -extfile "$DIR/signing.ext" -out "$DIR/signing.cert.pem" 2>/dev/null
rm -f "$DIR/signing.csr.pem" "$DIR/signing.ext" "$DIR/ca.cert.srl"
chmod 600 "$DIR"/*
openssl verify -CAfile "$DIR/ca.cert.pem" "$DIR/signing.cert.pem" > /dev/null
echo "Created the OTA signing keys in $DIR. Back this directory up: without it no update can be installed."
```

```bash
#!/usr/bin/env bash
# Publish a built OTA bundle to the brain (P4a design §8.1, spec D29): add release notes from git, then copy the bundle
# and its description into the brain's bundle directory (LOOPI_OTA_DIR; /srv/loopi/ota in the api container).
# Usage: os/scripts/publish-bundle.sh [--acceptance] <os/out/loopi-<variant>-<version>.json> <ota dir>
#   --acceptance  also allows the deliberately broken acceptance bundles (version contains -broken-)
# The notes are the subjects of the commits touching agent/, os/ or docs/protocol/ since the newest bundle already in
# the directory (any variant: both are built from the same code), at most 50 (the newest); with no usable base, the
# last 20.
set -euo pipefail
MAX_NOTES=50
FIRST_NOTES=20
NOTE_PATHS=(agent os docs/protocol)
REPO="${LOOPI_REPO:-$(cd "$(dirname "$0")/../.." && pwd)}"
die() { echo "publish-bundle: $*" >&2; exit 1; }

acceptance=0
if [ "${1:-}" = --acceptance ]; then acceptance=1; shift; fi
[ $# = 2 ] || { echo "usage: $0 [--acceptance] <bundle.json> <ota dir>" >&2; exit 2; }
desc="$1"
ota="$2"
[ -f "$desc" ] || die "$desc not found"
[ -d "$ota" ] || die "$ota is not a directory"
bundle="$(jq -er .bundle "$desc")" || die "$desc has no bundle name"
version="$(jq -er .version "$desc")" || die "$desc has no version"
commit="$(jq -er .commit "$desc")" || die "$desc has no commit"
sha="$(jq -er .sha256 "$desc")" || die "$desc has no sha256"
size="$(jq -er .size "$desc")" || die "$desc has no size"
desc_name="$(basename "$desc")"
[ "${desc_name%.json}.raucb" = "$bundle" ] || die "$desc does not describe $bundle"
src="$(dirname "$desc")/$bundle"
[ -f "$src" ] || die "$src not found"
case "$version" in *-dirty*) die "$version was built from uncommitted changes; commit them and build again" ;; esac
case "$version" in
  *-broken-*) [ "$acceptance" = 1 ] || die "$version is a deliberately broken acceptance bundle; pass --acceptance" ;;
esac
[ ! -e "$ota/$bundle" ] && [ ! -e "$ota/$desc_name" ] || die "$bundle is already published"
git -C "$REPO" cat-file -e "$commit^{commit}" 2>/dev/null || die "commit $commit is not in $REPO"
[ "$(stat -c %s "$src")" = "$size" ] || die "$bundle is not $size bytes"
[ "$(sha256sum "$src" | cut -d' ' -f1)" = "$sha" ] || die "$bundle does not match its sha256"

# The newest valid description already published, if its commit is an ancestor of this one.
entries=""
for f in "$ota"/loopi-*.json; do
  [ -f "$f" ] || continue
  entry="$(jq -c 'select(type == "object" and (.built_at|type) == "string" and (.version|type) == "string"
                  and (.commit|type) == "string") | {built_at, version, commit}' "$f" 2>/dev/null)" || continue
  [ -n "$entry" ] && entries+="$entry"$'\n'
done
newest="$(printf '%s' "$entries" | jq -sc 'sort_by(.built_at) | last // empty')"
base_version=null
base_commit=""
if [ -n "$newest" ]; then
  candidate="$(jq -r .commit <<<"$newest")"
  if git -C "$REPO" cat-file -e "$candidate^{commit}" 2>/dev/null \
      && git -C "$REPO" merge-base --is-ancestor "$candidate" "$commit"; then
    base_version="$(jq -c .version <<<"$newest")"
    base_commit="$candidate"
  fi
fi
if [ -n "$base_commit" ]; then
  log="$(git -C "$REPO" log --reverse --format='%H%x09%s' "$base_commit..$commit" -- "${NOTE_PATHS[@]}")"
else
  log="$(git -C "$REPO" log --reverse --format='%H%x09%s' -n "$FIRST_NOTES" "$commit" -- "${NOTE_PATHS[@]}")"
fi
count="$(grep -c . <<<"$log" || true)"
truncated=false
if [ "$count" -gt "$MAX_NOTES" ]; then
  log="$(tail -n "$MAX_NOTES" <<<"$log")"
  truncated=true
fi
notes="$(jq -R -s -c 'split("\n") | map(select(length > 0) | split("\t") | {commit: .[0], subject: (.[1:] | join("\t"))})' <<<"$log")"

tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"; rm -f "$ota/.$bundle.tmp" "$ota/.$desc_name.tmp"' EXIT
jq --argjson notes "$notes" --argjson base "$base_version" --argjson truncated "$truncated" \
  '. + {notes_base: $base, notes: $notes, notes_truncated: $truncated}' "$desc" > "$tmp/desc.json"
# The bundle first: the brain lists only bundles that have a description.
cp "$src" "$ota/.$bundle.tmp" && mv "$ota/.$bundle.tmp" "$ota/$bundle"
cp "$tmp/desc.json" "$ota/.$desc_name.tmp" && mv "$ota/.$desc_name.tmp" "$ota/$desc_name"
echo "published $bundle ($(jq length <<<"$notes") notes$([ "$truncated" = true ] && echo ", truncated"))"
```

```bash
#!/usr/bin/env bash
# Move a device running a pre-P4a image (kernel at the root of /boot, rootfs on p2, p3 empty, no RAUC) to the A/B
# layout over SSH, without taking the SD card out (P4a design §10). This is the first OTA, done by hand: the new rootfs
# goes to slot B (p3) and gets a trial boot; its agent confirms it after the first heartbeat, exactly as after a web
# update. If the trial fails, the device comes back on the old system, untouched, and this can be run again.
# Usage: os/scripts/migrate-to-ab.sh <device-ip> <os/out/loopi-dev-<version>.json> <backup dir>
#   The .squashfs next to the .json is written to p3. /data/keys and /data/config are first copied to
#   <backup dir>/data-keys-config.tar (mode 600, never printed, never committed): the way back after a re-flash.
set -euo pipefail
die() { echo "migrate-to-ab: $*" >&2; exit 1; }
[ $# = 3 ] || { echo "usage: $0 <device-ip> <bundle.json> <backup dir>" >&2; exit 2; }
host="$1"; desc="$2"; backup="$3"
ssh_() { ssh -o BatchMode=yes -o ConnectTimeout=10 "root@$host" "$@"; }
version="$(jq -er .version "$desc")"
rootfs="${desc%.json}.squashfs"
[ -f "$rootfs" ] || die "$rootfs not found"
size="$(stat -c %s "$rootfs")"
sha="$(sha256sum "$rootfs" | cut -d' ' -f1)"

echo "== checks"
cmdline="$(ssh_ cat /proc/cmdline)"
case "$cmdline" in *rauc.slot=*) die "the device already boots an A/B slot; use the web update instead" ;; esac
case " $cmdline " in *" root=/dev/mmcblk0p2 "*) ;; *) die "unexpected root= on the device: $cmdline" ;; esac
ssh_ '[ -b /dev/mmcblk0p3 ]' || die "no /dev/mmcblk0p3 on the device"
ssh_ '! grep -q "^/dev/mmcblk0p3 " /proc/mounts' || die "/dev/mmcblk0p3 is mounted"
p3="$(ssh_ blockdev --getsize64 /dev/mmcblk0p3)"
[ "$p3" -ge "$size" ] || die "p3 ($p3 bytes) is smaller than the rootfs ($size bytes)"
free_kb="$(ssh_ df -k /boot | awk 'NR == 2 { print $4 }')"
[ "$free_kb" -ge 12000 ] || die "only ${free_kb} KiB free on /boot; slot B needs about 9 MiB"

echo "== backup of /data/keys and /data/config to $backup"
mkdir -p "$backup"
chmod 700 "$backup"
( umask 077; ssh_ tar -C /data -cf - keys config > "$backup/data-keys-config.tar" )
tar -tf "$backup/data-keys-config.tar" | grep -q '^keys/' || die "the backup has no keys/"

echo "== a dev agent in /data/dev predates OTA and would never confirm the trial: set it aside"
ssh_ 'if [ -e /data/dev/loopi-agent ]; then mv /data/dev/loopi-agent /data/dev/loopi-agent.pre-ab; echo moved; fi'

echo "== writing the new rootfs ($version) to slot B"
ssh_ "dd of=/dev/mmcblk0p3 bs=1M conv=fsync 2>/dev/null" < "$rootfs"
remote_sha="$(ssh_ "head -c $size /dev/mmcblk0p3 | sha256sum" | cut -d' ' -f1)"
[ "$remote_sha" = "$sha" ] || die "slot B does not hold what was sent (sha256 differs)"

echo "== boot files for slot B and tryboot.txt, by the new system's own loopi-boot"
ssh_ 'set -u; m="$(mktemp -d)"; mount -t squashfs -o ro /dev/mmcblk0p3 "$m"; rc=0
      "$m/usr/libexec/loopi/loopi-boot" install-files B "$m" || rc=$?; umount "$m"; rmdir "$m"; exit $rc'
ssh_ 'grep -qx "os_prefix=b/" /boot/tryboot.txt' || die "tryboot.txt does not boot b/"

echo "== pending update state for the new agent"
printf '{"command_id":null,"bundle":null,"version":"%s","target_slot":"B","phase":"rebooting","error":null}' "$version" \
  | ssh_ 'mkdir -p /data/ota && cat > /data/ota/pending.json.tmp && sync && mv /data/ota/pending.json.tmp /data/ota/pending.json && sync'

echo "== trial boot of slot B"
ssh_ 'systemctl reboot --reboot-argument="0 tryboot"' || true
for _ in $(seq 1 60); do sleep 5; ssh_ true 2>/dev/null && break; done
cmdline="$(ssh_ cat /proc/cmdline)" || die "the device did not come back within 5 minutes"
case "$cmdline" in
  *rauc.slot=B*) echo "slot B is running; waiting for the agent to confirm it" ;;
  *) die "the trial did not start: the device is back on the old system (nothing changed); see its journal" ;;
esac
for _ in $(seq 1 60); do
  if ssh_ 'grep -qx "os_prefix=b/" /boot/config.txt'; then
    echo "== done: slot B ($version) is confirmed. The first web update will write slot A."
    exit 0
  fi
  sleep 5
done
die "slot B was not confirmed within 5 minutes; the guard reboots into the old system 10 minutes after boot"
```
