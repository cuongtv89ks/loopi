# P3b — Daily vlog timelapse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** after the evening recap the brain makes the day's vlog by itself:
- a 60–90 s MP4 of the hours with activity, sped up;
- Ken Burns pictures of the highlights;
- a few seconds of their sound;
- soft subtitles.

The owner watches and downloads it on a new Vlog page and on the Day page.

**Architecture:**
- A planner (every 15 min) asks for a day's vlog once its recap exists.
- `write_vlog_script` holds the text model's lock and reads the day's material (active recordings, highlight candidates). The recap's model writes a JSON script: a title plus up to 10 highlights by short ref, with ≤ 3 sound clips. A rule script is the fallback.
- `render_vlog` has its own lock and runs a renderer verified on the brain's ffmpeg 7.1.5:
  - one ffmpeg samples the day's MP4 segments into a 24 fps timelapse split at the highlights;
  - Pillow + `zoompan` make each Ken Burns still;
  - one ffmpeg concatenates the parts and muxes AAC sound and a `mov_text` track;
  - Python writes a WebVTT copy for the browser.
- Files live under `media/vlog/YYYY/MM/DD/` and are kept for ever. "Quên khoảng thời gian" deletes the touched days' vlogs, and the planner makes them again.

**Tech Stack:** Python 3.13, Procrastinate 3.10, psycopg 3, pydantic 2, Pillow, ffmpeg 7.1 (libx264, aac, mov_text, zoompan), FastAPI/Jinja/HTMX, pytest + testcontainers.

**Spec:**
- `docs/superpowers/specs/2026-10-17-p3-mcp-vlog-design.md` §1, §2, §4 (P3 design, approved 2026-10-17).
- The binding spec `docs/superpowers/specs/2026-10-14-loopi-design.md`: §9.2 (23:30), §9.4 (`vlog`), §9.5, §10.3, §10.6 (Vlog page), §14 (P3 row), D15, D19, D23, D25.

## Global Constraints

- **D25:** speed up only the hours with activity. The total is 60–90 s and never under 20 s when the day has enough material. A day without activity gets no vlog (state `empty`, page "Không có hoạt động").
- **Active recording:** a video item of the day with `analysis_state = 'done'`, raw file kept (`raw_deleted_at IS NULL`), an MP4 view (`view_path`), and a moment within **5 minutes** of it.
- **Lengths:**
  - timelapse `T = clamp(0.25 s × active segments, 10 s, 60 s)`;
  - each highlight picture **3 s**, lengthened up to **5 s** when the total would be under 20 s;
  - no picture and `T < 20` → `T = 20` (the renderer still never selects more frames than exist).
- **Highlight candidates:**
  - a marker ±30 s, with the nearest keyframe within 30 s;
  - a keyframe whose caption has `notable = true`;
  - a dense conversation: a 5-minute window with ≥ 6 speech moments, using the keyframe nearest its centre.
- **Scoring:** marker 3, notable 2, conversation 1 + min(count, 20)/10. Candidates closer than 2 min merge; the higher score stays. At most **40** candidates go to the model, each with ≤ 200 characters of text, named `H1`… in time order.
- **The script:**
  - the recap task's route (`qwen3:8b`, D23), JSON schema;
  - title ≤ 80 characters; 6–10 highlights, each with a line ≤ 120 characters;
  - ≤ **3** sound clips, only where the candidate has kept raw audio.
- **The fallback rule script:** 8 best candidates, title "Ngày dd/mm", lines from the candidates' text, sound for the first 2 conversations. `model_version = "rule"`. Every evening has a vlog.
- **Output:**
  - MP4, 1280×720, 24 fps, H.264 `libx264 -preset veryfast -crf 26 -threads 2`, `yuv420p` / tv range / bt709;
  - AAC mono 48 kHz 96 kbit/s; a `mov_text` subtitle track (language `vie`); `-movflags +faststart`;
  - a WebVTT file with the same cues next to it;
  - path `vlog/YYYY/MM/DD/<YYYY-MM-DD>.mp4` (and `.vtt`) under the media root.
- **Sound:** ≤ 3 clips, each ≤ 8 s (≥ 1 s or dropped), cut from the normalised playback copy (D19, `media.audio_view_path`, made with `media.normalise_audio` when missing). Fades of 0.3 s. Silence elsewhere.
- **Jobs:**
  - the script job takes lock `llm` at priority −10;
  - the render job takes lock `vlog` at priority −10, with a 20-minute timeout and at most 3 runs (`RetryStrategy(max_attempts=2)`);
  - both use queue `understand` and queueing lock `vlog:<day>`;
  - the planner is periodic on queue `light`.
- **Kept for ever (§9.5):** retention never touches `vlog/`. "Quên khoảng thời gian" deletes the vlog rows and both files of every day it touches, after its commit, through `media.remove_files`. A vlog rendered while a forget ran is never stored (the `forgotten()` count checked under `lock_day`).
- **Privacy:** a vlog never leaves the brain. It is served only behind the web's basic auth, and the MCP server never exposes it. No subtitle, transcript, caption or script text reaches a log line or an error message. Render errors read `render failed at <step> (ffmpeg exit <n>)`.
- **Robustness:**
  - Every MP4, JPEG and Opus input is checked in pure Python before ffmpeg runs, and a bad one is skipped.
  - Every ffmpeg output's frame count is checked: the concat demuxer ends silently, with exit 0, at a file that vanished.
  - Temporary files go under `vlog/.tmp/` and are removed whatever happens. The final files appear by atomic rename.
- **UI and process:**
  - UI text is Vietnamese. Every POST needs `HX-Request: true`, every form has `method="post"`, and text written by a model is HTML-escaped.
  - TDD, coverage ≥ 80 % (99 % now), conventional commits with the session trailers; never touch `/home/soul/loopi-p2`, `-p2b`, `-p2c` or `/home/soul/loopi-data`.
  - Tasks 1–5 never run `docker compose`, `deploy/smoke.sh` or any Docker command (testcontainers excepted).

## Review Focus

1. **A segment disappears or breaks between the material read and the render**, through retention, a forget or a truncated file. The renderer skips bad inputs before ffmpeg runs. If a file vanishes mid-run, the frame-count check raises `RenderError` and the job retries with fresh material. It never stores a shortened day. Task 3 tests a file deleted after inspection, and Task 4 tests a retry.
2. **A forget during a render** must leave no stored vlog of forgotten material and no orphan file. Task 4 tests this with the `forgotten()` count bumped between render and store.
3. **A day with no activity** (night, paused, empty room) is stored as `empty` once and not planned again until its recap changes. A day whose raw video is gone renders a keyframe slideshow. Task 4 tests both.
4. **A useless model answer** (unknown or duplicate refs, every highlight with sound, a blank title, invalid JSON, the server down) still gives a vlog: refs dropped, ≤ 3 clips, the default title, the rule script. Task 2 tests this.
5. **The browser.** The MP4 seeks with Range requests (206). Downloading gives `Content-Disposition: attachment`. The VTT escapes `<`, `&` and `-->` in model text, the page escapes the title, and a vlog path in the database outside the media root answers 404. Task 5 tests this.

## Rulings taken while writing this plan

Copy these into the ledger before Task 1, each as: decision — why — cost if wrong.

- **R1** The vlog script uses the `recap` route (same model, D23), not a new provider task. Adding a task would change `providers.yaml`, the provider router and the spec's provider table for one prompt. Cost if wrong: the vlog cannot get its own model without a config change.
- **R2** The renderer is the prototype verified on 2026-10-17, transcribed. It ran on the brain image's ffmpeg 7.1.5: 240 real 1080p 2 fps segments plus 10 stills in **152 s wall / 212 s CPU, peak 198 MB, 12.7 MB out**, plus robustness cases. Its error message is reduced to step and exit code. The stderr tail is kept on the exception, never logged or stored. Cost if wrong: an ffmpeg upgrade may need re-measuring.
- **R3** Keyframe-only decoding (`-skip_frame nokey`) is used when the day has ≥ 3 keyframes per output frame. Measured: 2.3× less CPU, with steps of 9–12 s instead of 10 s. Otherwise every frame is decoded. Cost if wrong: a slightly uneven timelapse pace on long days.
- **R4** Two jobs per day share the queueing lock `vlog:<day>`. The script job adds its render job in the same transaction that stores the script. The planner re-defers a render for a row left `scripted` with no job (a crash in between). Cost if wrong: none.
- **R5** Keep the vlog that is already there until its replacement is stored. A rebuild keeps `path`, `duration_s` and `generated_at` while the row is `scripted` again. The Vlog page shows "đang dựng lại" next to the old video. Cost if wrong: an outdated vlog is visible for a few minutes.
- **R6** The planner needs the day's recap (§9.2 "23:30: recap … dựng vlog"). It asks again once when the recap is rewritten after the vlog's script, and once per stale mark. Earlier days catch up one per run, newest first; today is never held back. "Dựng lại vlog" asks directly, even without a recap. Cost if wrong: a day without a recap gets no automatic vlog.
- **R7** A manual "Tạo lại recap" at noon today makes a noon vlog, and the 23:30 recap makes it again. Cost if wrong: one extra render, at most 3 minutes of CPU.
- **R8** The subtitle cue of a picture is its line. For a conversation highlight it is the line plus the quoted transcript sentence (≤ 120 characters), in the original language. The title shows for the first 3 s. Cost if wrong: Vietnamese and Korean subtitles mixed in one vlog.
- **R9** A day with no active recording but with keyframes renders a slideshow of at most 240 keyframes spread over the day, 0.25 s each (≤ 60 s). This covers a day whose raw video retention deleted, and a day whose only recordings had no moment. Cost if wrong: a short slideshow instead of nothing.
- **R10** The Vlog page's player plays `/vlog/<day>.mp4` with a `<track>` of `/vlog/<day>.vtt`, because browsers do not show `mov_text`. The download is the same MP4, carrying its `mov_text`. Cost if wrong: none.
- **R11** The vlog's sound comes from the normalised playback copy. The render job makes the copy when it is missing, exactly as the `/audio` route does, and removes it again if the item was forgotten meanwhile. Cost if wrong: one extra Opus file per conversation highlight, deleted with its item.

```sql
-- P3b: one vlog per local day (spec §9.4 `vlog`, §10.3, D15, D25; P3 design §4). Kept for ever (§9.5); "Quên khoảng
-- thời gian" deletes the vlogs of the days it touches (they may show and say what is forgotten), and the planner makes
-- them again from what is left. A rebuild keeps path/duration/generated_at of the vlog being replaced until the new
-- file is stored (state goes back to 'scripted' meanwhile).
CREATE TABLE vlog (
    day            DATE PRIMARY KEY,
    state          TEXT NOT NULL CHECK (state IN ('scripted', 'rendered', 'empty')),
    script         JSONB,                 -- title and highlights (times, keyframes, lines, sound), see vlog/script.py
    model_version  TEXT,                  -- the script's model, or 'rule' for the fallback script
    source         TEXT CHECK (source IN ('video', 'keyframes')),
    path           TEXT,                  -- vlog/YYYY/MM/DD/<day>.mp4 under the media root; .vtt beside it
    duration_s     REAL,
    generated_at   TIMESTAMPTZ,           -- when the current file was stored
    scripted_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    stale          BOOLEAN NOT NULL DEFAULT FALSE,
    error          TEXT,
    error_at       TIMESTAMPTZ
);
```

```python
"""What a day's vlog is made of (spec §10.3, D25; P3 design §4.2), read only:
- the recordings of the hours with activity (a moment within ACTIVITY_MARGIN, MP4 view present, raw kept);
- the day's keyframes, spread over the day (the slideshow when no recording is active, e.g. after retention);
- the highlight candidates — marked moments, notable pictures, dense conversations — each with a keyframe picture,
  scored, merged when close, at most CANDIDATES_MAX, named H1… in time order (what the script model chooses from).
Times are UTC datetimes; paths are relative to the media root."""
from __future__ import annotations

import bisect
import datetime as dt
from dataclasses import dataclass

from psycopg_pool import AsyncConnectionPool

from ..days import day_bounds_utc
from ..llm import clip, spread

ACTIVITY_MARGIN = dt.timedelta(minutes=5)  # a recording is active with a moment within 5 minutes of it
MARKER_REACH = dt.timedelta(seconds=30)  # a marked moment's picture: the nearest keyframe within ±30 s
TALK_WINDOW = dt.timedelta(minutes=5)
TALK_MIN = 6  # speech moments within TALK_WINDOW that make a dense conversation
MERGE_GAP = dt.timedelta(minutes=2)  # candidates closer than this are one highlight (the higher score stays)
CANDIDATES_MAX = 40
TEXT_MAX = 200
SLIDES_MAX = 240  # keyframes in a slideshow day (0.25 s each: at most 60 s)
SCORE = {"marker": 3.0, "notable": 2.0, "talk": 1.0}
AUDIO_LEAD_S = 0.5  # a conversation's sound starts this much before its longest line


@dataclass(frozen=True)
class Segment:
    item_id: str
    path: str  # the MP4 view, relative to the media root
    start: dt.datetime


@dataclass(frozen=True)
class Frame:
    keyframe_id: str
    path: str  # the JPEG, relative to the media root
    at: dt.datetime


@dataclass(frozen=True)
class Candidate:
    ref: str  # H1… in time order: how the script model names it
    kind: str  # marker | notable | talk
    at: dt.datetime
    frame: Frame
    text: str
    score: float
    audio_item: str | None = None  # an audio item whose sound can play under the picture (talk only)
    audio_offset: float = 0.0  # seconds into that item


@dataclass(frozen=True)
class Material:
    day: dt.date
    segments: list[Segment]
    frames: list[Frame]
    candidates: list[Candidate]

    @property
    def empty(self) -> bool:
        return not self.segments and not self.frames


_SEGMENTS = """
SELECT i.id, i.view_path, i.started_at FROM item i
 WHERE i.kind = 'video' AND i.analysis_state = 'done' AND i.raw_deleted_at IS NULL AND i.view_path IS NOT NULL
   AND i.started_at >= %(start)s AND i.started_at < %(end)s
   AND EXISTS (SELECT 1 FROM moment m WHERE m.ts_start >= i.started_at - %(margin)s
                                        AND m.ts_start <= i.ended_at + %(margin)s)
 ORDER BY i.started_at, i.id"""
_FRAMES = "SELECT id, path, ts, caption FROM keyframe WHERE ts >= %(start)s AND ts < %(end)s ORDER BY ts, id"
_MARKERS = """
SELECT ts_start, text FROM moment WHERE kind = 'marker' AND ts_start >= %(start)s AND ts_start < %(end)s
 ORDER BY ts_start, id"""
_SPEECH = """
SELECT m.ts_start, m.text, m.item_id, i.started_at AS item_start, i.raw_deleted_at
  FROM moment m LEFT JOIN item i ON i.id = m.item_id AND i.kind = 'audio'
 WHERE m.kind = 'speech' AND m.ts_start >= %(start)s AND m.ts_start < %(end)s ORDER BY m.ts_start, m.id"""


def nearest(frames: list[Frame], at: dt.datetime, reach: dt.timedelta) -> Frame | None:
    """The frame closest to ``at`` within ``reach`` (frames sorted by time), or None."""
    times = [f.at for f in frames]
    i = bisect.bisect_left(times, at)
    best = None
    for f in frames[max(0, i - 1):i + 1]:
        if abs(f.at - at) <= reach and (best is None or abs(f.at - at) < abs(best.at - at)):
            best = f
    return best


def talk_windows(rows: list[dict]) -> list[list[dict]]:
    """Dense conversations: runs of at least TALK_MIN speech lines starting within TALK_WINDOW of the first, taken
    greedily in time order (rows sorted by ``ts_start``); a line belongs to one window at most."""
    windows, i = [], 0
    while i < len(rows):
        j = i
        while j + 1 < len(rows) and rows[j + 1]["ts_start"] < rows[i]["ts_start"] + TALK_WINDOW:
            j += 1
        if j - i + 1 >= TALK_MIN:
            windows.append(rows[i:j + 1])
            i = j + 1
        else:
            i += 1
    return windows


def merge(candidates: list[Candidate]) -> list[Candidate]:
    """At most CANDIDATES_MAX candidates, no two closer than MERGE_GAP (the higher score stays, then the earlier),
    in time order and named H1…."""
    kept: list[Candidate] = []
    for c in sorted(candidates, key=lambda c: (-c.score, c.at)):
        if all(abs(c.at - k.at) >= MERGE_GAP for k in kept):
            kept.append(c)
        if len(kept) == CANDIDATES_MAX:
            break
    kept.sort(key=lambda c: c.at)
    return [Candidate(f"H{n}", c.kind, c.at, c.frame, c.text, c.score, c.audio_item, c.audio_offset)
            for n, c in enumerate(kept, start=1)]


def _caption_text(caption: dict | None) -> str:
    if not isinstance(caption, dict):
        return ""
    for key in ("activity", "scene"):
        if isinstance(caption.get(key), str) and caption[key].strip():
            return caption[key].strip()
    return ""


async def vlog_material(pool: AsyncConnectionPool, day: dt.date, zone) -> Material:
    start, end = day_bounds_utc(day, zone)
    params = {"start": start, "end": end, "margin": ACTIVITY_MARGIN}
    async with pool.connection() as conn:
        segments = [Segment(r["id"], r["view_path"], r["started_at"])
                    for r in await (await conn.execute(_SEGMENTS, params)).fetchall()]
        frame_rows = await (await conn.execute(_FRAMES, params)).fetchall()
        markers = await (await conn.execute(_MARKERS, params)).fetchall()
        speech = await (await conn.execute(_SPEECH, params)).fetchall()
    frames = [Frame(r["id"], r["path"], r["ts"]) for r in frame_rows]
    found: list[Candidate] = []
    for m in markers:
        frame = nearest(frames, m["ts_start"], MARKER_REACH)
        if frame is not None:
            found.append(Candidate("", "marker", m["ts_start"], frame, clip(m["text"], TEXT_MAX), SCORE["marker"]))
    for r, frame in zip(frame_rows, frames):
        caption = r["caption"]
        if isinstance(caption, dict) and caption.get("notable") is True:
            found.append(Candidate("", "notable", frame.at, frame, clip(_caption_text(caption), TEXT_MAX),
                                   SCORE["notable"]))
    for window in talk_windows(speech):
        first, last = window[0]["ts_start"], window[-1]["ts_start"]
        centre = first + (last - first) / 2
        frame = nearest(frames, centre, TALK_WINDOW)
        if frame is None:
            continue
        longest = max(window, key=lambda r: len(r["text"] or ""))
        audio, offset = None, 0.0
        if longest["item_id"] and longest["item_start"] is not None and longest["raw_deleted_at"] is None:
            audio = longest["item_id"]
            offset = max(0.0, (longest["ts_start"] - longest["item_start"]).total_seconds() - AUDIO_LEAD_S)
        found.append(Candidate("", "talk", centre, frame, clip(longest["text"] or "", TEXT_MAX),
                               SCORE["talk"] + min(len(window), 20) / 10, audio, offset))
    return Material(day, segments, spread(frames, SLIDES_MAX), merge(found))
```

```python
"""The vlog's script (spec §10.3 "LLM viết kịch bản dưới dạng JSON"; P3 design §4.3): a Vietnamese title and up to
HIGHLIGHTS_MAX highlights chosen among the day's candidates by their refs, each with one line, at most AUDIO_MAX
with their own sound. Written by the recap's model (D23, ruling R1); when the model cannot answer usefully, a rule
picks them, so every evening has a vlog. Nothing here is logged but counts."""
from __future__ import annotations

import datetime as dt
import logging
from dataclasses import dataclass

from pydantic import BaseModel

from ..llm import AnswerInvalid, clipped, parse_answer
from ..providers.base import ProviderError, ProviderUnavailable
from ..providers.router import Router
from .material import Candidate, Material

log = logging.getLogger(__name__)

TITLE_MAX = 80
LINE_MAX = 120
HIGHLIGHTS_MAX = 10
HIGHLIGHTS_RULE = 8
AUDIO_MAX = 3
AUDIO_RULE = 2
SCRIPT_MAX_TOKENS = 800
RULE = "rule"
KIND_LABELS = {"marker": "đánh dấu", "notable": "khung hình đáng chú ý", "talk": "hội thoại"}
SCRIPT_SYSTEM = (
    "Bạn dựng kịch bản cho một vlog ngắn (khoảng một phút) về một ngày ở nhà, từ danh sách khoảnh khắc nổi bật. "
    "Chọn 6 đến 10 khoảnh khắc đáng xem nhất bằng mã của chúng (H1, H2, …), mỗi khoảnh khắc một câu mô tả ngắn, "
    "tự nhiên, bằng tiếng Việt, không bịa thêm điều không có trong mô tả. Chỉ đặt audio=true cho tối đa 3 khoảnh "
    "khắc có ghi '(có tiếng)'. Đặt một tiêu đề ngắn cho cả ngày. Lời nói trong danh sách do máy nhận dạng, có thể sai."
)
SCRIPT_SCHEMA = {
    "type": "object",
    "properties": {
        "title": {"type": "string", "maxLength": TITLE_MAX},
        "highlights": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "ref": {"type": "string"},
                    "line": {"type": "string", "maxLength": LINE_MAX},
                    "audio": {"type": "boolean"},
                },
                "required": ["ref", "line", "audio"],
            },
            "maxItems": HIGHLIGHTS_MAX,
        },
    },
    "required": ["title", "highlights"],
}


class HighlightAnswer(BaseModel):
    ref: str
    line: clipped(LINE_MAX)
    audio: bool = False


class ScriptAnswer(BaseModel):
    title: clipped(TITLE_MAX)
    highlights: list[HighlightAnswer]


@dataclass(frozen=True)
class Highlight:
    candidate: Candidate
    line: str
    audio: bool


@dataclass(frozen=True)
class Script:
    title: str
    highlights: list[Highlight]
    model_version: str


def default_title(day: dt.date) -> str:
    return f"Ngày {day:%d/%m}"


def script_messages(material: Material, zone) -> list[dict]:
    lines = []
    for c in material.candidates:
        sound = " (có tiếng)" if c.audio_item else ""
        lines.append(f"{c.ref} · {c.at.astimezone(zone):%H:%M} · {KIND_LABELS[c.kind]}{sound} · {c.text}")
    user = f"Ngày {material.day:%d/%m/%Y}. Các khoảnh khắc:\n" + "\n".join(lines)
    return [{"role": "system", "content": SCRIPT_SYSTEM}, {"role": "user", "content": user}]


def _cap_audio(highlights: list[Highlight], limit: int) -> list[Highlight]:
    out, used = [], 0
    for h in highlights:
        audio = h.audio and h.candidate.audio_item is not None and used < limit
        used += audio
        out.append(Highlight(h.candidate, h.line, audio))
    return out


def resolve(answer: ScriptAnswer, material: Material) -> list[Highlight]:
    """The answer's highlights that name a candidate, each candidate once, in time order, at most HIGHLIGHTS_MAX,
    sound only where the candidate has it and on AUDIO_MAX of them at most."""
    by_ref = {c.ref: c for c in material.candidates}
    chosen: dict[str, Highlight] = {}
    for h in answer.highlights:
        ref = h.ref.strip().upper()
        if ref in by_ref and ref not in chosen and h.line.strip():
            chosen[ref] = Highlight(by_ref[ref], h.line.strip(), h.audio)
    ordered = sorted(chosen.values(), key=lambda h: h.candidate.at)[:HIGHLIGHTS_MAX]
    return _cap_audio(ordered, AUDIO_MAX)


def rule_script(material: Material) -> Script:
    """The fallback: the HIGHLIGHTS_RULE best candidates in time order, their own text as lines, sound on the first
    AUDIO_RULE conversations that have it."""
    best = sorted(material.candidates, key=lambda c: (-c.score, c.at))[:HIGHLIGHTS_RULE]
    ordered = sorted(best, key=lambda c: c.at)
    highlights = _cap_audio([Highlight(c, c.text[:LINE_MAX], c.kind == "talk") for c in ordered], AUDIO_RULE)
    return Script(default_title(material.day), highlights, RULE)


async def write_script(router: Router, material: Material, zone) -> Script:
    """The model's script, or the rule's when the model is unavailable, fails or names no usable candidate."""
    if not material.candidates:
        return rule_script(material)
    try:
        result = await router.chat("recap", script_messages(material, zone), json_schema=SCRIPT_SCHEMA,
                                   temperature=0.0, max_tokens=SCRIPT_MAX_TOKENS)
        answer = parse_answer(result.text, ScriptAnswer)
    except (ProviderUnavailable, ProviderError, AnswerInvalid) as exc:
        log.warning("vlog script of %s: the rule script is used (%s)", material.day, type(exc).__name__)
        return rule_script(material)
    highlights = resolve(answer, material)
    if not highlights:
        log.warning("vlog script of %s: the model named no usable highlight; the rule script is used", material.day)
        return rule_script(material)
    return Script(answer.title.strip() or default_title(material.day), highlights, result.model_version)


def to_json(written: Script) -> dict:
    """The script as stored on the vlog row (times in UTC ISO 8601)."""
    return {
        "title": written.title,
        "highlights": [
            {
                "ref": h.candidate.ref,
                "kind": h.candidate.kind,
                "at": h.candidate.at.astimezone(dt.UTC).isoformat(),
                "keyframe_id": h.candidate.frame.keyframe_id,
                "jpeg": h.candidate.frame.path,
                "line": h.line,
                "speech": h.candidate.text if h.candidate.kind == "talk" else None,
                "audio_item": h.candidate.audio_item if h.audio else None,
                "audio_offset": h.candidate.audio_offset,
            }
            for h in written.highlights
        ],
    }
```

```python
"""The vlog renderer (spec §10.3, D15; P3 design §4.4; ruling R2): a prototype verified on 2026-10-17 on the brain
image's ffmpeg 7.1.5 (240 real 1080p 2 fps segments + 10 stills: 152 s wall, 212 s CPU, peak 198 MB), transcribed.

Pipeline (every ffmpeg call is built by a pure function returning its argv):
  0. inputs are checked in pure Python — MP4 frame/keyframe counts (moov parse), Ogg Opus duration, JPEG decode
     (Pillow); a bad input is skipped here, before any ffmpeg runs.
  1. base track: ONE ffmpeg over a concat-demuxer list of the day's segments, keeping exactly N = T*24 frames (uniform
     select), split into chunks at the stills' positions (forced keyframes + the segment muxer). Without segments: a
     keyframe slideshow (Pillow -> rawvideo pipe), 0.25 s per JPEG, split the same way.
  2. Ken Burns stills: Pillow -> one 1920x1080 rawvideo frame on stdin -> pre-scale x4 -> zoompan, D s at 24 fps.
  3. assembly: concat demuxer over [chunk, still, chunk, still, ...] with -c:v copy, one AAC track (silence + clips cut
     from the normalised Opus copies, faded, delayed to their stills) and a mov_text track from an SRT the code writes;
     -movflags +faststart. A WebVTT file with the same cues is written in Python (browsers do not show mov_text).

Every part is encoded with the same libx264 settings and output tags, so their avcC (SPS/PPS), timebase and SAR are
byte-identical, which is what makes `-c:v copy` concatenation valid. Success never depends on ffmpeg's stderr: each
step checks the exit code and then re-reads its output with the pure-Python MP4 parser (frame count, track kinds).
The stderr tail is kept on RenderError for debugging but is never put in its message: errors are stored and shown.
"""

from __future__ import annotations

# --------------------------------------------------------------------------------------------- constants

FPS = 24
OUT_W, OUT_H = 1280, 720
KB_SRC_W, KB_SRC_H = 1920, 1080  # canvas Pillow hands to zoompan
KB_PRESCALE = 4  # 1920x1080 canvas x4 = 7680x4320 = 6x the output width: zoompan jitter ~0.2 px/frame
#                  (measured: no pre-scale 1.3 px, 2560w 1.0 px, 3840w 0.7 px, 5120w 0.6 px, 7680w 0.17 px)
SLIDE_SECONDS = 0.25
AUDIO_FADE = 0.3
AUDIO_CLIP_MAX = 8.0
AUDIO_CLIP_MIN = 1.0  # shorter remainders are dropped rather than played as a blip
# Keyframe-only decoding (-skip_frame nokey) picks the nearest keyframe instead of the exact frame, so each
# output step is off by up to one GOP: relative speed jitter <= N/keyframes. Require >= 3 keyframes per output
# frame (<= 33 % jitter); measured with GOP 3 s on a 4 h day (3.3 keys/frame): steps 9-12 s instead of 10 s.
KEYFRAMES_PER_OUTPUT_MIN = 3

FFMPEG = "ffmpeg"
BASE = [FFMPEG, "-hide_banner", "-nostats", "-loglevel", "error", "-y"]

# Identical encoder settings + output tags for EVERY part => identical avcC => -c:v copy concat is valid.
X264 = [
    "-c:v", "libx264", "-preset", "veryfast", "-crf", "26", "-threads", "2",
    "-pix_fmt", "yuv420p", "-color_range", "tv", "-colorspace", "bt709",
    "-video_track_timescale", str(FPS * 512),  # 12288, same timescale in every part
]
# Fit inside 1280x720 keeping aspect, pad to exactly 1280x720, square pixels, limited range BT.709 4:2:0.

    f"scale={OUT_W}:{OUT_H}:force_original_aspect_ratio=decrease:force_divisible_by=2"
    f":out_range=tv:out_color_matrix=bt709,"
    f"pad={OUT_W}:{OUT_H}:(ow-iw)/2:(oh-ih)/2,setsar=1,format=yuv420p"

class RenderError(RuntimeError):
    """An ffmpeg step failed, or its output is not what it must be. The message names only the step and the exit
    code (it is stored and shown); ``stderr_tail`` keeps ffmpeg's last words for debugging, never logged."""

        super().__init__(f"{step}: ffmpeg exited {returncode}")
        self.step, self.returncode, self.stderr_tail = step, returncode, stderr_tail


class InvalidMedia(ValueError):
    """An input file that cannot be used (its message names the file, never its content)."""


# --------------------------------------------------------------------------------------------- MP4 parsing

@dataclass(frozen=True)
class Track:
    handler: str  # "vide", "soun", "sbtl"/"text"
    timescale: int
    duration: int  # in timescale units (mdhd)
    samples: int  # stsz sample_count = frames for video
    sync_samples: int  # stss entry_count (== samples when there is no stss box)

    @property
    def seconds(self) -> float:
        return self.duration / self.timescale if self.timescale else 0.0


def _boxes(f, start: int, end: int) -> Iterable[tuple[bytes, int, int]]:
    pos = start
    while pos + 8 <= end:
        f.seek(pos)
        size, kind = struct.unpack(">I4s", f.read(8))
        hdr = 8
        if size == 1:
            size, hdr = struct.unpack(">Q", f.read(8))[0], 16
        elif size == 0:
            size = end - pos
        if size < hdr or pos + size > end:
            raise InvalidMedia(f"truncated box {kind!r} at {pos}")
        yield kind, pos + hdr, pos + size
        pos += size


def _child(f, start: int, end: int, kind: bytes) -> tuple[int, int] | None:
    for k, s, e in _boxes(f, start, end):
        if k == kind:
            return s, e
    return None


def probe_mp4(path: Path) -> list[Track]:
    """Tracks of an MP4 from its moov box only (no decoding). Raises InvalidMedia when moov is missing
    (e.g. a recording cut before the moov was written) or any top-level box overruns the file."""
    try:
        with open(path, "rb") as f:
            size = f.seek(0, 2)
            moov = None
            for kind, s, e in _boxes(f, 0, size):
                if kind == b"moov":
                    moov = (s, e)
            if moov is None:
                raise InvalidMedia(f"{path}: no moov box")
            tracks = []
            for kind, s, e in _boxes(f, *moov):
                if kind != b"trak":
                    continue
                mdia = _child(f, s, e, b"mdia")
                if mdia is None:
                    continue
                hdlr, mdhd = _child(f, *mdia, b"hdlr"), _child(f, *mdia, b"mdhd")
                minf = _child(f, *mdia, b"minf")
                stbl = _child(f, *minf, b"stbl") if minf else None
                if not (hdlr and mdhd and stbl):
                    raise InvalidMedia(f"{path}: incomplete trak")
                f.seek(hdlr[0] + 8)
                handler = f.read(4).decode("latin-1")
                f.seek(mdhd[0])
                version = f.read(1)[0]
                if version == 1:
                    f.seek(mdhd[0] + 20)
                    timescale, duration = struct.unpack(">IQ", f.read(12))
                else:
                    f.seek(mdhd[0] + 12)
                    timescale, duration = struct.unpack(">II", f.read(8))
                stsz, stss = _child(f, *stbl, b"stsz"), _child(f, *stbl, b"stss")
                if stsz is None:
                    raise InvalidMedia(f"{path}: no stsz")
                f.seek(stsz[0] + 8)
                (samples,) = struct.unpack(">I", f.read(4))
                sync = samples
                if stss is not None:
                    f.seek(stss[0] + 4)
                    (sync,) = struct.unpack(">I", f.read(4))
                tracks.append(Track(handler, timescale, duration, samples, sync))
            return tracks
    except (OSError, struct.error) as exc:
        raise InvalidMedia(f"{path}: {exc}") from exc


def video_track(path: Path) -> Track:
    vids = [t for t in probe_mp4(path) if t.handler == "vide"]
    if len(vids) != 1 or vids[0].samples == 0:
        raise InvalidMedia(f"{path}: expected one non-empty video track")
    return vids[0]


# --------------------------------------------------------------------------------------------- Ogg Opus

def ogg_opus_duration(path: Path) -> float:
    """Playable seconds of an Ogg Opus file: (last granule - pre-skip) / 48000. Header reads only."""
    with open(path, "rb") as f:
        head = f.read(4096)
        if head[:4] != b"OggS":
            raise InvalidMedia(f"{path}: not Ogg")
        body = 27 + head[26]
        if head[body:body + 8] != b"OpusHead":
            raise InvalidMedia(f"{path}: not Opus")
        pre_skip = struct.unpack("<H", head[body + 10:body + 12])[0]
        size = f.seek(0, 2)
        f.seek(max(0, size - 65536))
        tail = f.read()
    i = tail.rfind(b"OggS")
    if i < 0 or i + 14 > len(tail):
        raise InvalidMedia(f"{path}: no final Ogg page")
    (granule,) = struct.unpack("<q", tail[i + 6:i + 14])
    return max(0.0, (granule - pre_skip) / 48000.0)


# --------------------------------------------------------------------------------------------- JPEG

def jpeg_canvas(path: Path, w: int, h: int) -> bytes:
    """Decode a JPEG with Pillow (EXIF orientation, CMYK/grey/progressive, any size), fit it into a w x h
    black canvas and return rgb24 bytes. Raises InvalidMedia for truncated/unreadable files -- ffmpeg would
    exit 0 on a truncated JPEG and silently render a half-grey frame."""
    try:
        with Image.open(path) as im:
            im.draft("RGB", (w, h))  # DCT-domain downscale of huge JPEGs (never below w x h)
            im = ImageOps.exif_transpose(im).convert("RGB")
            return ImageOps.pad(im, (w, h), method=Image.Resampling.BICUBIC, color=(0, 0, 0)).tobytes()
    except (OSError, ValueError, Image.DecompressionBombError) as exc:
        raise InvalidMedia(f"{path}: {exc}") from exc


# --------------------------------------------------------------------------------------------- text files

def concat_list(paths: Iterable[Path]) -> str:
    """concat-demuxer script; single quotes in paths are escaped as '\\''."""
    lines = ["ffconcat version 1.0"]
    for p in paths:
        q = str(Path(p).resolve()).replace("'", "'\\''")
        lines.append(f"file '{q}'")
    return "\n".join(lines) + "\n"


@dataclass(frozen=True)
class Cue:
    start: float
    end: float
    text: str


def _ts(seconds: float, sep: str) -> str:
    ms = round(seconds * 1000)
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02d}:{m:02d}:{s:02d}{sep}{ms:03d}"


def srt_text(cues: Sequence[Cue]) -> str:
    return "".join(f"{i}\n{_ts(c.start, ',')} --> {_ts(c.end, ',')}\n{c.text}\n\n"
                   for i, c in enumerate(cues, 1))


def vtt_text(cues: Sequence[Cue]) -> str:
    def esc(t: str) -> str:
        return t.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;").replace("-->", "--&gt;")
    body = "".join(f"{_ts(c.start, '.')} --> {_ts(c.end, '.')}\n{esc(c.text)}\n\n" for c in cues)
    return "WEBVTT\n\n" + body


# --------------------------------------------------------------------------------------------- argv builders

def uniform_select(n_out: int, n_in: int) -> str:
    """select expression keeping exactly n_out of n_in frames, evenly spread: frame k kept iff
    (k*n_out mod n_in) < n_out. Quoted so the commas survive filtergraph parsing."""
    return f"select='lt(mod(n*{n_out},{n_in}),{n_out})'"


def _split_args(out_pattern: Path, boundaries: Sequence[int]) -> list[str]:
    """Output args for one file, or for chunks split exactly at the given output-frame numbers."""
    if not boundaries:
        return [str(out_pattern).replace("%03d", "000")]
    frames = ",".join(str(b) for b in boundaries)
    keys = "+".join(f"eq(n,{b})" for b in boundaries)
    return ["-force_key_frames", f"expr:{keys}", "-f", "segment", "-segment_format", "mp4",
            "-segment_frames", frames, "-reset_timestamps", "1", str(out_pattern)]


def timelapse_argv(list_path: Path, out_pattern: Path, *, n_out: int, n_in: int, keyframes_only: bool,
                   boundaries: Sequence[int] = (), decode_threads: int = 2) -> list[str]:
    """One ffmpeg over the concat list. n_in = frames (or keyframes when keyframes_only) in the list.
    setpts=N/(24*TB) repacks the kept frames at 1/24 s; `fps=24` then only sets the link frame rate (no
    dup/drop because timestamps already sit on the grid). Do NOT use `-r 24` instead: frames keep their 0.5 s
    duration and ffmpeg's cfr logic duplicated 11 of 144 frames and dropped the end of the day (measured).
    No tpad here: the concat demuxer treats a file it cannot open as END OF INPUT with exit code 0, so a short
    output must stay short and be caught by the frame-count check, not padded over."""
    vf = f"{uniform_select(n_out, n_in)},setpts=N/({FPS}*TB),fps={FPS},{NORMALISE}"
    return [*BASE, "-nostdin", "-threads", str(decode_threads),
            *(["-skip_frame", "nokey"] if keyframes_only else []),
            "-f", "concat", "-safe", "0", "-i", str(list_path),
            "-map", "0:v:0", "-an", "-sn", "-dn", "-vf", vf, "-fps_mode", "passthrough",
            "-frames:v", str(n_out), *X264, *_split_args(out_pattern, boundaries)]


def slideshow_argv(out_pattern: Path, *, n_images: int, boundaries: Sequence[int] = ()) -> list[str]:
    """rgb24 1280x720 frames on stdin, one per JPEG, each held SLIDE_SECONDS at 24 fps."""
    per = round(SLIDE_SECONDS * FPS)
    vf = (f"setpts=N/({1 / SLIDE_SECONDS:g}*TB),scale=out_range=tv:out_color_matrix=bt709,format=yuv420p,"
          f"fps={FPS},setsar=1,{PAD_TAIL}")
    return [*BASE, "-f", "rawvideo", "-pix_fmt", "rgb24", "-s", f"{OUT_W}x{OUT_H}",
            "-framerate", f"{1 / SLIDE_SECONDS:g}", "-i", "pipe:0",
            "-vf", vf, "-fps_mode", "passthrough", "-frames:v", str(per * n_images),
            *X264, *_split_args(out_pattern, boundaries)]


def kenburns_argv(out: Path, *, seconds: float = 3.0, zoom_from: float = 1.0, zoom_to: float = 1.1) -> list[str]:
    """One rgb24 KB_SRC_W x KB_SRC_H frame on stdin -> `seconds` of centred zoom at 24 fps.
    zoompan: d = output frames PER INPUT FRAME (input is exactly one frame), fps defaults to 25 (set it),
    zoom is driven by the output frame number `on` so it is linear and ends exactly at zoom_to."""
    nf = round(seconds * FPS)
    big_w, big_h = KB_SRC_W * KB_PRESCALE, KB_SRC_H * KB_PRESCALE
    z = f"{zoom_from}+({zoom_to}-{zoom_from})*on/{max(nf - 1, 1)}"
    vf = (f"scale={big_w}:{big_h}:flags=bicubic:out_range=tv:out_color_matrix=bt709,format=yuv420p,"
          f"zoompan=z='{z}':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d={nf}:s={OUT_W}x{OUT_H}:fps={FPS},"
          f"setsar=1,format=yuv420p")
    return [*BASE, "-f", "rawvideo", "-pix_fmt", "rgb24", "-s", f"{KB_SRC_W}x{KB_SRC_H}", "-framerate", str(FPS),
            "-i", "pipe:0", "-vf", vf, "-frames:v", str(nf), *X264, str(out)]


@dataclass(frozen=True)
class ClipCut:
    ogg: Path
    offset: float  # seconds into the Opus copy
    length: float  # already clamped to what the file holds / the next clip / the video end
    start: float  # seconds into the vlog


def audio_graph(total: float, clips: Sequence[ClipCut], first_input: int) -> str:
    """Silence of `total` s with each clip faded in/out (0.3 s) and delayed to its start; mono 48 kHz.
    amix normalize=0: amix otherwise divides every input by the input count (clips get quieter)."""
    parts = [f"anullsrc=r=48000:cl=mono:d={total:.3f}[base]"]
    labels = ["[base]"]
    for i, c in enumerate(clips):
        fo = max(c.length - AUDIO_FADE, 0.0)
        parts.append(
            f"[{first_input + i}:a]aresample=48000,aformat=sample_fmts=fltp:channel_layouts=mono,"
            f"afade=t=in:st=0:d={AUDIO_FADE},afade=t=out:st={fo:.3f}:d={AUDIO_FADE},"
            f"adelay=delays={round(c.start * 1000)}:all=1[c{i}]")
        labels.append(f"[c{i}]")
    parts.append(f"{''.join(labels)}amix=inputs={len(labels)}:duration=first:dropout_transition=0:normalize=0,"
                 f"aformat=sample_rates=48000:channel_layouts=mono[aout]")
    return ";".join(parts)


def assemble_argv(parts_list: Path, out: Path, *, total: float, clips: Sequence[ClipCut], srt: Path,
                  sub_language: str = "vie") -> list[str]:
    clip_inputs: list[str] = []
    for c in clips:
        clip_inputs += ["-ss", f"{c.offset:.3f}", "-t", f"{c.length:.3f}", "-i", str(c.ogg)]
    sub_index = 1 + len(clips)
    return [*BASE, "-nostdin",
            "-f", "concat", "-safe", "0", "-i", str(parts_list),
            *clip_inputs,

            "-c:s", "mov_text", f"-metadata:s:s:0", f"language={sub_language}",
            "-video_track_timescale", str(FPS * 512), "-movflags", "+faststart", str(out)]


# --------------------------------------------------------------------------------------------- running

Feed = AsyncIterator[bytes] | None
Runner = Callable[[str, list[str], Feed], Awaitable[None]]


async def run_step(step: str, argv: list[str], feed: Feed = None, *, timeout: float = 3600.0) -> None:
    """Run one ffmpeg. Success = exit code 0 (stderr is only kept, last 8 KiB, for the error message).
    Kills the process on timeout or cancellation so no ffmpeg outlives the job."""
    proc = await asyncio.create_subprocess_exec(
        *argv, stdin=asyncio.subprocess.PIPE if feed else asyncio.subprocess.DEVNULL,
        stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.PIPE)
    tail = bytearray()

    async def drain_stderr() -> None:
        assert proc.stderr is not None
        while chunk := await proc.stderr.read(65536):
            tail.extend(chunk)
            del tail[:-8192]

    async def pump() -> None:
        assert proc.stdin is not None
        try:
            async for chunk in feed:  # type: ignore[union-attr]
                proc.stdin.write(chunk)
                await proc.stdin.drain()
        except (BrokenPipeError, ConnectionResetError):
            pass  # ffmpeg died; its exit code tells why
        finally:
            proc.stdin.close()

    try:
        async with asyncio.timeout(timeout):
            await asyncio.gather(drain_stderr(), *([pump()] if feed else []), proc.wait())
    except BaseException:
        if proc.returncode is None:
            proc.kill()
            await proc.wait()
        raise
    if proc.returncode != 0:
        raise RenderError(step, proc.returncode, tail.decode("utf-8", "replace"))

@dataclass(frozen=True)
class Segment:
    path: Path
    start: datetime  # wall-clock start of the recording


@dataclass(frozen=True)
class Still:
    jpeg: Path
    at: datetime
    caption: str
    clip_ogg: Path | None = None
    clip_offset: float = 0.0


@dataclass(frozen=True)
class Keyframe:
    jpeg: Path
    at: datetime


@dataclass
class RenderResult:
    out: Path
    vtt: Path
    frames: int
    seconds: float
    mode: str
    skipped: list[str] = field(default_factory=list)


def chunk_boundaries(cum_units_before: Sequence[int], n_in: int, n_out: int) -> list[int]:
    """Output-frame index where each still goes: number of selected frames among the first m input frames
    is ceil(m * n_out / n_in) for the uniform select above."""
    return [min(n_out, -(-m * n_out // n_in)) for m in cum_units_before]


async def _bytes_once(data: bytes) -> AsyncIterator[bytes]:
    yield data


async def _slides(jpegs: Sequence[Path]) -> AsyncIterator[bytes]:
    for p in jpegs:
        yield await asyncio.to_thread(jpeg_canvas, p, OUT_W, OUT_H)


async def render(*, segments: Sequence[Segment], stills: Sequence[Still], keyframes: Sequence[Keyframe],
                 target_seconds: float, workdir: Path, out: Path, still_seconds: float = 3.0,
                 title: str | None = None, allow_keyframes_only: bool = True,
                 runner: Runner = run_step) -> RenderResult:
    workdir.mkdir(parents=True, exist_ok=True)
    skipped: list[str] = []
    n_out = round(target_seconds * FPS)

    # ---- 0. inspect inputs (pure Python; bad inputs are skipped, never handed to ffmpeg)
    good: list[tuple[Segment, Track]] = []
    for s in sorted(segments, key=lambda s: s.start):
        try:
            good.append((s, video_track(s.path)))
        except InvalidMedia as exc:
            skipped.append(f"segment {exc}")
    ok_stills: list[tuple[Still, None]] = []
    for st in sorted(stills, key=lambda s: s.at):
        try:
            await asyncio.to_thread(jpeg_canvas, st.jpeg, 16, 9)  # full decode check, tiny output
            ok_stills.append((st, None))
        except InvalidMedia as exc:
            skipped.append(f"still {exc}")

    # ---- 1. base track, split at the stills' positions
    chunk_pat = workdir / "chunk_%03d.mp4"
    if good:
        frames = sum(t.samples for _, t in good)
        keys = sum(t.sync_samples for _, t in good)
        keyframes_only = allow_keyframes_only and keys >= KEYFRAMES_PER_OUTPUT_MIN * n_out
        units = [(s, t.sync_samples if keyframes_only else t.samples, t.seconds) for s, t in good]
        n_in = keys if keyframes_only else frames
        n_out = min(n_out, n_in)

        def units_before(at: datetime) -> int:
            m = 0
            for s, u, secs in units:
                into = (at - s.start).total_seconds()
                if into >= secs:
                    m += u
                elif into > 0:
                    m += math.ceil(u * into / secs)
            return m

        bounds = chunk_boundaries([units_before(st.at) for st, _ in ok_stills], n_in, n_out)
        lst = workdir / "segments.ffconcat"
        lst.write_text(concat_list(s.path for s, _ in good), encoding="utf-8")
        cut = sorted({b for b in bounds if 0 < b < n_out})
        await runner("timelapse", timelapse_argv(lst, chunk_pat, n_out=n_out, n_in=n_in,
                                                 keyframes_only=keyframes_only, boundaries=cut), None)
        mode = "timelapse-keyframes" if keyframes_only else "timelapse-full"
    else:
        ok_kf: list[Keyframe] = []
        for k in sorted(keyframes, key=lambda k: k.at):
            try:
                await asyncio.to_thread(jpeg_canvas, k.jpeg, 16, 9)  # decode check
                ok_kf.append(k)
            except InvalidMedia as exc:
                skipped.append(f"keyframe {exc}")
        if not ok_kf and not ok_stills:
            raise InvalidMedia("nothing to render")
        per = round(SLIDE_SECONDS * FPS)
        n_out = per * len(ok_kf)
        bounds = [per * sum(1 for k in ok_kf if k.at < st.at) for st, _ in ok_stills]
        cut = sorted({b for b in bounds if 0 < b < n_out})
        if ok_kf:
            await runner("slideshow", slideshow_argv(chunk_pat, n_images=len(ok_kf), boundaries=cut),
                         _slides([k.jpeg for k in ok_kf]))
        mode = "slideshow"
    chunk_edges = [0, *cut, n_out] if n_out else [0]
    chunks = [Path(str(chunk_pat).replace("%03d", f"{i:03d}")) for i in range(len(chunk_edges) - 1)]
    for c, (a, b) in zip(chunks, zip(chunk_edges, chunk_edges[1:])):
        try:
            got = video_track(c).samples
        except InvalidMedia:
            got = 0
        if got != b - a:  # e.g. a segment vanished/corrupted after inspection: concat stops there, rc 0
            raise RenderError(mode, 0, f"{c.name}: {got} frames, expected {b - a}")

    # ---- 2. Ken Burns stills
    kb_frames = round(still_seconds * FPS)
    still_parts: list[Path] = []
    for i, (st, _) in enumerate(ok_stills):
        p = workdir / f"still_{i:03d}.mp4"
        canvas = await asyncio.to_thread(jpeg_canvas, st.jpeg, KB_SRC_W, KB_SRC_H)
        await runner(f"kenburns[{i}]", kenburns_argv(p, seconds=still_seconds), _bytes_once(canvas))
        if video_track(p).samples != kb_frames:
            raise RenderError(f"kenburns[{i}]", 0, f"{p.name}: wrong frame count")
        still_parts.append(p)

    # ---- 3. interleave, cues, audio clips, assemble
    order: list[tuple[Path, int, Still | None]] = []
    for ci, c in enumerate(chunks):
        if ci == 0:
            order += [(still_parts[j], kb_frames, ok_stills[j][0]) for j, b in enumerate(bounds) if b == 0]
        order.append((c, chunk_edges[ci + 1] - chunk_edges[ci], None))
        order += [(still_parts[j], kb_frames, ok_stills[j][0])
                  for j, b in enumerate(bounds) if b == chunk_edges[ci + 1] and b > 0]
    if not chunks:
        order = [(still_parts[j], kb_frames, ok_stills[j][0]) for j in range(len(ok_stills))]
    total_frames = sum(n for _, n, _ in order)
    total = total_frames / FPS

    cues: list[Cue] = [Cue(0.0, min(3.0, total), title)] if title else []
    starts: list[tuple[Still, float]] = []
    pos = 0
    for _, n, st in order:
        if st is not None:
            starts.append((st, pos / FPS))
            cues.append(Cue(pos / FPS, (pos + n) / FPS, st.caption))
        pos += n
    if title:  # mov_text cannot show overlapping cues: end the title where the first caption starts
        first = min((c.start for c in cues[1:]), default=total)
        cues[0] = Cue(0.0, min(3.0, total, first) if first > 0 else min(3.0, total), title)
        if first == 0:
            cues.pop(0)
    cues.sort(key=lambda c: c.start)

    clip_cuts: list[ClipCut] = []
    with_clip = [(st, t0) for st, t0 in starts if st.clip_ogg is not None][:3]
    for i, (st, t0) in enumerate(with_clip):
        assert st.clip_ogg is not None
        try:
            avail = ogg_opus_duration(st.clip_ogg) - st.clip_offset
        except (InvalidMedia, OSError) as exc:
            skipped.append(f"clip {exc}")
            continue
        nxt = with_clip[i + 1][1] if i + 1 < len(with_clip) else total
        length = min(AUDIO_CLIP_MAX, avail, nxt - t0, total - t0)
        if length < AUDIO_CLIP_MIN:
            skipped.append(f"clip {st.clip_ogg.name}@{st.clip_offset}: only {max(avail, 0):.2f}s available")
            continue
        clip_cuts.append(ClipCut(st.clip_ogg, st.clip_offset, round(length, 3), t0))

    srt = workdir / "subs.srt"
    srt.write_text(srt_text(cues), encoding="utf-8")
    vtt = out.with_suffix(".vtt")
    vtt.write_text(vtt_text(cues), encoding="utf-8")
    parts = workdir / "parts.ffconcat"
    parts.write_text(concat_list(p for p, _, _ in order), encoding="utf-8")
    await runner("assemble", assemble_argv(parts, out, total=total, clips=clip_cuts, srt=srt), None)

    tracks = probe_mp4(out)
    kinds = sorted(t.handler for t in tracks)
    vid = [t for t in tracks if t.handler == "vide"]
    if kinds != ["sbtl", "soun", "vide"] or vid[0].samples != total_frames:
        raise RenderError("assemble", 0, f"unexpected output tracks {kinds} / frames {vid and vid[0].samples}")
    return RenderResult(out, vtt, total_frames, total, mode, skipped)
```

```python
"""Making the daily vlog (spec §9.2 "23:30: … dựng vlog", §10.3, D25; P3 design §4.1, §4.5; rulings R4–R7, R9, R11):
a planner every 15 minutes; per day one script job (the text model's lock) and one render job (its own lock); the
vlog row and its two files; "Dựng lại vlog". A vlog is stored only if no part of its day was forgotten while it was
made (the forget count, read before and checked again under the day's lock)."""
from __future__ import annotations

import asyncio
import datetime as dt
import logging
import os
import shutil
import uuid
from pathlib import Path, PurePosixPath

import anyio
import procrastinate
from psycopg import AsyncConnection
from psycopg.types.json import Jsonb
from psycopg_pool import AsyncConnectionPool

from .. import media
from ..days import day_bounds_utc, local_now
from ..vlog import render
from ..vlog.material import vlog_material
from ..vlog.script import to_json, write_script
from . import jobs
from .context import PipelineContext, get_context
from .jobs import job_app
from .state import clear_day_error, forgotten, lock_day, raw_kept, record_day_error

log = logging.getLogger(__name__)

VLOG_LOCK = "vlog"
RENDER_RETRY = procrastinate.RetryStrategy(max_attempts=2, exponential_wait=60)  # at most 3 runs
RENDER_TIMEOUT_S = 1200.0
SECONDS_PER_SEGMENT = 0.25  # of timelapse per active one-minute recording
TIMELAPSE_MIN, TIMELAPSE_MAX = 10.0, 60.0
STILL_SECONDS, STILL_MAX = 3.0, 5.0
VLOG_MIN = 20.0
CATCH_UP = 1  # earlier days asked for per planner run (newest first); today never waits
TMP_DIR = "vlog/.tmp"
SPEECH_MAX = 120  # characters of a conversation's sentence under its picture

_STORE_SCRIPT = """
INSERT INTO vlog (day, state, script, model_version) VALUES (%s, 'scripted', %s, %s)
ON CONFLICT (day) DO UPDATE SET state = 'scripted', script = EXCLUDED.script, model_version = EXCLUDED.model_version,
    scripted_at = now(), stale = false, error = NULL, error_at = NULL"""
_STORE_EMPTY = """
INSERT INTO vlog (day, state) VALUES (%s, 'empty')
ON CONFLICT (day) DO UPDATE SET state = 'empty', script = NULL, model_version = NULL, source = NULL, path = NULL,
    duration_s = NULL, generated_at = NULL, scripted_at = now(), stale = false, error = NULL, error_at = NULL"""


class VlogFailed(Exception):
    """A render that failed; the message is fixed text (it is stored and shown)."""


def vlog_lock(day: dt.date) -> str:
    return f"vlog:{day.isoformat()}"


def vlog_rel(day: dt.date) -> str:
    return f"vlog/{day:%Y/%m/%d}/{day.isoformat()}.mp4"


def vtt_rel(path: str) -> str:
    return str(PurePosixPath(path).with_suffix(".vtt"))


def plan_seconds(n_segments: int, n_stills: int) -> tuple[float, float]:
    """(timelapse seconds, seconds per picture), D25: 60–90 s on a full day, not under VLOG_MIN when it can be."""
    timelapse = min(TIMELAPSE_MAX, max(TIMELAPSE_MIN, SECONDS_PER_SEGMENT * n_segments)) if n_segments else 0.0
    still = STILL_SECONDS
    if n_stills and timelapse + n_stills * still < VLOG_MIN:
        still = min(STILL_MAX, (VLOG_MIN - timelapse) / n_stills)
    if not n_stills and n_segments and timelapse < VLOG_MIN:
        timelapse = VLOG_MIN
    return timelapse, round(still, 3)


async def _enqueue(conn: AsyncConnection, task: str, day: dt.date, lock: str) -> int:
    return await jobs.enqueue(conn, task, queue="understand", lock=lock, priority=jobs.LLM_PRIORITY,
                              queueing_lock=vlog_lock(day), day=day.isoformat())


async def defer_script(pool: AsyncConnectionPool, day: dt.date) -> int:
    async with pool.connection() as conn, conn.transaction():
        return await _enqueue(conn, jobs.WRITE_VLOG_SCRIPT, day, jobs.LLM_LOCK)


async def defer_render(pool: AsyncConnectionPool, day: dt.date) -> int:
    async with pool.connection() as conn, conn.transaction():
        return await _enqueue(conn, jobs.RENDER_VLOG, day, VLOG_LOCK)


async def drop_failed_vlogs(conn: AsyncConnection, days: list[dt.date]) -> None:
    """In the caller's transaction: delete the failed vlog runs of ``days`` and their stored errors."""
    await conn.execute("DELETE FROM procrastinate_jobs WHERE status = 'failed' AND queueing_lock = ANY(%s)",
                       ([vlog_lock(day) for day in days],))
    await conn.execute("DELETE FROM day_job_error WHERE task = ANY(%s) AND day = ANY(%s)",
                       ([jobs.WRITE_VLOG_SCRIPT, jobs.RENDER_VLOG], days))


def _inside(root: Path, rel: str | PurePosixPath | None) -> Path | None:
    if not rel:
        return None
    try:
        return media.inside(root, rel)
    except ValueError:
        log.warning("a vlog input path leaves the media root; skipped")
        return None


async def write_vlog_script(ctx: PipelineContext, day: dt.date) -> str:
    """Script the day's vlog and ask for its render ('scripted'), or store it 'empty' (nothing active); 'skipped'
    when part of the day was forgotten meanwhile (nothing stored: the planner asks again)."""
    pool, zone = ctx.pool, ctx.settings.zone
    start, end = day_bounds_utc(day, zone)
    old_path = None
    try:
        async with pool.connection() as conn:
            generation = await forgotten(conn, start, end)
        material = await vlog_material(pool, day, zone)
        written = None if material.empty else await write_script(ctx.router, material, zone)
        async with pool.connection() as conn, conn.transaction():
            await lock_day(conn, day)
            if await forgotten(conn, start, end) != generation:
                log.info("vlog of %s: part of the day was forgotten while it was scripted; not stored", day)
                return "skipped"
            if written is None:
                cur = await conn.execute("SELECT path FROM vlog WHERE day = %s FOR UPDATE", (day,))
                old = await cur.fetchone()
                old_path = old["path"] if old else None
                await conn.execute(_STORE_EMPTY, (day,))
                state = "empty"
            else:
                await conn.execute(_STORE_SCRIPT, (day, Jsonb(to_json(written)), written.model_version))
                await _enqueue(conn, jobs.RENDER_VLOG, day, VLOG_LOCK)
                state = "scripted"
    except Exception as exc:
        await record_day_error(pool, jobs.WRITE_VLOG_SCRIPT, day, exc)
        raise
    if old_path:  # the day has nothing left to show: its earlier vlog goes
        media.remove_files(ctx.settings.media_root, [old_path, vtt_rel(old_path)])
    await clear_day_error(pool, jobs.WRITE_VLOG_SCRIPT, day)
    log.info("vlog of %s: %s (%d highlights)", day, state, len(written.highlights) if written else 0)
    return state


async def _sound(pool: AsyncConnectionPool, root: Path, item_id: str) -> Path | None:
    """The normalised playback copy of an audio item (D19), made now when missing (as the /audio route does), or
    None: raw audio expired or forgotten, file missing, or the copy could not be made."""
    async with pool.connection() as conn:
        cur = await conn.execute("SELECT raw_path, raw_deleted_at FROM item WHERE id = %s AND kind = 'audio'",
                                 (item_id,))
        row = await cur.fetchone()
    if row is None or row["raw_deleted_at"] is not None:
        return None
    raw_rel = PurePosixPath(row["raw_path"])
    view_rel = media.audio_view_path(raw_rel)
    raw, view = _inside(root, raw_rel), _inside(root, view_rel)
    if raw is None or view is None or not raw.is_file():
        return None
    if not view.is_file():
        try:
            await media.normalise_audio(raw, view)
        except (media.MediaError, OSError) as exc:
            log.warning("vlog sound of %s skipped: %s", item_id, type(exc).__name__)
            return None
        if not await raw_kept(pool, item_id):  # forgotten or expired while the copy was made
            media.remove_files(root, [str(view_rel)])
            return None
    return view


async def _stills(pool: AsyncConnectionPool, root: Path, script: dict) -> list[render.Still]:
    stills = []
    for h in script.get("highlights", []):
        jpeg = _inside(root, h.get("jpeg"))
        if jpeg is None or not jpeg.is_file():
            continue  # its picture is gone (forgotten): the highlight is left out
        clip = await _sound(pool, root, h["audio_item"]) if h.get("audio_item") else None
        caption = h["line"] if not h.get("speech") else f"{h['line']}\n“{h['speech'][:SPEECH_MAX]}”"
        stills.append(render.Still(jpeg, dt.datetime.fromisoformat(h["at"]), caption, clip, h.get("audio_offset", 0.0)))
    return stills


def _failure(exc: BaseException) -> str:
    if isinstance(exc, render.RenderError):
        return f"render failed at {exc.step} (ffmpeg exit {exc.returncode})"
    if isinstance(exc, render.InvalidMedia):
        return "a picture or recording could not be read"
    return f"render took longer than {RENDER_TIMEOUT_S / 60:.0f} minutes"


async def _store_render(ctx: PipelineContext, day: dt.date, scripted_at: dt.datetime, generation: int,
                        result: render.RenderResult, source: str) -> bool:
    root, zone = ctx.settings.media_root, ctx.settings.zone
    start, end = day_bounds_utc(day, zone)
    rel = vlog_rel(day)
    final = media.inside(root, rel)
    async with ctx.pool.connection() as conn, conn.transaction():
        await lock_day(conn, day)
        if await forgotten(conn, start, end) != generation:
            log.info("vlog of %s: part of the day was forgotten while it rendered; not stored", day)
            return False
        cur = await conn.execute(
            "SELECT 1 FROM vlog WHERE day = %s AND state = 'scripted' AND scripted_at = %s FOR UPDATE", (day, scripted_at)
        )
        if await cur.fetchone() is None:
            log.info("vlog of %s: its script changed while it rendered; not stored", day)
            return False
        final.parent.mkdir(parents=True, exist_ok=True)
        os.replace(result.out, final)
        os.replace(result.vtt, final.with_suffix(".vtt"))
        await conn.execute(
            "UPDATE vlog SET state = 'rendered', path = %s, source = %s, duration_s = %s, generated_at = now(),"
            " error = NULL, error_at = NULL WHERE day = %s",
            (rel, source, result.seconds, day),
        )
    return True


async def render_vlog(ctx: PipelineContext, day: dt.date) -> bool:
    """Render the day's scripted vlog and store it; False when there is nothing to render or it was not stored
    (forgotten or rescripted meanwhile). VlogFailed (fixed message, stored on the row) when the render fails."""
    pool, settings = ctx.pool, ctx.settings
    root, zone = settings.media_root, settings.zone
    start, end = day_bounds_utc(day, zone)
    async with pool.connection() as conn:
        cur = await conn.execute("SELECT state, script, scripted_at FROM vlog WHERE day = %s", (day,))
        row = await cur.fetchone()
        generation = await forgotten(conn, start, end)
    if row is None or row["state"] != "scripted":
        return False
    work = root / TMP_DIR / f"{day.isoformat()}-{uuid.uuid4().hex}"
    try:
        material = await vlog_material(pool, day, zone)
        stills = await _stills(pool, root, row["script"] or {})
        segments = [render.Segment(p, s.start) for s in material.segments if (p := _inside(root, s.path))]
        frames = [] if segments else [render.Keyframe(p, f.at) for f in material.frames if (p := _inside(root, f.path))]
        timelapse, still_seconds = plan_seconds(len(segments), len(stills))
        work.mkdir(parents=True)
        try:
            async with asyncio.timeout(RENDER_TIMEOUT_S):
                result = await render.render(
                    segments=segments, stills=stills, keyframes=frames, target_seconds=timelapse,
                    workdir=work / "parts", out=work / "vlog.mp4", still_seconds=still_seconds,
                    title=(row["script"] or {}).get("title"),
                )
        except (render.RenderError, render.InvalidMedia, TimeoutError) as exc:
            log.warning("vlog of %s: %s", day, _failure(exc))
            raise VlogFailed(_failure(exc)) from None
        stored = await _store_render(ctx, day, row["scripted_at"], generation, result,
                                     "video" if segments else "keyframes")
    except Exception as exc:
        message = str(exc) if isinstance(exc, VlogFailed) else None
        try:
            async with pool.connection() as conn:
                await conn.execute("UPDATE vlog SET error = %s, error_at = now() WHERE day = %s",
                                   (message or "render failed", day))
        except Exception:
            log.exception("could not record the vlog error of %s", day)
        await record_day_error(pool, jobs.RENDER_VLOG, day, exc)
        raise
    finally:
        await anyio.to_thread.run_sync(lambda: shutil.rmtree(work, ignore_errors=True))
    await clear_day_error(pool, jobs.RENDER_VLOG, day)
    if stored:
        log.info("vlog of %s rendered: %s, %.1f s, %d skipped inputs", day, result.mode, result.seconds,
                 len(result.skipped))
    return stored


async def request_rebuild(pool: AsyncConnectionPool, day: dt.date) -> int | None:
    """"Dựng lại vlog": drop the day's failed vlog runs and their errors, mark its vlog out of date (it stays until
    the new one is stored, R5), and ask for a new script now. Its job id, or None when it could not be queued."""
    async with pool.connection() as conn, conn.transaction():
        await drop_failed_vlogs(conn, [day])
        await conn.execute("UPDATE vlog SET stale = true WHERE day = %s", (day,))
    try:
        return await defer_script(pool, day)
    except Exception:
        log.exception("could not ask for the vlog of %s", day)
        return None


async def plan_vlogs(pool: AsyncConnectionPool, zone, now: dt.datetime | None = None) -> list[dt.date]:
    """Ask for the vlog of every day that has a recap and needs one (R6), and return those days:
    - no vlog yet, a stale one, or one scripted before the day's (non-stale) recap was last written;
    - a 'scripted' vlog with no job (a render lost in a crash): its render.
    Never a day whose vlog job waits, runs or failed; earlier days CATCH_UP per run, newest first."""
    today = local_now(zone, now).date()
    async with pool.connection() as conn:
        cur = await conn.execute(
            """SELECT r.day, r.generated_at AS recap_at, r.stale AS recap_stale, v.state, v.scripted_at, v.stale
                 FROM day_recap r LEFT JOIN vlog v ON v.day = r.day
                WHERE r.day <= %(today)s
                  AND NOT EXISTS (SELECT 1 FROM procrastinate_jobs j
                                   WHERE j.queueing_lock = 'vlog:' || r.day::text
                                     AND j.status IN ('todo', 'doing', 'failed'))
                ORDER BY r.day DESC""",
            {"today": today},
        )
        rows = await cur.fetchall()
    asked: list[dt.date] = []
    earlier = 0
    for r in rows:
        if r["state"] == "scripted" and not r["stale"]:
            await defer_render(pool, r["day"])
            asked.append(r["day"])
            continue
        due = r["state"] is None or r["stale"] or (not r["recap_stale"] and r["scripted_at"] < r["recap_at"])
        if not due:
            continue
        if r["day"] < today:
            if earlier >= CATCH_UP:
                continue
            earlier += 1
        await defer_script(pool, r["day"])
        asked.append(r["day"])
    return asked


@job_app.periodic(cron="*/15 * * * *")
@job_app.task(name=jobs.PLAN_VLOGS, queue="light", queueing_lock="plan_vlogs")
async def plan_vlogs_job(timestamp: int | None = None) -> None:
    ctx = get_context()
    await plan_vlogs(ctx.pool, ctx.settings.zone)
```

```python
"""The Vlog pages (spec §10.6 "Vlog: xem và tải từng ngày"; P3 design §4.6; ruling R10): the list, one day's player
(the MP4 with a WebVTT track: browsers do not show mov_text), the files (Range requests for seeking; a download)
and "Dựng lại vlog". The file routes are declared before the page route: ``/vlog/{day}`` would take
``2026-10-14.mp4`` otherwise."""
from __future__ import annotations

import datetime as dt
from pathlib import Path

from fastapi import APIRouter, Depends, HTTPException, Query, Request
from fastapi.responses import FileResponse, HTMLResponse

from .. import media
from ..pipeline import vlogs as vlog_rules
from .routes import TEMPLATES, require_htmx

router = APIRouter()
LIST_MAX = 120


def _duration(seconds: float | None) -> str | None:
    if not seconds:
        return None
    minutes, rest = divmod(round(seconds), 60)
    return f"{minutes}:{rest:02d}"


async def vlog_view(pool, day: dt.date, zone) -> dict | None:
    """What the pages show of one day's vlog; None when there is no vlog row and no vlog job, waiting or failed."""
    lock = vlog_rules.vlog_lock(day)
    async with pool.connection() as conn:
        cur = await conn.execute("SELECT * FROM vlog WHERE day = %s", (day,))
        row = await cur.fetchone()
        cur = await conn.execute(
            "SELECT e.error FROM procrastinate_jobs j LEFT JOIN day_job_error e ON e.task = j.task_name AND e.day = %s"
            " WHERE j.queueing_lock = %s AND j.status = 'failed' ORDER BY j.id DESC LIMIT 1",
            (day, lock),
        )
        failed = await cur.fetchone()
        cur = await conn.execute(
            "SELECT 1 FROM procrastinate_jobs WHERE queueing_lock = %s AND status IN ('todo', 'doing')", (lock,)
        )
        waiting = await cur.fetchone()
    if row is None and failed is None and waiting is None:
        return None
    row = row or {}
    script = row.get("script") or {}
    return {
        "day": day,
        "state": row.get("state"),
        "title": script.get("title"),
        "duration": _duration(row.get("duration_s")),
        "at": row["generated_at"].astimezone(zone).strftime("%d/%m %H:%M") if row.get("generated_at") else None,
        "has_file": bool(row.get("path")) and row.get("state") != "empty",
        "working": waiting is not None or row.get("state") == "scripted" or bool(row.get("stale")),
        "error": row.get("error") or (failed["error"] if failed and failed["error"] else None)
        or ("lần dựng gần nhất bị lỗi" if failed else None),
        "source": row.get("source"),
        "model": row.get("model_version"),
    }


async def _file(request: Request, day: dt.date, suffix: str) -> Path:
    async with request.app.state.pool.connection() as conn:
        cur = await conn.execute("SELECT path FROM vlog WHERE day = %s AND path IS NOT NULL", (day,))
        row = await cur.fetchone()
    if row is None:
        raise HTTPException(status_code=404, detail="no vlog")
    rel = row["path"] if suffix == ".mp4" else vlog_rules.vtt_rel(row["path"])
    try:
        path = media.inside(request.app.state.settings.media_root, rel)
    except ValueError as exc:
        raise HTTPException(status_code=404, detail="no vlog") from exc
    if not path.is_file():
        raise HTTPException(status_code=404, detail="no vlog")
    return path


@router.get("/vlog", response_class=HTMLResponse)
async def vlog_list(request: Request):
    state = request.app.state
    async with state.pool.connection() as conn:
        cur = await conn.execute("SELECT day FROM vlog ORDER BY day DESC LIMIT %s", (LIST_MAX,))
        days = [r["day"] for r in await cur.fetchall()]
    views = [v for day in days if (v := await vlog_view(state.pool, day, state.settings.zone)) is not None]
    return TEMPLATES.TemplateResponse(request, "vlog_list.html", {"vlogs": views})


@router.get("/vlog/{day}.mp4")
async def vlog_mp4(request: Request, day: dt.date, download: bool = Query(default=False)):
    path = await _file(request, day, ".mp4")
    if download:
        return FileResponse(path, media_type="video/mp4", filename=f"loopi-vlog-{day.isoformat()}.mp4")
    return FileResponse(path, media_type="video/mp4", headers={"Cache-Control": "private, max-age=3600"})


@router.get("/vlog/{day}.vtt")
async def vlog_vtt(request: Request, day: dt.date):
    return FileResponse(await _file(request, day, ".vtt"), media_type="text/vtt; charset=utf-8")


@router.get("/vlog/{day}", response_class=HTMLResponse)
async def vlog_page(request: Request, day: dt.date):
    state = request.app.state
    return TEMPLATES.TemplateResponse(
        request, "vlog_day.html", {"day": day, "vlog": await vlog_view(state.pool, day, state.settings.zone)}
    )


@router.post("/vlog/{day}/rebuild", response_class=HTMLResponse, dependencies=[Depends(require_htmx)])
async def vlog_rebuild(request: Request, day: dt.date):
    if await vlog_rules.request_rebuild(request.app.state.pool, day) is None:
        return HTMLResponse('<span class="err">Chưa yêu cầu được, hãy thử lại sau.</span>')
    return HTMLResponse("<span>Đã yêu cầu dựng lại vlog; vài phút nữa xem lại trang này.</span>")
```

````markdown
## Vlog (P3b)

Every evening, after the day's recap, the brain makes a vlog of the day (spec §10.3, D25):
- the hours with activity, sped up to at most 60 s;
- 6–10 highlight pictures with a slow zoom (marked moments, notable pictures, dense conversations);
- up to three short clips of their sound (the normalised playback copy, D19);
- subtitles.

It is written by the recap's model. When that model cannot answer, a rule picks the highlights, so there is still a vlog. Earlier days that have a recap catch up one day per 15 minutes.

- **Where:** "Vlog" in the menu lists every day. A day's page plays it with subtitles and has "Tải về" and "Dựng lại vlog". The Day page shows it too.
- **Files:** `$LOOPI_DATA_DIR/media/vlog/YYYY/MM/DD/<day>.mp4` and `.vtt`, about 10–20 MB a day, kept for ever. Retention never deletes them. "Quên khoảng thời gian" deletes the vlogs of the days it touches, and they are made again.
- **Cost:** about 2–4 minutes of CPU per day on the brain PC (measured: a 4-hour active day took 152 s wall and 212 s CPU, peak 198 MB). It runs one vlog at a time (job lock `vlog`) behind live work.
- **When the raw video has expired:** the vlog is made from the day's keyframes as a slideshow.
- **If one fails:** "Dựng vlog lỗi" shows on the day's page and on Xử lý, with a retry button. A failed vlog is not retried by itself after its 3 runs.
````
